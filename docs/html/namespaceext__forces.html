Detailed Description

External forces module for QM/MM calculations.

This module provides data structures and variables for handling external forces in QM/MM calculations, including spline-interpolated forces and van der Waals interactions.

The module contains:

  • Spline parameters for force interpolation
  • External force coefficients and knots
  • Force arrays for different interaction types
  • QM/MM region force contributions
Note
Used in QM/MM calculations with external force fields
Supports various force field types and interpolation schemes
