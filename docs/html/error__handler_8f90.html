subroutine errore ( character(len=*), intent(in) calling_routine,
character(len=*), intent(in) message,
integer, intent(in) ierr )

Write and handle error messages for parallel and serial execution.

This subroutine writes an error message to output. If ierr <= 0, it does nothing. If ierr > 0, it prints the error and stops execution. In parallel execution, it also writes to a crash file and aborts MPI if available.

Parameters
[in]calling_routineName of the calling routine
[in]messageError message to output
[in]ierrError flag (if > 0, triggers stop)
