Solve generalized eigenvalue problem for unpaired molecular orbitals.

This subroutine solves the generalized eigenvalue problem for molecular orbitals including unpaired electrons. It handles the case where some orbitals are occupied by unpaired electrons and need to be orthogonalized separately. The routine performs matrix preconditioning, diagonalization with constraints for unpaired orbitals, and proper eigenvector sorting with gauge fixing.
