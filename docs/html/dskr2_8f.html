39* Purpose
40* =======
41*
42* DSKR2 performs the skew-symmetric rank 2 operation
43*
44* A := alpha*x*y^T - alpha *y*x^T + A,
45*
46* where alpha is a scalar, x and y are n element vectors and A is an n
47* by n skew-symmetric matrix (A^T=-A).
48*
49* Arguments
50* ==========
51*
52* UPLO - CHARACTER*1.
53* On entry, UPLO specifies whether the upper or lower
54* triangular part of the array A is to be referenced as
55* follows:
56*
57* UPLO = 'U' or 'u' Only the upper triangular part of A
58* is to be referenced.
59*
60* UPLO = 'L' or 'l' Only the lower triangular part of A
61* is to be referenced.
62*
63* Unchanged on exit.
64*
65* N - INTEGER.
66* On entry, N specifies the order of the matrix A.
67* N must be at least zero.
68* Unchanged on exit.
69*
70* ALPHA - DOUBLE PRECISION .
71* On entry, ALPHA specifies the scalar alpha.
72* Unchanged on exit.
73*
74* X - DOUBLE PRECISION array of dimension at least
75* ( 1 + ( n - 1 )*abs( INCX ) ).
76* Before entry, the incremented array X must contain the n
77* element vector x.
78* Unchanged on exit.
79*
80* INCX - INTEGER.
81* On entry, INCX specifies the increment for the elements of
82* X. INCX must not be zero.
83* Unchanged on exit.
84*
85* Y - DOUBLE PRECISION array of dimension at least
86* ( 1 + ( n - 1 )*abs( INCY ) ).
87* Before entry, the incremented array Y must contain the n
88* element vector y.
89* Unchanged on exit.
90*
91* INCY - INTEGER.
92* On entry, INCY specifies the increment for the elements of
93* Y. INCY must not be zero.
94* Unchanged on exit.
95*
96* A - DOUBLE PRECISION array of DIMENSION ( LDA, n ).
97* Before entry with UPLO = 'U' or 'u', the leading n by n
98* upper triangular part of the array A must contain the upper
99* triangular part of the skew-symmetric matrix and the strictly
100* lower triangular part of A is not referenced. On exit, the
101* upper triangular part of the array A is overwritten by the
102* upper triangular part of the updated matrix.
103* Before entry with UPLO = 'L' or 'l', the leading n by n
104* lower triangular part of the array A must contain the lower
105* triangular part of the skew-symmetric matrix and the strictly
106* upper triangular part of A is not referenced. On exit, the
107* lower triangular part of the array A is overwritten by the
108* lower triangular part of the updated matrix.
109* Note that the imaginary parts of the diagonal elements need
110* not be set, they are assumed to be zero, and on exit they
111* are set to zero.
112*
113* LDA - INTEGER.
114* On entry, LDA specifies the first dimension of A as declared
115* in the calling (sub) program. LDA must be at least
116* max( 1, n ).
117* Unchanged on exit.
