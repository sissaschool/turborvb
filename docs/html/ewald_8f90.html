Detailed Description

Ewald summation module for long-range Coulomb interactions in periodic systems.

This module implements the Ewald summation method for efficiently computing long-range Coulomb interactions in periodic boundary conditions. It provides both real-space and reciprocal-space contributions to the electrostatic energy, along with self-energy corrections and efficient parallelization support. The implementation is optimized for quantum Monte Carlo calculations and supports both ionic and electronic charge distributions.

Author
TurboRVB group
Date
2022

Algorithm

The Ewald summation splits the Coulomb interaction into three parts:

  • Real-space sum: Short-range interactions with Gaussian screening
  • Reciprocal-space sum: Long-range interactions in Fourier space
  • Self-energy correction: Removal of self-interaction terms

References

  • S. Sorella et al., J. Chem. Phys. 143, 244112 (2015)
  • M. Born, K. Huang, Dynamical Theory of Crystal Lattices (1954)
  • P. P. Ewald, Ann. Phys. 64, 253 (1921)

Find optimal condition number for non-orthogonal cell.

This function computes the optimal condition number for determining the G-vector cutoff in non-orthogonal cells. It tries all possible permutations of the reciprocal lattice vectors to find the minimum condition number, which ensures the cutoff sphere fits within the cell.

Parameters
[in]sabCosine of angle between first and second reciprocal vectors
[in]sacCosine of angle between first and third reciprocal vectors
[in]sbcCosine of angle between second and third reciprocal vectors
Returns
Optimal condition number for G-vector cutoff
Note
Tests all 6 permutations of the three reciprocal lattice vectors
Uses Gram determinant to check validity of 3D cell
Doubles condition number if Gram determinant is negative (2D case)

subroutine ewald::ewaldself

Compute the Ewald self-energy correction.

This subroutine calculates the self-interaction correction for the Ewald sum, which must be subtracted to obtain the correct total energy. The correction follows the form: -2ε₀κ/√π * Σq²ᵢ

Note
eself: Total self-energy for all physical charges
eself1b: Per-electron self-energy correction for ions only
Uses Ewald screening parameter κ and dielectric constant ε₀

Compute the reciprocal space part of the Ewald sum (energy and potential)

This subroutine evaluates the reciprocal space contribution to the Ewald sum for a given configuration of ions and electrons. It computes the Fourier space energy contribution and updates the regularized potential for each electron. The energy follows the form: (8π/Ω) * Σ factor(G) * |ρ(G)|²

Parameters
[in]kelElectronic coordinates (3, nelectrons)
[in]rionIonic coordinates (3, natoms)
[out]energyTotal Ewald energy (including self-energy)
[out]vpotregRegularized potential array (2, nelectrons)
[in]iwWalker index (for QMC)
Note
Calls TrigRecur to compute phase factors exp(iG·r)
Uses OpenMP parallelization for G-vector loop
Excludes G=0 vector from the sum
Adds self-energy correction to total energy
Distributes long-range contribution equally among electrons

◆ ggen_samegrid()

subroutine ewald::ggen_samegrid

Generate G-vectors using existing grid indices.

This subroutine computes reciprocal lattice vectors (G) and their squared magnitudes using pre-existing grid indices stored in ind_g. It also calculates the exponential factors exp(-G^2/4κ^2)/G^2 used in the reciprocal space part of the Ewald sum.

Note
Uses existing ind_g array for grid indices
Sets factor(ig) = ε₀ * exp(-G²/4κ²) / G² for each G-vector

Compute sin and cos phase factors for G·r by recursion.

This subroutine efficiently computes the phase factors exp(iG·r) for all G-vectors and particle positions using recursive relations. It generates phsfac1, phsfac2, phsfac3 arrays containing exp(ihG₁·r), exp(ikG₂·r), and exp(ilG₃·r) respectively, where h,k,l are the G-vector indices.

Parameters
[in]particle_startIndex of first particle to process
[in]particle_endIndex of last particle to process
[in]sArray of particle coordinates (3, particle_end)
Note
Supports OpenMP parallelization for large systems
Uses recursive relations: exp(ijθ) = [exp(iθ)]^j for efficiency
Handles single-particle case separately for thread safety
Only stores l≥0 for phsfac3 to save memory in long cells
