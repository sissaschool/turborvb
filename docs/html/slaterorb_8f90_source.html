16!> @brief Orbital type classification for Slater vs Gaussian orbitals
17!>
18!> This function determines whether a given orbital type code corresponds
19!> to a Slater-type orbital (STO) or a Gaussian-type orbital (GTO) in
20!> quantum Monte Carlo calculations. It provides a systematic way to
21!> classify orbital types based on their numerical identifiers.
22!>
23!> @param[in] ioptorb Orbital type code to be classified
24!> @return Logical value: .true. for Slater orbitals, .false. for Gaussian orbitals
25!>
26!> @details
27!> The function performs the following classification:
28!> 1. Slater-type orbitals (return .true.):
29!> - Ranges: 1:8, 10:15, 20:29, 30:35, 38:43, 50, 55:57, 66, 70, 71, 80:89
30!> - Extended ranges: 121:123, 125:130, 133:144
31!> 2. Gaussian-type orbitals (return .false.):
32!> - Ranges: 16:19, 36, 37, 44:49, 51:54, 58:59, 60:65, 68:69, 72, 73
33!> - Extended ranges: 100:105, 108, 109, 131, 132, 145:155, 161
34!> - Large ranges: 1000:1099, 2000:2099, 1100:1199, 2100:2199, 1200:1299, 2200:2299
35!> - Special case: 200 (constant orbital considered Gaussian)
36!> 3. Unknown orbital types: Sets error flag and reports the unknown code
37!>
38!> @note The function uses case statements for efficient classification
39!> @note Slater orbitals include s, p, d, f, g orbitals and their variants
40!> @note Gaussian orbitals include contracted Gaussians and specialized forms
41!> @note The constant orbital (ioptorb=200) is classified as Gaussian
42!> @note Unknown orbital types trigger an error condition (iflagerr=1)
43!> @note Used in wave function setup and orbital basis set management
44function slaterorb(ioptorb)
45 use constants, only: iflagerr
46 implicit none
47 integer ioptorb
48 logical slaterorb
49 select case (ioptorb)
50 ! case(34,10,12,28,57,80) ! Slater s
51 ! slaterorb=.true.
52 ! case(20,22,82) ! Slater p
53 ! slaterorb=.true.
54 ! case(30,33,84) ! Slater d
55 ! slaterorb=.true.
56 ! case(70,86) ! Slater f
57 ! slaterorb=.true.
58 ! case(55,88) ! Slater g
59 ! slaterorb=.true.
60 case (1:8, 10:15, 20:29, 30:35, 38:43, 50, 55:57, 66, 70, 71, 80:89, &
61 121:123, 125:130, 133:144)
62 slaterorb = .true.
63 case (16:19, 36, 37, 44:49, 51:54, 58:59, 60:65, 68:69, 72, 73, 100:105, 108, 109, &
64 131, 132, 145:155, 161, 1000:1099, 2000:2099, 1100:1199, &
65 2100:2199, 1200:1299, 2200:2299, 200)
66! the constant orbital is considered Gaussian
67 slaterorb = .false.
68 case default
69 ! Orbital not found
70 write (6, *) ' ERROR orbital not Slater neither Gaussian, &
71 & check slaterorb function, ioptorb= ', ioptorb
72 iflagerr = 1
73 end select
74 return
75end
