16!> @brief Real wave function constraint builder with sparse matrix indexing
17!>
18!> This subroutine constructs constraints for real wave functions using sparse
19!> matrix indexing. It handles Jastrow factor derivatives and maps them to
20!> wave function parameters using a sparse matrix representation.
21!>
22!> @param[in] iesfreer Number of free parameters in the wave function
23!> @param[in] n3body Number of three-body terms (Jastrow factors)
24!> @param[in] jbraj Array mapping Jastrow terms to parameter indices
25!> @param[in] nozeroj Array of sparse matrix indices for non-zero elements
26!> @param[in] derjas Array of Jastrow derivatives
27!> @param[in,out] econf Energy configuration array to be updated
28!> @param[in] nw Number of walkers
29!> @param[in] iopt Operation mode flag
30!>
31!> @details
32!> The subroutine performs the following operations:
33!>
34!> **Operation Modes (iopt):**
35!> - iopt = 0: Accumulate derivatives (add to existing values)
36!> - iopt ≠ 0: Replace derivatives (set new values)
37!>
38!> **Sparse Matrix Handling:**
39!> The nozeroj array provides indices into the sparse derivative array,
40!> allowing efficient handling of only non-zero matrix elements.
41!>
42!> **Parameter Mapping:**
43!> - jbraj(i) > 0: Add derivative to parameter jbraj(i)
44!> - jbraj(i) < 0: Subtract derivative from parameter |jbraj(i)|
45!>
46!> @note This subroutine always initializes the energy configuration array to zero.
47!> @note The sparse indexing allows efficient handling of large, sparse matrices.
48subroutine constrbra(iesfreer, n3body, jbraj, nozeroj, derjas &
49 &, econf, nw, iopt)
50 implicit none
51 integer iesfreer, jbraj(*), nozeroj(*), nw, i, j, n3body, iopt
52 real*8 econf(nw, *), derjas(*)
53
54 !> @brief Early return if no free parameters
55 if (iesfreer .eq. 0) return
56
57 !> @brief Initialize energy configuration array to zero
58 do j = 1, iesfreer
59 econf(1, j) = 0.d0
60 end do
61
62 !> @brief Accumulate derivatives (iopt = 0)
63 if (iopt .eq. 0) then
64
65 do i = 1, n3body
66 j = jbraj(i)
67
68 if (j .gt. 0) then
69 !> @brief Add derivative using sparse matrix indexing
70 econf(1, j) = econf(1, j) + derjas(nozeroj(i))
71 elseif (j .lt. 0) then
72 !> @brief Subtract derivative using sparse matrix indexing
73 econf(1, -j) = econf(1, -j) - derjas(nozeroj(i))
74 end if
75 end do
76
77 else
78 !> @brief Replace derivatives (iopt ≠ 0)
79
80 do i = 1, n3body
81 j = jbraj(i)
82 if (j .gt. 0) then
83 !> @brief Set derivative using sparse matrix indexing
84 econf(1, j) = derjas(nozeroj(i))
85 elseif (j .lt. 0) then
86 !> @brief Set negative derivative using sparse matrix indexing
87 econf(1, -j) = -derjas(nozeroj(i))
88 end if
89 end do
90
91 end if
92
93 return
94end

115!> - iopt = 0: Accumulate derivatives (add to existing values)

117!>

126!> @note This subroutine always initializes the energy configuration array to zero.
127!> @note The alternative indexing scheme may be more efficient for certain
128!> sparse matrix structures.
