Apply energy cutoff using hyperbolic tangent or linear function.

This function applies an energy cutoff using either a hyperbolic tangent function (if costcut≠0) or a linear cutoff (if costcut=0). The hyperbolic tangent form provides a smooth cutoff around etry.

Parameters
[in]etryReference energy for cutoff
[in]srparLinear cutoff parameter
[in]costcutHyperbolic tangent cutoff parameter
[in]enerInput energy value
Returns
enercutoff Energy value after cutoff transformation
