Detailed Description

Orbital contraction mapping and multiplicity checking functions.

This module provides functions to map contracted orbital types to their uncontracted counterparts and check orbital multiplicity consistency. The functions handle various orbital types including s, p, d, f, g, h, i orbitals with different basis set contractions (Gaussian, Slater, mixed). Used extensively in quantum Monte Carlo calculations for wave function optimization and evaluation.
