33 !> @brief Computes and sets up the computational grid
34 !> @details This subroutine generates or reads a computational grid
35 !> for correlation function calculations. It can either read
36 !> grid points from an external file (turbo_grid.dat) or
37 !> generate a regular grid with various centering options.
38 !> The grid can be centered on the coordinate origin, the
39 !> barycenter of atoms, or a specified point in space.
40 !> @param[in] ngrid_l Local grid dimensions (3)
41 !> @param[in] ell System dimensions (3)
42 !> @param[out] vell Grid velocity vectors (3)
