program plot_orbitals

Orbital plotting program for TurboRVB.

This program generates 3D plots of molecular orbitals, charge density, and spin density from TurboRVB wave functions. It reads a fort.10 file and outputs data files suitable for visualization software like XCrySDen. The program supports both open and periodic boundary conditions and can handle complex wave functions.
