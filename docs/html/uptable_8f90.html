Update table and tabler for real wave function ratios.

Updates the table and tabler arrays for real wave function ratios. The bosonic regularizing wfb is Sqrt(Det^2+exp(2 epscut)) and the guiding is the fermionic one wf = Sign Det x Sqrt(Det^2+exp(2 epscut)). abs(table) are the ratio of the bosonic wf. Handles real matrices for up and down electrons with regularization options.

Parameters
[in]nelupNumber of up electrons
[in]neldoNumber of down electrons
[in]indtIndex offset for derivatives
[out]tableReal table of wave function values
[out]tablerReal table of regularized values
[in]winvupReal inverse matrix for up electrons
[in]winvdoReal inverse matrix for down electrons
[in]tabpipTable of pip values
[in]tmuTable of tmu values
[in]epscutCutoff parameter for regularization
[in]psilnPsi log value
[in]psidetlnPsi determinant log value
[in]costaCost parameter (plat(2)/alat**2)
[in]parcutgCutoff parameter
[in]istartStart index for calculation
[in]typeregRegularization type
