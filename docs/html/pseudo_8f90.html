program pseudo

Pseudopotential analysis and conversion program for TurboRVB.

This program reads pseudopotential data from pseudo.dat and analyzes the pseudopotential functions. It can suggest appropriate cutoff radii and convert pseudopotential data to different formats. The program outputs plotting data and can rewrite the pseudopotential file with optimized parameters.

real*8 r,
real*8, dimension(3, *) param,

Calculate pseudopotential function value.

This function evaluates the pseudopotential at a given distance using the provided parameters. The function uses a sum of exponential terms with polynomial prefactors.

Parameters
nmaxNumber of terms in the pseudopotential expansion
rDistance at which to evaluate the pseudopotential
paramArray of pseudopotential parameters
psipWork array for intermediate calculations
Returns
The value of the pseudopotential at distance r
