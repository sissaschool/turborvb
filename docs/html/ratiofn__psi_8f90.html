Compute regularized wave function ratio.

Computes the ratio of regularized wave functions (wfnew/wfnewr)/(wfold/wfoldr) where wf*r means the regularized wave function. The sign does not play any role since Sign wf*r = Sign wf*. Different regularization types are supported.

Parameters
[in]parcutRegularization parameter (cutoff value)
[in]psioldLog of old wave function amplitude: log(|wfold|)
[in]ratioRatio of new to old wave function: wfnew/wfold
[out]tablerRegularized ratio: (wfnew/wfnewr)/(wfold/wfoldr)
[in]typeregType of regularization:
  • 2: Hard cutoff regularization
  • 4: Soft regularization with sqrt(wf^2 + epsilon^2)
  • 8: Sign regularization (wfr = sgn(wf))
  • Other: Standard cutoff regularization
