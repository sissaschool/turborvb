Symmetrize the AGP (Antisymmetrized Geminal Power) matrix according to symmetry constraints.

This subroutine enforces symmetry constraints on the AGP matrix (detmat_c), ensuring that only allowed matrix elements are retained and that symmetrization is performed according to the system's point group and physical requirements. It supports both real and complex AGP, molecular and periodic systems, and handles Hermitian and non-Hermitian cases. The symmetrization is performed by averaging over symmetry-equivalent elements and applying sign conventions as needed.

The algorithm includes:

  • Zeroing forbidden elements
  • Averaging over symmetry-equivalent elements
  • Enforcing Hermitian or other symmetry constraints
  • Special handling for molecular/periodic, real/complex, and Pfaffian cases

[in]jbradetSymmetry label array for compact AGP

[out]dswSymmetrized values for each symmetry class
[in]iessw0Number of symmetry groupings
[in,out]scale_cWorking array for compact AGP values
[out]itouchCounter for number of times each symmetry class is touched
[in,out]detmat_cAGP matrix to be symmetrized (input/output)
[in]nelorb_cNumber of orbitals (columns)
[in]nelorb_atNumber of atomic orbitals
[in]nelcol_cNumber of columns in AGP matrix
[in]symmagpLogical flag: apply additional symmetrization for AGP
[in]yes_hermiteLogical flag: enforce Hermitian symmetry
Note
This subroutine is essential for ensuring the physical correctness of the AGP wave function in quantum Monte Carlo calculations, especially when using symmetry reduction and compact representations.
