Set up TurboQ parameters for quantum dynamics.

Computes TurboQ parameters for quantum dynamics including Green's functions, noise matrices, and time evolution operators. Handles both overdamped and underdamped regimes with proper noise corrections for quantum Monte Carlo.

Parameters
[in]gamma_eigEigenvalue of gamma matrix
[in]kdyn_eigEigenvalue of kinetic matrix
[in]dtTime step
[in]alphaallAll alpha parameter
[in]alphaqmcQMC alpha parameter
[out]mnoiseNoise matrix
[out]GnGreen's function
[out]TnT function
[out]GniGreen's function inverse
[out]GnhHalf-step Green's function
[out]GnihHalf-step Green's function inverse
