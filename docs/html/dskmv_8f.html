41*
42* DSKMV performs the matrix-vector operation
43*
44* y := alpha*A*x + beta*y,
45*
46* where alpha and beta are scalars, x and y are n element vectors and
47* A is an n by n skew-symmetric matrix.
48*
49* Arguments
50* ==========
51*
52* UPLO - CHARACTER*1.
53* On entry, UPLO specifies whether the upper or lower
54* triangular part of the array A is to be referenced as
55* follows:
56*
57* UPLO = 'U' or 'u' Only the upper triangular part of A
58* is to be referenced.
59*
60* UPLO = 'L' or 'l' Only the lower triangular part of A
61* is to be referenced.
62*
63* Unchanged on exit.
64*
65* N - INTEGER.
66* On entry, N specifies the order of the matrix A.
67* N must be at least zero.
68* Unchanged on exit.
69*
70* ALPHA - DOUBLE PRECISION .
71* On entry, ALPHA specifies the scalar alpha.
72* Unchanged on exit.
73*
74* A - DOUBLE PRECISION array of DIMENSION ( LDA, n ).
75* Before entry with UPLO = 'U' or 'u', the leading n by n
76* upper triangular part of the array A must contain the upper
77* triangular part of the skew-symmetric matrix and the strictly
78* lower triangular part of A is not referenced.
79* Before entry with UPLO = 'L' or 'l', the leading n by n
80* lower triangular part of the array A must contain the lower
81* triangular part of the skew-symmetric matrix and the strictly
82* upper triangular part of A is not referenced.
83* Note that the imaginary parts of the diagonal elements need
84* not be set and are assumed to be zero.
85* Unchanged on exit.

88* On entry, LDA specifies the first dimension of A as declared
