subroutine convertdec ( integer imax,
integer, dimension(6) idigit )

Convert decimal integer to ASCII digit array.

This subroutine converts a decimal integer to an array of ASCII digit characters. It extracts each digit from the integer and converts it to its corresponding ASCII representation.

Parameters
[in]imaxInput integer to be converted (0 ≤ imax ≤ 999999)
[out]idigitArray of 6 ASCII digit characters (ASCII codes 48-57)

The subroutine performs the following operations:

Algorithm:

  1. Extract the most significant digit (100000s place)
  2. Calculate remainder and extract next digit (10000s place)
  3. Continue for all 6 digits (1000s, 100s, 10s, 1s places)
  4. Convert each digit to ASCII by adding 48 (ASCII '0' = 48)

Digit Extraction:

  • idigit(1): 100000s place (imax/100000)
  • idigit(2): 10000s place (remainder/10000)
  • idigit(3): 1000s place (remainder/1000)
  • idigit(4): 100s place (remainder/100)
  • idigit(5): 10s place (remainder/10)
  • idigit(6): 1s place (final remainder)

ASCII Conversion: Each digit is converted to ASCII by adding 48:

  • 0 → 48 (ASCII '0')
  • 1 → 49 (ASCII '1')
  • ... → ...
  • 9 → 57 (ASCII '9')
Note
The input integer should be in the range [0, 999999].
The output array contains 6 elements regardless of input value.
Leading zeros are preserved in the output array.
This subroutine is commonly used for file naming and string formatting.
