Detailed Description

Fort.11 file I/O operations for TurboRVB.

This module handles reading and writing of fort.11 files, which contain simulation state information for restart and continuation of quantum Monte Carlo calculations.

Author
TurboRVB group
Date
2022

Features

  • Write simulation state to fort.11 for restart capability
  • Read simulation state from fort.11 for continuation
  • Handle various simulation parameters and arrays
  • Support for different simulation modes (VMC, LRDMC, etc.)
  • Compatibility checking between read and current parameters

Files

fort.11 contains:

  • Simulation parameters (nw, np, nmatb, etc.)
  • Walker configurations (wconfn)
  • Correlation weights (wcorw)
  • Kinetic energy derivatives (dek, dekg)
  • Ion velocities (velion)
  • CG optimization data (reduce)
  • Contraction matrices (detmat_proj, projmat_c)

subroutine read_fort11_begin

Read simulation header information from fort.11.

Reads the beginning section of fort.11 file containing simulation parameters, dimensions, and control variables. Performs compatibility checks and handles parameter updates.

Note
Rewinds unit 11 before reading
Reads rmax and rmaxj if scalermax is enabled
Handles adaptive parameter reading (parr, tpar) based on flags
Updates parameters only if iopt = 0 (restart mode)
Initializes tpar buffer if restarting with new tpar
Sets error flag (iflagerr) if read fails
Handles backward compatibility for parameter changes

subroutine write_fort11_begin

Write simulation header information to fort.11.

Writes the beginning section of fort.11 file containing simulation parameters, dimensions, and control variables. This includes walker counts, matrix dimensions, optimization parameters, and convergence criteria.

Note
Rewinds unit 11 before writing
Updates nmatb to nnozero_c for current simulation
Writes rmax and rmaxj for scaling parameters
Conditionally writes parr and tpar arrays if change_parr/change_tpar are enabled
Handles adaptive parameter adjustment for optimization

subroutine write_fort11_end

Write simulation data arrays to fort.11.

Writes the main simulation data arrays to fort.11 file, including walker configurations, correlation weights, kinetic energy derivatives, and optimization data.

Note
Writes different data sets based on itestr value
Handles contraction matrices if contraction > 0
Includes ion velocities for dynamics simulations (itestr = -5)
Writes CG optimization data (reduce array) for parameter optimization
Conditionally writes detmat_proj and projmat_c if allocated
Writes covariance matrix (cov_old) if allocated
