16/**
17 * @brief set default values for memory allocation and program parameters
18 *
19 * this subroutine initializes all global variables and parameters to their
20 * default values before memory allocation in turborvb. it sets up the basic
21 * configuration for quantum monte carlo calculations including optimization
22 * parameters, parallel execution settings, and array dimensions.
23 *
24 * @details
25 * the subroutine sets default values for:
26 * - sparse matrix and optimization flags
27 * - dft and qmc calculation parameters
28 * - parallel execution communicators and ranks
29 * - array dimensions and indices
30 * - optimization parameters and constraints
31 * - pseudopotential and wave function parameters
32 * - file i/o and output control parameters
33 *
34 * key parameters initialized:
35 * - yes_sparse_choose, yes_sparse: sparse matrix optimization flags
36 * - yesdft: dft calculation mode flag
37 * - epscut, epscuttype: energy cutoff parameters
38 * - rank, nproc: mpi parallel execution parameters
39 * - np, npm, npmn: optimization parameter counts
40 * - ieser, iese, isfix: Parameter optimization flags
41 * - npsa, nintpsa: pseudopotential parameters
42 *
43 * @note
44 * - this subroutine should be called before any memory allocation
45 * - parallel execution parameters are set differently for serial/parallel builds
46 * - default values are conservative and suitable for most calculations
47 * - some parameters may be overridden by input file settings
48 *
49 * @see deallocate_all()
50 *
51 * @author turborvb group
52 * @date 2022
53 */

176/**
177 * @brief Deallocate all dynamically allocated arrays and free memory
178 *
179 * this subroutine systematically deallocates all dynamically allocated arrays
180 * used in turborvb calculations. it handles arrays for wave functions,
181 * pseudopotentials, optimization parameters, and various computational arrays.
182 *
183 * @details
184 * the subroutine deallocates arrays in the following categories:
185 * - wave function and orbital arrays (winv, psiln, detmat, etc.)
186 * - jastrow factor arrays(vj, jasmat, etc.)
187 * - pseudopotential arrays(wpseudo, legendre, parshell, etc.)
188 * - optimization parameter arrays(reduce, velion, force, etc.)
189 * - periodic boundary condition arrays(q, g, cosphase, etc.)
190 * - temporary and auxiliary arrays(ipsip, dupr, etc.)
191 *
192 * memory management features:
193 * - safe deallocation with allocated() checks
194 * - conditional deallocation based on calculation type
195 * - proper cleanup of parallel execution arrays
196 * - deallocation of both real and complex arrays
197 *
198 * @note
199 * - this subroutine should be called at the end of calculations
200 * - it prevents memory leaks and frees system resources
201 * - safe to call multiple times due to allocated() checks
202 * - deallocation order is optimized to avoid dependency issues
203 *
204 * @see default_allocate()
205 *
206 * @author turborvb group
207 * @date 2022
208 */
