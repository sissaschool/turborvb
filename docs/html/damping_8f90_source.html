16!> @brief Calculate damping function for quantum chemistry interactions
17!>
18!> This function computes a damping factor used in quantum chemistry
19!> calculations to modify the strength of interactions based on distance
20!> and quantum number. The damping function is based on the work by
21!> G. Scoles et al. in J. Chem. Phys. 76, 3057 (1982).
22!>
23!> @param[in] r Distance parameter (typically interatomic distance)
24!> @param[in] n Quantum number parameter (0 for no damping)
25!> @return damping Damping factor (0 ≤ damping ≤ 1)
26!>
27!> @details
28!> The damping function implements the following formula:
29!>
30!> **For n ≠ 0:**
31!> ```
32!> damping = (1 - exp(-r*2.1/n - 0.109*r²/√n))^n
33!> ```
34!>
35!> **For n = 0:**
36!> ```
37!> damping = 1.0
38!> ```
39!>
40!> **Physical Interpretation:**
41!> - The damping function reduces the strength of interactions at short distances
42!> - The reduction is more pronounced for larger quantum numbers (n)
43!> - The function approaches 1.0 as distance increases
44!> - For n = 0, no damping is applied (damping = 1.0)
45!>
46!> **Parameters:**
47!> - r: Distance parameter (typically in atomic units)
48!> - n: Quantum number that controls the damping strength
49!> - 2.1: Linear damping coefficient
50!> - 0.109: Quadratic damping coefficient
51!>
52!> @note The function is commonly used in van der Waals and dispersion interactions.
53!> @note The damping factor is always in the range [0, 1].
54!> @note For n = 0, the function returns 1.0 regardless of the distance r.
55!> @note The exponential form ensures smooth behavior across all distances.
56function damping(r, n)
57 implicit none
58 real*8 damping, r
59 integer n
60 ! damping=1.d0
61 ! return
62 ! From G. Scoles et al. J. Chem. Phys. 76, 3057 (1982);
63 !> @brief Return unity damping for n = 0 (no damping)
64 if (n .ne. 0) then
65 !> @brief Calculate damping factor using Scoles formula
66 !> @note Based on G. Scoles et al. J. Chem. Phys. 76, 3057 (1982)
67 damping = (1.d0 - dexp(-r*2.1d0/n - 0.109d0*r**2/dsqrt(dble(n))))**n
68 else
69 !> @brief No damping applied for n = 0
70 damping = 1.d0
71 end if
72 return
73end
