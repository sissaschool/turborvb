16!> @file corrforza.f90
17!> @brief Program for computing force correlation functions using bootstrap analysis
18!> @details This program reads energy and derivative data from fort.21 files and computes
19!> force correlation functions using bootstrap resampling. It calculates various correlation
20!> terms including energy derivatives, log derivatives of wave functions, and their products.
21!> The program implements the Pulay correction for force calculations in quantum Monte Carlo.

23!> @brief Main program for force correlation analysis
24!> @details Reads energy and derivative data from multiple fort.21 files, performs bootstrap
25!> resampling to estimate statistical errors, and computes force correlation functions with
26!> Pulay corrections. Outputs correlation values and their statistical uncertainties.
