Detailed Description

Program for copying determinant parameters between TurboRVB wave functions.

This program reads two TurboRVB wave functions (fort.10 and fort.10_new) and copies determinant parameters from one to the other. It handles orbital mapping, parameter scaling, and supports various modes including k-points calculations, ion position copying, and contracted orbital parameter transfer. Similar to copyjas.f90 but for determinant parts.
