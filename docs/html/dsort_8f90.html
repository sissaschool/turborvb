Sorts array X and optionally carries along array Y.

This subroutine sorts array X and optionally makes the same interchanges in array Y. The array X may be sorted in increasing order or decreasing order. A slightly modified QUICKSORT algorithm (Singleton's algorithm) is used. This is a Fortran 77 implementation from the SLATEC library.

Parameters
[in,out]XArray of values to be sorted (usually abscissas)
[in,out]YArray to be optionally carried along with X
[in]NNumber of values in array X to be sorted
[in]KFLAGControl parameter:
  • KFLAG = 2: sort X in increasing order and carry Y along
  • KFLAG = 1: sort X in increasing order (ignoring Y)
  • KFLAG = -1: sort X in decreasing order (ignoring Y)
  • KFLAG = -2: sort X in decreasing order and carry Y along
