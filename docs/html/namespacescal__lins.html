Detailed Description

Module for SCALAPACK linear algebra operations.

Provides subroutines for SCALAPACK environment setup and matrix distribution calculations. Handles parallel matrix operations and processor grid management for distributed linear algebra.

Reshuffle matrix distributed by column to cyclic distribution.

This subroutine reshuffles a matrix divided between the processors by column. The initial configuration is over the first processes in blocks of in_blocks elements and is stored in the elements S of dimension (m,sizei). The final configuration is CYCLIC over num_procs processors and is stored in b(m,sizef).

Parameters
[in]mMatrix size
[in]ldsLeading dimension of s
[in]dimmDimension of output matrix b
[in]dimsDimension of input matrix s
[in]rankProcess rank
[in]in_blocksInput block size
[in]out_procsNumber of output processors
[in]sInput matrix block distributed by column
[out]bOutput matrix with cyclic distribution
[in]commMPI communicator

Solve linear system in parallel using SCALAPACK.

Takes a block distributed matrix s (m,m) of block size in_blocks and distributes it on the mesh of out_procs processors, then solves the linear system associated with the matrix s and the known term solu (input) that is known to all processors. The master process has the solution stored in solu (output).

Parameters
[in]mMatrix size
[in]ldsLeading dimension of s
[in]in_blocksInput block size
[in]rankProcess rank
[in]out_procsNumber of output processors
[in]commLocal communicator
[in]commtotTotal communicator
[in]ictxtBLACS context
[in,out]soluSolution vector (input: known term, output: solution)
[in]sInput matrix block distributed by column
