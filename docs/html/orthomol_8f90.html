program orthomol

Molecular orbital orthogonalization program for TurboRVB.

This program performs orthogonalization of molecular orbitals in a TurboRVB wave function. It reads a fort.10 file, applies orthogonalization procedures, and outputs a new fort.10_new file with orthogonalized orbitals. The program supports both serial and parallel execution modes.
