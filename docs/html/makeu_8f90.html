Generate 3x3 rotation matrix from axis-angle representation.

This subroutine constructs a 3x3 rotation matrix from the axis-angle representation. The rotation is around the axis defined by the unit vector (x,y,z) by an angle alpha.

Parameters
[in]alphaRotation angle in radians
[in]xX-component of rotation axis unit vector
[in]yY-component of rotation axis unit vector
[in]zZ-component of rotation axis unit vector
[out]u3x3 rotation matrix
