Add sine and cosine contributions to sumImgReal array.

This subroutine computes and adds sine and cosine contributions to the sumImgReal array for wave vector summations. It was created by Sandro Sorella on 27th Nov. 2007. The subroutine loops over kx, ky, kz wave vectors and accumulates the contributions to the real and imaginary parts of the sum.

Parameters
[in]zetaScaling factor
[in,out]sumImgRealArray containing real and imaginary parts of the sum
[in]kSqSquare of wave vector cutoff
[in]VkWave vector dependent coefficients
[in]kxbndUpper bound for kx
[in]kybndUpper bound for ky
[in]kzbndUpper bound for kz
[in]vsinSine values for wave vector increments
[in]vcosCosine values for wave vector increments
