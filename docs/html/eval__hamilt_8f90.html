Evaluates Hamiltonian eigenvalues and eigenvectors in non-orthogonal basis.

This subroutine computes the first bands eigenvectors of a Hamiltonian defined in a non-orthogonal basis. It handles ill-conditioned overlap matrices by applying a stable diagonalization algorithm that removes singular eigenvalues and reorthogonalizes eigenvectors. Supports both serial and parallel (SCALAPACK) execution with different algorithms for each case.

45 ! This subroutine was written by Sandro Sorella and Carlo Cavazzoni
46 ! 14 November 2008. Revised 20 January 2008
47 !
48 ! The task of this subroutine is to compute in a stable way the first
49 ! bands= (~# electrons/2) eigenvectors of an Hamiltonian defined in
50 ! a non orthogonal basis of linear dimension nelorb_c>>bands.
51 ! The overlap matrix input matrix elements
52 ! being oversav and the corresponding hamiltonian matrix elements matsav.
53 ! These matrices are not destroyed on output.
54 ! The problem is that the matrix oversav may have a very small condition
55 ! number and straighforward diagonalization using scalapack PDSYGVX
56 ! leads to inaccurate and often garbage eigenvectors.
57 ! In parallel computation there is also the further complication that
58 ! it is difficult to preserve orthogonality (and accuracy) of eigenvectors
59 ! without having a huge buffer memory at disposal, as no memory
60 ! distribution is possible in order to orthogonalize.
61 ! The parallel code is therefore slightly different from the scalar one.
62 ! #########################################################################
63 ! Scalar algorithm:
64 ! 1) Diagonalize the full overlap matrix with maximum accuracy
65 ! (ABSTOL=2.*dlamch('S')), compute eigenvalies eig(i) and eigenvectors umat).
66 ! After removing the singular eigenvalues recompute and reorthoganilize
67 ! them exactly as is done in the parallel algorithm.
68 ! 2) Recompute the matrix elements of the Hamiltonian in the new
69 ! orthogonal basis by taking only the vectors {i} with eigenvalues
70 ! eig(i)/eig_max < epsr (input). So that the new overlap matrix
71 ! has by definition condition number > eps.
72 ! 3) Now the diagonalization of the matrix in the new basis can be done
73 ! because it is a well conditioned matrix as
74 ! the eigenvalues are the physical eigenvalues of the Hamiltonian.
75 ! 4) Go back in the original basis for the eigenvectors computed.
76 ! #########################################################################
77 ! PARALLEL algorithm (Using SCALAPACK version...):
78 ! 1) Apply Cavazzoni's diagonalization to the overlap matrix.
79 ! Disregard eigenvalues of the overlap matrix with
80 ! eig(i)/eig_max < eps.
81 ! This is justified from the fact that an eigenvector of the
82 ! overlap matrix with nearly zero eigenvalue corresponds to
83 ! a linear combination of states in the original basis with
84 ! vanishing norm, i.e. the non orthogonal basis is redundant and
85 ! this direction can be eliminated within numerical accuracy<sqrt(eps).
86 ! In this step we do not require neither orthogonality between
87 ! the selected eigenvectors nor maximum accuracy.
88 ! However the accuracy has to be sufficient to guarantee that
89 ! the eigenvectors are at least linearly independent.
90 ! In a second step we diagonalize again the overlap matrix in
91 ! this basis without the singular vectors corresponding to the
92 ! disregarded eigenvalues. Since in this basis
93 ! the matrix has very good condition number, we can assume that
94 ! the Cavazzoni's diagonalization routine provides a very accurate
95 ! orthonormal basis set. Then we store in umatl the transformation
96 ! between the original basis and the orthogonal one.
97 ! This step is done only at the inizialization (iopt=1) and umatl is
98 ! saved, and used for all further iterations (iopt=0).
99 ! 2) At each iteration recompute the hamiltonian matrix H
100 ! in this new basis.
101 ! 3) Then apply again the Cavazzoni's diagonalization routine.
102 ! Computation and memory requirements are minimal.
103 ! 4) Go back to the original basis for the eigenvectors computed at
104 ! each iteration.
