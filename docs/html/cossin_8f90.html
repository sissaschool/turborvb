Computes cosine and sine values for plane wave evaluation.

This subroutine calculates nk pairs of cosine and sine values for a particle located at position x. It evaluates plane wave contributions exp(i*k*r) = cos(k*r) + i*sin(k*r) for correlation function calculations. Supports 1D, 2D, and 3D systems.

Parameters
[in]xParticle position coordinates
[out]spArray containing cosine and sine values (n2, nk)
[in]n2Dimension of sp array (should be 2 for cos/sin pairs)
[in]nkNumber of wave vectors
[in]ndimDimension of coordinate space
[in]rkcompWave vector components (ndim, nk)
[in]ddimPhysical dimension of the system (1, 2, or 3)
[in]vdimVector dimensions for coordinate mapping
