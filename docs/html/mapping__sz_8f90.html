Calculate mapping function for distance-dependent interactions.

This function computes a mapping function based on the minimum distance to ions, excluding ghost atoms (zeta=0). The mapping provides a distance-dependent scaling factor for interactions.

Parameters
[in]nionNumber of ions
[in]distArray of distances to ions
[in]zetaArray of ion charges/weights
[in]bMapping parameter b
[in]cMapping parameter c
[out]iminIndex of ion with minimum distance
[out]imaxIndex of ion with maximum distance
Returns
mapping Mapping function value
