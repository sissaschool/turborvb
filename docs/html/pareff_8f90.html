Detailed Description

Parameterization system for Jastrow factors and determinant matrices.

This module provides the core parameterization system for TurboRVB's variational wave function optimization. It handles the mapping between physical parameters (distances between particles) and variational parameters for Jastrow factors and determinant matrices. The system supports various parameterization schemes including power-law expansions, logarithmic forms, and constant parameterization with distance-dependent basis functions.

Note
The parameterization distinguishes between Jastrow parameters (rpar > 0) and determinant parameters (rpar < 0) based on the sign of input distances.

Main parameterization routine for variational parameters.

Parameters
npar

Constructs the parameterization matrix that maps physical distances to variational parameters for Jastrow factors and determinant matrices. Handles three types of parameterization: spin Jastrow (inv), density-density Jastrow (regular), and determinant parameters (sw). Supports multiple parameterization schemes including power-law expansions, logarithmic forms, and constant parameterization with distance-dependent basis functions.

Parameters
[in]nparNumber of density-density Jastrow parameters
[in]initpowerInitial power for density-density Jastrow parameterization
[in]nparswNumber of determinant parameters
[in]initpowerswInitial power for determinant parameterization
[in]nparinvNumber of spin Jastrow parameters
[in]initpowerinvInitial power for spin Jastrow parameterization
[in]endinvEnd index for spin Jastrow parameters
[in]nleadLeading dimension of reduce matrix
[in]kp_ionNumber of ion pairs
[in]rparPhysical distances between particles (positive for Jastrow, negative for det)
[out]reduceParameterization matrix (npar+nparsw+nparinv, kp_ion)
[in]jas_invariantJastrow invariants for orbital-dependent terms
[in]adrlambdaAddress mapping for lambda parameters
[in]nmax_ionMaximum number of ion types
[in]type_atomAtom type assignments
[in]allfitWhether to fit all atom type combinations
[in]orbpsOrbital pairing information
Note
The routine handles different parameterization schemes based on initpower values:
  • initpower > 0: Power-law expansion r^(-power)
  • initpower = 0: Logarithmic form log(r)
  • initpower = -1: Constant parameterization with distance-dependent basis
  • initpower < -1: Advanced parameterization with orbital-dependent terms
