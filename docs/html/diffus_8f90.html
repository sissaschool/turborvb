Calculate diffusion coefficient for real wave function.

This subroutine computes the diffusion coefficient for the quantum Monte Carlo walkers. It evaluates the quantity that should be exactly one for perfect short-time diffusion.

Parameters
[in]nelNumber of electrons
[in]indtNumber of time steps
[in]gammaDiffusion parameter
[in]ivicVelocity array (3, indt, nel)
[in]tableWave function table
[out]funDiffusion coefficient
[in]istartStarting index for calculation
