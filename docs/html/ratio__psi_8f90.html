Compute regularization values for wave function ratio.

This function computes several values related to regularization which is defined as \psi_g(x)=R_\epsilon(x)*[\psi_T(x)/R(x)]. R_\epsilon(x) is explicitly expressed here as Max(\epsilon, R(x)).

Parameters
[in]RoldOld value of R(x) function computed in ratiovar() as ratiodetr
[in]RnewNew (proposed move) value of R(x) function
[in]parcutRegularization parameter (cutoff value)
[out]ratioregNew R_\epsilon(x) / old R_\epsilon(x)
[out]reweight[new \psi_T(x) / new \psi_g(x)]^2
[in]epstlPrecision control parameter (if zero not used)
