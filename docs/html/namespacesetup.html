Detailed Description

Setup module for DFT calculations in TurboRVB.

This module contains all the setup parameters, variables, and subroutines needed for DFT calculations. It manages input parameters, real-space integration mesh, k-points, main matrices, and various computational flags. The module provides initialization routines and utilities for self-consistent field calculations.
