Performs linear fitting with weighted least squares.

This subroutine performs linear fitting using weighted least squares method. It computes the slope and intercept of a linear function that best fits the data points.

Parameters
[in]zIndependent variable array
[in]yDependent variable array
[in]erError weights array
[in]nNumber of data points
[out]stotTotal sum of weighted squares
[out]aSlope of the linear fit
[out]cIntercept of the linear fit
