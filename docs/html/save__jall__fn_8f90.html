Jastrow factor support vector update for DMC and LR-DMC.

This subroutine updates the support vector jastrowall_ee used in Diffusion Monte Carlo (DMC) and Lattice Regularized DMC (LR-DMC) calculations. The updated vector is used by the fast update routine "uptabtot_new.f90" to speed up Jastrow factor calculations.

The subroutine handles both 3/4-body Jastrow factors and wave function components, with support for spin-dependent calculations and OpenMP offloading for GPU acceleration.

Parameters
[in]yesfnFlag indicating whether to update gradients and Laplacians
[in,out]jastrowall_eeSupport vector for Jastrow factor calculations
[in]winvjbarJastrow factor basis coefficients for up electrons
[in]winvjbarszJastrow factor basis coefficients for spin-dependent terms
[in]winvjJastrow factor basis vectors
[in,out]psipWorking array for matrix operations

The subroutine performs the following operations:

  1. Initializes working array psip to zero
  2. If yesfn is true, updates gradients and Laplacians:
    • Processes 3/4-body terms (k = 1 to ip4)
    • Processes lattice terms (k = 1 to indt)
    • Uses matrix multiplication to compute Jastrow contributions
    • Handles both up and down electron components
    • Updates spin-dependent terms if iessz is true
  3. Updates wave function components:
    • Computes Jastrow factor contributions to wave function
    • Handles both up and down electron components
    • Updates spin-dependent terms if iessz is true
Note
The 2-body part of jastrowall_ee is computed in "compute_fast.f90"
The subroutine supports OpenMP offloading for GPU acceleration
Handles both paired (ipj=1) and unpaired (ipj=2) electron configurations
Spin-dependent calculations are performed when iessz is true
Used in DMC and LR-DMC calculations for efficient Jastrow updates
