Symmetrizes real matrix to reduce roundoff errors.

This subroutine symmetrizes a real matrix by averaging the matrix with its transpose. Supports both serial and parallel (SCALAPACK) execution. Used to reduce roundoff errors in overlap and Hamiltonian matrices.

Parameters
[in]nMatrix dimension
[in]ldLeading dimension of the matrix
[in,out]mat_inInput matrix to be symmetrized (overwritten)
