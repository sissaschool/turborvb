Fills SCALAPACK block matrix with real data from grid calculations.

This subroutine updates a block matrix in SCALAPACK format using real data from molecular orbital grid calculations. It performs matrix multiplication using BLAS routines and handles parallel reduction across MPI processes.

Parameters
[in]mat_inInput matrix to be updated
[in]bufferBuffer array containing molecular orbital values
[in]nelorbLeading dimension of the buffer array
[in]buffer_weightWeight buffer array
[in]nelorb_wLeading dimension of the weight buffer
[in]bufbufNumber of buffered grid points
[in]irc_ipRow indices for processor grid
[in]nrc_ipNumber of rows per processor
[in]rank_ipRank mapping for processor grid
[in]nlaxLeading dimension of the block matrix
[in]adr_bufAddress offset for buffer access
