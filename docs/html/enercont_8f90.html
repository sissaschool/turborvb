Calculate energy contribution from wave function derivatives.

This function computes the energy contribution from the Laplacian and gradient terms of the wave function for both up and down electrons. It combines terms from winv (inverse matrix) and tabpip (derivatives).

Parameters
[in]indtIndex offset for derivatives
[in]nelupNumber of up electrons
[in]neldoNumber of down electrons
[in]winvupInverse matrix for up electrons
[in]winvdoInverse matrix for down electrons
[in]tabpipWave function derivatives table
Returns
enercont Energy contribution from derivatives
