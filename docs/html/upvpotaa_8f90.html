Calculate ion-ion potential energy with Ewald summation.

This function computes the ion-ion electrostatic potential energy using either direct Coulomb interaction (for isolated systems) or Ewald summation (for periodic boundary conditions). The calculation includes both the real-space and self-interaction contributions.

Parameters

ZETA : real*8 array, in Array of ion charges (NION). IOND : real*8 array, in Matrix of ion-ion distances (NION × NION). NION : integer, in Number of ions in the system. KAPPA : real*8, in Ewald parameter for splitting the Coulomb interaction. LBOX : real*8, in Box length for periodic boundary conditions. If LBOX ≤ 0: isolated system (direct Coulomb). If LBOX > 0: periodic system (Ewald summation).

Returns

real*8 Total ion-ion potential energy including self-interaction correction.

Notes

  • For isolated systems (LBOX ≤ 0): uses direct Coulomb interaction.
  • For periodic systems (LBOX > 0): uses Ewald summation with:
    • Real-space contribution using complementary error function.
    • Self-interaction correction to avoid double-counting.
  • Includes nearest-neighbor interactions for periodic systems.
  • Uses SIMD vectorization for performance optimization.
  • The self-interaction term is: -2*κ*ε₀/√π * Σ(zeta²).

Algorithm

For isolated systems: E = Σᵢⱼ 2*zeta(i)*zeta(j)*veps(iond(i,j))

For periodic systems: E_real = Σᵢⱼ 2*zeta(i)*zeta(j)*erfc(κ*rᵢⱼ)/rᵢⱼ E_self = -2*κ*ε₀/√π * Σ(zeta²) E_total = E_real + E_self
