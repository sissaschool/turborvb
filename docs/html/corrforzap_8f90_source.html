17!> @brief Program for computing simplified force correlation functions using bootstrap analysis
18!> @details This program reads energy and derivative data from fort.21 files and computes
19!> simplified force correlation functions using bootstrap resampling. It calculates the
20!> Pulay correction term 2*(<OH> - <O><H>) where O is the log derivative of the wave function

23!> @brief Main program for simplified force correlation analysis

25!> resampling to estimate statistical errors, and computes the simplified force correlation
