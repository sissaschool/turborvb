49* Purpose
50* =======
51*
52* ZSKTRD reduces a complex skew-symmetric matrix A to real skew-symmetric
53* tridiagonal form T by a unitary congruence transformation:
54* Q^H * A * Q^* = T. Alternatively, the routine can also compute
55* a partial tridiagonal form useful for computing the Pfaffian.
56*
57* Arguments
58* =========
59*
60* UPLO (input) CHARACTER*1
61* = 'U': Upper triangle of A is stored;
62* = 'L': Lower triangle of A is stored.
63*
64* MODE (input) CHARACTER*1
65* = 'N': A is fully tridiagonalized
66* = 'P': A is partially tridiagonalized for Pfaffian computation
67* (details see below)
68*
69* N (input) INTEGER
70* The order of the matrix A. N >= 0. N must be even if MODE = 'P'.
71*
72* A (input/output) DOUBLE COMPLEX array, dimension (LDA,N)
73* On entry, the skew-symmetric matrix A.
74* If UPLO = 'U', the leading N-by-N upper triangular part
75* of A contains the upper triangular part of the matrix A,
76* and the strictly lower triangular part of A is not referenced.
77* If UPLO = 'L', the leading N-by-N lower triangular part
78* of A contains the lower triangular part of the matrix A,
79* and the strictly upper triangular part of A is not referenced.
80* On exit, if MODE = 'N':
81* If UPLO = 'U', the diagonal and first superdiagonal
82* of A are overwritten by the corresponding elements of the
83* tridiagonal matrix T, and the elements above the first
84* superdiagonal, with the array TAU, represent the unitary
85* matrix Q as a product of elementary reflectors;
86* If UPLO = 'L', the diagonal and first subdiagonal of A are over-
87* written by the corresponding elements of the tridiagonal
88* matrix T, and the elements below the first subdiagonal, with
89* the array TAU, represent the unitary matrix Q as a product
90* of elementary reflectors.
91* See Further Details, also for information about MODE = 'P'.
92*
93* LDA (input) INTEGER
94* The leading dimension of the array A. LDA >= max(1,N).
95*
96* E (output) DOUBLE PRECISION array, dimension (N-1)
97* The off-diagonal elements of the tridiagonal matrix T:
98* E(i) = A(i,i+1) if UPLO = 'U', E(i) = A(i+1,i) if UPLO = 'L'.
99* If MODE = 'P', only the entries at i odd are well-defined
100* (see Further Details)
101*
102* TAU (output) DOUBLE COMPLEX array, dimension (N-1)
103* The scalar factors of the elementary reflectors (see Further
104* Details).
105*
106* WORK (workspace/output) DOUBLE COMPLEX array, dimension (MAX(1,LWORK))
107* On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
108*
109* LWORK (input) INTEGER
110* The dimension of the array WORK. LWORK >= 1.
111* For optimum performance LWORK >= N*NB, where NB is the
112* optimal blocksize.
113*
114* If LWORK = -1, then a workspace query is assumed; the routine
115* only calculates the optimal size of the WORK array, returns
116* this value as the first entry of the WORK array, and no error
117* message related to LWORK is issued by XERBLA.
118*
119* INFO (output) INTEGER
120* = 0: successful exit
121* < 0: if INFO = -i, the i-th argument had an illegal value
122*
123* Further Details
124* ===============
125*
126* The normal use for ZSKTRD is to compute the tridiagonal form of
127* a skew-symmetric matrix under an orthogonal similarity transformation,
128* and chosen by setting MODE = 'N' ("normal" mode). The other
129* use of ZSKTRD is the computation the Pfaffian of a skew-symmetric matrix,
130* which only requires a partial tridiagonalization, this mode is chosen
131* by setting MODE = 'P' ("Pfaffian" mode).
132*
133* Normal mode (MODE = 'N'):
134* ========================
135*
136* The routine computes a tridiagonal matrix T and an orthogonal Q such
137* that A = Q * T * Q^T .
138*
139* If UPLO = 'U', the matrix Q is represented as a product of elementary
140* reflectors
141*
142* Q = H(n-1) . . . H(2) H(1).
143*
144* Each H(i) has the form
145*
146* H(i) = I - tau * v * v'
147*
148* where tau is a complex scalar, and v is a complex vector with
149* v(i+1:n) = 0 and v(i) = 1; v(1:i-1) is stored on exit in
150* A(1:i-1,i+1), and tau in TAU(i).
151*
152* If UPLO = 'L', the matrix Q is represented as a product of elementary
153* reflectors
154*
155* Q = H(1) H(2) . . . H(n-1).
156*
157* Each H(i) has the form
158*
159* H(i) = I - tau * v * v'
160*
161* where tau is a complex scalar, and v is a complex vector with
162* v(1:i) = 0 and v(i+1) = 1; v(i+2:n) is stored on exit in A(i+2:n,i),
163* and tau in TAU(i).
164*
165* The contents of A on exit are illustrated by the following examples
166* with n = 5:
167*
168* if UPLO = 'U': if UPLO = 'L':
169*
170* ( 0 e v2 v3 v4 ) ( 0 )
171* ( 0 e v3 v4 ) ( e 0 )
172* ( 0 e v4 ) ( v1 e 0 )
173* ( 0 e ) ( v1 v2 e 0 )
174* ( 0 ) ( v1 v2 v3 e 0 )
175*
176* where d and e denote diagonal and off-diagonal elements of T, and vi
177* denotes an element of the vector defining H(i).
178*
179* The LAPACK routine ZUNGTR can be used to form the transformation
180* matrix explicitely, and ZUNMTR can be used to multiply another
181* matrix without forming the transformation.
182*
183* Pfaffian mode (MODE = 'P'):
184* ==========================
185*
186* For computing the Pfaffian, it is enough to bring A into a partial
187* tridiagonal form. In particular, assuming n even, it is enough to
188* bring A into a form with A(i,j) = A(j,i) = 0 for i > j+1 with j odd
189* (this is computed if UPLO = 'L'), or A(i,j) = A(j,i) = 0 for
190* i > j-1 with j even (this is computed if UPLO = 'U'). Note that
191* only the off-diagonal entries in the odd columns (if UPLO = 'L')
192* or in the even columns (if UPLU = 'U') are properly computed by ZSKTRD.
193*
194* A is brought into this special form pT using an orthogonal matrix Q:
195* A = Q * pT * Q^T
196*
197* If UPLO = 'U', the matrix Q is represented as a product of elementary
198* reflectors
199*
200* Q = H(n-1) H(n-3) . . . H(3) H(1).
201*
202* Each H(i) has the form
203*
204* H(i) = I - tau * v * v^T
205*
206* where tau is a complex scalar, and v is a complex vector with
207* v(i+1:n) = 0 and v(i) = 1; v(1:i-1) is stored on exit in
208* A(1:i-1,i+1), and tau in TAU(i).
209*
210* If UPLO = 'L', the matrix Q is represented as a product of elementary
211* reflectors
212*
213* Q = H(1) H(3) . . . H(n-3) H(n-1).
214*
215* Each H(i) has the form
216*
217* H(i) = I - tau * v * v^T
218*
219* where tau is a complex scalar, and v is a complex vector with
220* v(1:i) = 0 and v(i+1) = 1; v(i+2:n) is stored on exit in A(i+2:n,i),
221* and tau in TAU(i).
222*
223* The contents of A on exit are illustrated by the following examples
224* with n = 6:
225*
226* if UPLO = 'U': if UPLO = 'L':
227*
228* ( 0 e x v3 x v5 ) ( 0 )
229* ( 0 x v3 x v5 ) ( e 0 )
230* ( 0 e x v5 ) ( v1 x 0 )
231* ( 0 x v5 ) ( v1 x e 0 )
232* ( 0 e ) ( v1 x v3 x 0 )
233* ( 0 ) ( v1 x v3 x e 0 )
234*
235* where d and e denote diagonal and off-diagonal elements of T, vi
236* denotes an element of the vector defining H(i), and x denotes an
237* element not computed by ZSKTRD.
