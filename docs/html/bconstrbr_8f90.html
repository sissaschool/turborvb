Translates constrained Jastrow parameter changes to unconstrained representation.

This subroutine handles the transformation of constrained Jastrow parameter changes back to their original unconstrained representation. It is specifically designed for handling real wave functions and 3-body Jastrow terms.

The subroutine performs the following operations:

  1. Maps constrained Jastrow parameters to their original positions using jbraj array
  2. Handles real wave functions only (simplified version of bconstrbr_complex)
  3. Supports sign-flipped parameter mapping for constraint handling
  4. Specifically designed for 3-body Jastrow correlation functions

The algorithm uses a mapping array jbraj to translate between constrained and unconstrained parameter spaces, where:

  • Positive values: direct mapping from ddw to derjas
  • Negative values: sign-flipped mapping from ddw to derjas

This is the real-valued counterpart to bconstrbr_complex, optimized for cases where complex arithmetic is not required.

Parameters
[in]iesfreerSwitch flag for constraint handling (0: no constraints, >0: apply constraints)
[in]n3bodyNumber of 3-body Jastrow parameters
[in]jbrajMapping array from constrained to unconstrained Jastrow parameters
[out]derjasOutput array for unconstrained Jastrow derivatives
[in]ddwInput array of constrained parameter changes
Note
If iesfreer = 0, the subroutine returns immediately without any operations
Warning
The subroutine assumes that ddw array contains valid constrained parameter values
Algorithm Details:
The subroutine implements simple parameter mapping for real wave functions:
  1. Direct Mapping: For positive jbraj values, copy ddw(j) to derjas(i)
  2. Sign-Flipped Mapping: For negative jbraj values, copy -ddw(-j) to derjas(i)
Parameter Mapping:
  • Positive jbraj values: derjas(i) = ddw(j)
  • Negative jbraj values: derjas(i) = -ddw(-j)
3-Body Jastrow Terms:
This subroutine is specifically designed for 3-body Jastrow correlation functions, which describe electron-electron-electron correlations in quantum Monte Carlo calculations. The n3body parameter specifies the number of such terms.
Performance Considerations:
This real-valued version is more efficient than bconstrbr_complex for real wave functions as it avoids unnecessary complex arithmetic operations.
