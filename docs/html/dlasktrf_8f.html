43*
44* DLASKTRF computes NB steps of the factorization of a skew-symmetric
45* matrix A using the Parlett-Reid algorithm:
46*
47* P*A*P^T = U*T*U^T or P*A*P^T = L*T*L^T
48*
49* If UPLO = 'U', DLASKTRF reduces the last NB rows and columns of a
50* matrix, of which the upper triangle is supplied;
51* if UPLO = 'L', DLASKTRF reduces the first NB rows and columns of a
52* matrix, of which the lower triangle is supplied.
53*
54* Alternatively, the routine can also be used to compute a partial
55* tridiagonal form
56*
57* This is an auxiliary routine called by DSKTRF.

59* Arguments

66* = 'L': Lower triangular
