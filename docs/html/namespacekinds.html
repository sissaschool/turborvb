Detailed Description

Data type definitions and information module for TurboRVB.

This module defines precision parameters for real and integer data types used throughout the TurboRVB code. It provides consistent precision across different platforms and compilers.

The module defines:

  • DP: Double precision real (14 digits, 200 exponent range)
  • sgl: Single precision real (6 digits, 30 exponent range)
  • i4b: 32-bit integer (9 digits)

It also provides a subroutine to print detailed information about the data types for debugging and verification purposes.

Note
The subroutine prints information for:
  • DP (double precision): precision, epsilon, tiny, huge values

  • INTEGER: kind value, bit size, largest representable number
