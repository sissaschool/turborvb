Computes inverse of symmetric positive definite matrix using SVD.

This subroutine computes the inverse of a symmetric positive definite matrix using singular value decomposition (SVD). It eliminates singular directions with eigenvalues smaller than the condition number threshold to ensure numerical stability. Supports both serial and parallel (SCALAPACK) execution. The input matrix is assumed to be positive definite and is overwritten with its inverse.

Parameters
[in]nOrder of the matrix
[in,out]aInput matrix to be inverted (overwritten with inverse)
[in]ldaLeading dimension of array a
[out]infoStatus flag (0 for success)
[in]epsrCondition number threshold for eigenvalue filtering
[out]mineNumber of neglected singular directions
[in]rankRank of current MPI process
[in]epssrOptional shift parameter for diagonal elements
[in]bandsNumber of bands (for SCALAPACK)
[in]nlaxLeading dimension for SCALAPACK arrays
