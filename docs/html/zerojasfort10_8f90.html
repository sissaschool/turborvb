program zerojasfort10

Jastrow factor zeroing program for TurboRVB.

This program reads a TurboRVB wave function (fort.10) and selectively zeros Jastrow factors while preserving the wave function structure. It can zero both charge and spin-dependent Jastrow factors, with an option to preserve one-body terms. The program outputs a new fort.10_new file with the modified Jastrow parameters.

The program supports two modes:

  • Normal mode: zeros all Jastrow factors
  • leave1body mode: preserves one-body Jastrow terms
