Assemble the complete Pfaffian matrix from AGP and skew-symmetric parts.

This subroutine combines the AGP (antisymmetrized geminal power) and skew-symmetric parts to create the complete Pfaffian matrix. It handles different configurations based on the presence of up and down Pfaffian components.

The subroutine handles:

  • AGP matrix elements (recordsymagp)
  • Skew-symmetric matrix elements (recordsymskw)
  • Up/down Pfaffian configurations
  • Orbital indexing for spin-up and spin-down components
Parameters
[in]norbNumber of orbitals
[in]nrotNumber of rotation symmetries
[in]ntraNumber of translation symmetries
[out]occupiedLogical matrix indicating allowed matrix elements
[in]recordsymagpSymmetry records for AGP matrix elements
[in]lenrecagpLength of each AGP symmetry record
[in]recordsymskwSymmetry records for skew-symmetric matrix elements
[in]lenrecskwLength of each skew-symmetric symmetry record
[out]recordsymCombined symmetry records for Pfaffian matrix
[out]lenrecLength of each combined symmetry record
[in,out]nrecNumber of combined records (input: max, output: actual)
[in]nrecagpNumber of AGP records
[in]nrecskwNumber of skew-symmetric records
[in]nouppfaffLogical flag for up Pfaffian
[in]nodownpfaffLogical flag for down Pfaffian
[in]opposite_phaseLogical flag for opposite phase treatment

Generate symmetry-equivalent matrix elements for skew-symmetric part of Pfaffian.

This subroutine generates symmetry-equivalent matrix elements for the skew-symmetric part of the Pfaffian matrix. It applies rotation and translation symmetries to identify equivalent orbital pairs and groups them into records for efficient computation.

The subroutine handles:

  • Rotation symmetries (symrot)
  • Translation symmetries (symtra)
  • Skew-symmetric constraints (i < j)
  • Hermitian treatment for boundary conditions
  • Phase locking for long bonds
Parameters
[in]norbNumber of orbitals
[in]symrotRotation symmetry matrix (norb, nrot)
[in]nrotNumber of rotation symmetries
[in]symtraTranslation symmetry matrix (norb, ntra)
[in]ntraNumber of translation symmetries
[out]occupiedLogical matrix indicating allowed matrix elements
[out]recordsymSymmetry records for matrix elements
[out]lenrecLength of each symmetry record
[in,out]nrecNumber of records (input: max, output: actual)
[in]ipsipTemporary array for symmetry operations
[in]rionAtomic positions (3, ntotatoms)
[in]ntotatomsTotal number of atoms
[in]orb2atomMapping from orbitals to atoms
[in]cellscaleCell dimensions
[in]depsNumerical tolerance for comparisons
[in]zetaZeta parameters for atoms (2, ntotatoms)
[in]yes_hermiteLogical flag for Hermitian treatment
