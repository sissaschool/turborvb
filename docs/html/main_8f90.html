subroutine main::update_projm

Update projection matrix for complex or real wave functions.

This subroutine updates the projection matrix (projm) by performing matrix multiplication between mu_c and detmat_c matrices. It handles both complex and real wave functions using appropriate BLAS routines (zgemm_ or dgemm_). The operation is optimized for GPU offloading when _OFFLOAD is defined.

Parameters
None(uses module variables)
