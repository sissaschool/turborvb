Detailed Description

Symmetric (Hermitian) matrix inversion and trace utilities.

This module provides routines for inverting symmetric or Hermitian matrices using eigenvalue decomposition, as well as utility functions for computing traces and trace-like quantities for real and complex matrices.

Author
TurboRVB group
Date
2022

Features

  • Robust inversion of symmetric/Hermitian matrices with eigenvalue thresholding
  • Handles both real and complex matrices (ipc=1 or 2)
  • Computes traces and trace-like quantities for matrix products
  • Parallelization support (MPI)

Invert a symmetric (Hermitian) matrix using eigenvalue decomposition.

Computes the inverse of a symmetric (real or complex Hermitian) matrix by diagonalizing and thresholding small eigenvalues. Handles both real and complex cases, and supports parallel execution with MPI.

Parameters
[in]ipc1 for real, 2 for complex
[in]nMatrix dimension
[in,out]aMatrix to invert (overwritten with inverse)
[in]ldaLeading dimension of a
[out]infoError flag (0=success)
[in]epsEigenvalue threshold for inversion
[out]mineNumber of excluded eigenvalues
[out]umatEigenvector matrix
[out]eigmatEigenvalues (and their inverses)
[in]nprocNumber of MPI processes
[in]rankMPI rank
[in]comm_mpiMPI communicator
Note
Uses DSYEV_MY or ZSYEV_MY for diagonalization
Eigenvalues below eps are excluded from inversion
Writes warnings for small or negative eigenvalues
Returns inverse in-place in a
