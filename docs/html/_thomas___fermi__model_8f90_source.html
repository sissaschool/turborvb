16!> @brief Thomas-Fermi model implementation for electron density calculations
17!>
18!> This module provides functions for calculating electron density distributions
19!> using the Thomas-Fermi model, which is a semi-classical approximation for
20!> atomic electron density. It is particularly useful for determining core and
21!> valence electron distributions in quantum Monte Carlo calculations.
22!>
23!> The module implements the Thomas-Fermi model according to standard textbooks
24!> and provides numerical integration capabilities for calculating electron
25!> numbers within specified cutoff radii.
26!>
27!> @author Kosuke Nakano 2019
28!> @affiliation SISSA
29!> @email kousuke_1123@icloud.com
30!> @created 13 Dec. 2019
31!> @modified 13 Feb. 2020 - Improved integration accuracy
32!>
33!> @details
34!> The Thomas-Fermi model provides an approximate description of electron density
35!> in atoms based on the following equations:
36!> - b = (9 * π² / 128)^(1/3)
37!> - r_TF = b * Z^(-1/3)
38!> - x_TF = r / r_TF
39!> - ρ(r) = (32 * Z²) / (9 * π³) * (χ(x_TF) / x_TF)^(3/2)
40!> where χ(x) is the Gross-Dreizler function.
41!>
42!> @note Used in quantum Monte Carlo calculations for pseudopotential generation
43!> @note Provides core/valence electron separation for double-grid schemes

55 !> @brief Calculate core electron number using Thomas-Fermi model
56 !>
57 !> This function calculates the number of electrons inside a cutoff radius r_c
58 !> according to the Thomas-Fermi model. It performs numerical integration of
59 !> the electron density multiplied by a Gaussian function p(r) that separates
60 !> core and valence electrons.
61 !>
62 !> @param[in] atomic_number Atomic number Z of the element
63 !> @param[in] r_c Cutoff radius for core electron definition (atomic units)
64 !> @return Number of core electrons within r_c
65 !>
66 !> @details
67 !> The function implements the following algorithm:
68 !> 1. Calculates Thomas-Fermi radius: r_TF = b * Z^(-1/3)
69 !> 2. Defines Gaussian function: p(r) = exp(-r²/(2*r_c²))
70 !> 3. Performs numerical integration:
71 !> - Core electrons: ∫ 4πr² ρ(r) p(r) dr
72 !> - Valence electrons: ∫ 4πr² ρ(r) (1-p(r)) dr
73 !> 4. Uses Gross-Dreizler approximation for χ(x) function
74 !>
75 !> @note Integration range: r_min = 1.0d-3 to r_max = 25.0d0
76 !> @note Integration step: dr = 1.0d-3
77 !> @note Used in pseudopotential generation and core-valence separation
78 ! function Thomas_Fermi_core_electron_number(atomic_number, r_c)
79 ! to calculate the number of electrons inside r_c according to the Thomas-Fermi model.
80 ! According to the textbook written in Takada (it can be also obtained from the Landau textbook),
81 ! The number of electron inside rc is represented as
82 ! b = (9 * np.pi ** 2 / 128) ** (1.0 / 3.0)
83 ! r_TF = b * Z ** (-1.0 / 3.0)
84 ! x_TF = r / r_TF
85 ! rho_r = (32 * Z ** 2) / (9 * np.pi ** 3) * (Gross_Dreizler(x_TF) / x_TF) ** (3.0 / 2.0)
86 ! p_r = exp(-r** 2.0 / 2.0 / rc ** 2.0) # function p(r) in the double-grid scheme
87 ! num_ele_core = integral (4 * np.pi * r ** 2 * rho_r * p_r) * dr
88 ! num_ele_val = integral (4 * np.pi * r ** 2 * rho_r * (1-p_r)) * dr
89
90 function thomas_fermi_core_electron_number(atomic_number, r_c) result(num_core_electron)
91
92 real(8), intent(in) :: atomic_number, r_c
93 real(8) num_core_electron, num_val_electron
94 real(8) r_tf, x_tf, b, pi, rho_r, p_r
95 real(8) :: r = 0.0d0, r_min = 1.0d-3, r_max = 25.0d0, dr = 1.0d-3
96
97 ! define constant
98 pi = 3.1415926535d0
99 b = (9*pi**2/128)**(1.0d0/3.0d0)
100 r_tf = b*atomic_number**(-1.0/3.0)
101
102 ! results
103 num_core_electron = 0.0d0
104 num_val_electron = 0.0d0
105
106 ! integral
107 r = r_min
108 do while (r .lt. r_max)
109 x_tf = r/r_tf
110 rho_r = (32.0d0*atomic_number**2.0d0)/(9.0d0*pi**3.0d0)*(gross_dreizler(x_tf)/x_tf)**(3.0d0/2.0d0)
111 p_r = dexp(-r**2.0d0/2.0d0/r_c**2.0d0)
112 num_core_electron = num_core_electron + (4.0d0*pi*r**2.0d0*rho_r*p_r)*dr
113 num_val_electron = num_val_electron + (4.0d0*pi*r**2.0d0*rho_r*(1.0d0 - p_r))*dr
114 r = r + dr
115 ! write(6,*) "r = ", r
116 end do
117
118 ! output result (test)
119 ! write(6,*) "Z = ", atomic_number
120 ! write(6,*) "r_c = ", r_c
121 ! write(6,*) "num_core_electron = ", num_core_electron
122 ! write(6,*) "num_val_electron = ", num_val_electron
123
124 ! end
125
126 end function thomas_fermi_core_electron_number

128 !> @brief Gross-Dreizler approximation for Thomas-Fermi function
129 !>
130 !> This function implements the Gross-Dreizler approximation for the
131 !> Thomas-Fermi function χ(x), which is a key component in the Thomas-Fermi
132 !> model for electron density calculations.
133 !>
134 !> @param[in] x Dimensionless radial coordinate x = r/r_TF
135 !> @return Approximate value of χ(x) function
136 !>
137 !> @details
138 !> The Gross-Dreizler approximation provides a good analytical approximation
139 !> for the Thomas-Fermi function χ(x) using a rational function:
140 !> χ(x) = 1 / (1 + 1.4712*x - 0.4973*x^(3/2) + 0.3875*x² + 0.002102*x³)
141 !>
142 !> @note This approximation is accurate for a wide range of x values
143 !> @note Used in electron density calculations in Thomas-Fermi model
144 ! Gross Dreizler developed a good approximation of chi(x)
145
146 function gross_dreizler(x) result(f)
147
148 real(8), intent(in) :: x
149 real(8) f
150
151 f = 1.0d0/(1.0d0 + 1.4712d0*x - 0.4973d0*x**(3.0d0/2.0d0) + 0.3875d0*x**(2.0d0) + 0.002102d0*x**(3.0d0))
152
153 end function gross_dreizler
