16!> @brief 3D data visualization output in XCrySDen format for tilted cells
17!>
18!> This subroutine generates 3D data visualization files in XCrySDen (.xsf) format
19!> for quantum Monte Carlo calculations with tilted (non-orthogonal) unit cells.
20!> It outputs crystal structure information and 3D data grids that can be
21!> visualized using XCrySDen or similar software.
22!>
23!> The subroutine handles unit conversion from atomic units to Angstroms and
24!> supports both periodic and non-periodic systems with proper file naming
25!> conventions. Unlike plot_3d_data, this version supports general 3x3
26!> transformation matrices for tilted cells.
27!>
28!> @param[in] ipc Number of components per grid point (1 for scalar, 3 for vector)
29!> @param[in] s2r_loc Local transformation matrix for grid coordinates (3,3)
30!> @param[in] s2r Global transformation matrix for crystal structure (3,3)
31!> @param[in] natoms Number of atoms in the system
32!> @param[in] pos Atomic positions in atomic units (3, natoms)
33!> @param[in] zeta Atomic numbers or charges (natoms)
34!> @param[in] periodic Flag indicating periodic boundary conditions
35!> @param[in] mesh Grid dimensions (3)
36!> @param[in] origin Origin of the grid in atomic units (3)
37!> @param[in] datagrid 3D data grid to be plotted (ipc*mesh(1), mesh(2), mesh(3))
38!> @param[in] indmol Molecular index for file naming
39!> @param[in] word Identifier string for file naming
40!>
41!> @details
42!> The subroutine performs the following operations:
43!> 1. Checks file unit availability and opens output file
44!> 2. Converts all units from atomic units to Angstroms:
45!> - Transformation matrices (s2r and s2r_loc)
46!> - Origin and atomic positions
47!> - Data grid values (divided by length_unit^3)
48!> 3. Writes XCrySDen format header:
49!> - CRYSTAL section with primitive vectors from s2r matrix
50!> - PRIMCOORD section with atomic positions and charges
51!> 4. Writes 3D data grid section:
52!> - BEGIN_BLOCK_DATAGRID_3D header
53!> - Grid dimensions and origin
54!> - Primitive vectors for grid orientation from s2r_loc matrix
55!> - Data values in optimized format (3 values per line)
56!> 5. Closes the output file
57!>
58!> @note Output filename format: output_<word><indmol>.xsf
59!> @note The subroutine handles both scalar (ipc=1) and vector (ipc=3) data
60!> @note Data is written in chunks of 3 values per line for efficiency
61!> @note Used for visualizing electron density, wave functions, and other
62!> quantum mechanical properties in tilted cell geometries
63!> @note Compatible with XCrySDen, VESTA, and other visualization software
64!> @note The s2r matrix defines the crystal structure, while s2r_loc defines
65!> the local grid coordinate system
66subroutine plot_3d_data_tilted(ipc, s2r_loc, s2r, natoms, pos, zeta, periodic, mesh, origin, datagrid, indmol, word)
