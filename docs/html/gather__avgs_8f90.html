Gather averages and weights from all processes.

This subroutine gathers energy, weights, and correlation functions from all MPI processes to the root process. Used for parallel QMC calculations.

Parameters
[in]wbraLocal walker weight
[in]enerLocal energy
[in]wtotfLocal total weights (array)
[in]etotLocal correlation function array
[in,out]ener_tGathered energies (root only)
[in,out]wbra_tGathered weights (root only)
[in,out]wtotf_tGathered total weights (root only)
[in,out]etot_tGathered correlation functions (root only)
[in]np3Number of correlation functions
[in]pdimNumber of processes
