23!> @brief Returns the atomic weight (relative atomic mass) of an element given its atomic number
24!> @details This function provides access to a lookup table of atomic weights for elements with
25!> atomic numbers 1-103 (Hydrogen to Lawrencium). The atomic weights are based on the
26!> standard atomic weights recommended by IUPAC, taking into account the natural abundance
27!> of isotopes.
28!>
29!> The function performs bounds checking and returns an error if an invalid atomic number
30!> is provided.
31!>
32!> Atomic weights are dimensionless quantities relative to 12C = 12, stored with double
33!> precision (DP) for accuracy. The data array is indexed from 1 to 103, matching atomic numbers.
34!>
35!> @param[in] atomic_number The atomic number Z of the element (1-103)
36!> @return The atomic weight in atomic mass units (u)
37!>
38!> @note If atomic_number < 1 or atomic_number > 103, the function calls errore() with an error
39!> code of 1000 + atomic_number.
40!>
41!> @warning The error message in the original code mentions 'atom_name' but this function is
42!> 'atom_weight'. This might be a copy-paste error from another function.
43!>
44!> @par Examples:
45!> @code
46!> atom_weight(1) ! returns 1.00794 (Hydrogen)
47!> atom_weight(6) ! returns 12.0107 (Carbon)
48!> atom_weight(79) ! returns 196.96655 (Gold)
49!> @endcode
50!>
51!> @par Data Source:
52!> IUPAC standard atomic weights (natural abundance)
53!>
54!> @see kinds module for DP precision definition
55!> @see errore() for error handling
