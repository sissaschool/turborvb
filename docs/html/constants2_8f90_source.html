18!> @brief Physical and mathematical constants module for quantum Monte Carlo calculations
19!> @details This module provides a comprehensive collection of physical and mathematical
20!> constants used throughout the TurboRVB quantum Monte Carlo code. It includes
21!> fundamental mathematical constants, SI physical constants, atomic units,
22!> and various unit conversion factors.
23!>
24!> The constants are organized into several categories:
25!> - Mathematical constants (pi, sqrt2, etc.)
26!> - SI physical constants (Planck's constant, Boltzmann constant, etc.)
27!> - Atomic units and conversion factors
28!> - Numerical precision parameters
29!> - Compatibility constants for legacy code
30!>
31!> All constants are defined as double precision parameters for maximum
32!> accuracy in quantum mechanical calculations.

48 !
