Detailed Description

Thomas-Fermi model implementation for electron density calculations.

This module provides functions for calculating electron density distributions using the Thomas-Fermi model, which is a semi-classical approximation for atomic electron density. It is particularly useful for determining core and valence electron distributions in quantum Monte Carlo calculations.

The module implements the Thomas-Fermi model according to standard textbooks and provides numerical integration capabilities for calculating electron numbers within specified cutoff radii.

The Thomas-Fermi model provides an approximate description of electron density in atoms based on the following equations:

  • b = (9 * π² / 128)^(1/3)
  • r_TF = b * Z^(-1/3)
  • x_TF = r / r_TF
  • ρ(r) = (32 * Z²) / (9 * π³) * (χ(x_TF) / x_TF)^(3/2) where χ(x) is the Gross-Dreizler function.

real(8) function thomas_fermi_model::gross_dreizler ( real(8), intent(in) x)

Gross-Dreizler approximation for Thomas-Fermi function.

This function implements the Gross-Dreizler approximation for the Thomas-Fermi function χ(x), which is a key component in the Thomas-Fermi model for electron density calculations.

Parameters
[in]xDimensionless radial coordinate x = r/r_TF
Returns
Approximate value of χ(x) function

The Gross-Dreizler approximation provides a good analytical approximation for the Thomas-Fermi function χ(x) using a rational function: χ(x) = 1 / (1 + 1.4712*x - 0.4973*x^(3/2) + 0.3875*x² + 0.002102*x³)

Note
This approximation is accurate for a wide range of x values
Used in electron density calculations in Thomas-Fermi model

real(8) function thomas_fermi_model::thomas_fermi_core_electron_number ( real(8), intent(in) atomic_number,

Calculate core electron number using Thomas-Fermi model.

This function calculates the number of electrons inside a cutoff radius r_c according to the Thomas-Fermi model. It performs numerical integration of the electron density multiplied by a Gaussian function p(r) that separates core and valence electrons.

Parameters
[in]atomic_numberAtomic number Z of the element
[in]r_cCutoff radius for core electron definition (atomic units)
Returns
Number of core electrons within r_c

The function implements the following algorithm:

  1. Calculates Thomas-Fermi radius: r_TF = b * Z^(-1/3)
  2. Defines Gaussian function: p(r) = exp(-r²/(2*r_c²))
  3. Performs numerical integration:
    • Core electrons: ∫ 4πr² ρ(r) p(r) dr
    • Valence electrons: ∫ 4πr² ρ(r) (1-p(r)) dr
  4. Uses Gross-Dreizler approximation for χ(x) function
Note
Integration range: r_min = 1.0d-3 to r_max = 25.0d0
Integration step: dr = 1.0d-3
Used in pseudopotential generation and core-valence separation
