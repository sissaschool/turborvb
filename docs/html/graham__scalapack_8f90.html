Performs Gram-Schmidt orthogonalization for real matrices using SCALAPACK.

This subroutine performs Gram-Schmidt orthogonalization in a metric given by the overlap matrix. It orthogonalizes vectors such that sum_kl [over(k,l) * psi(k,i) * psi(l,j)] = 1 if i=j, 0 otherwise. Supports both serial and parallel (SCALAPACK) execution.

Parameters
[in,out]PSIMatrix of vectors to be orthogonalized
[in]overOverlap matrix defining the metric
[out]rnNormalization factors for the vectors
[in]ldaLeading dimension of PSI
[in]NDIMEDimension of the vectors
[in]MHNumber of vectors to orthogonalize
[out]infoStatus flag (0=success, >0=number of linearly dependent vectors)
[in]descSCALAPACK descriptor for PSI
[in]deschSCALAPACK descriptor for overlap matrix
[in]nlaxLeading dimension for SCALAPACK arrays
[in]rankRank of current MPI process
