Parallel matrix-matrix multiplication with MPI distribution.

This subroutine performs matrix-matrix multiplication C = α*A*B + β*C in parallel using MPI. The K dimension is distributed across processors, with each processor computing a partial result that is then reduced to form the final result.

Parameters

TRANSA : character*1, in Transpose flag for matrix A ('N'=no transpose, 'T'=transpose). TRANSB : character*1, in Transpose flag for matrix B ('N'=no transpose, 'T'=transpose). M : integer, in Number of rows in matrices A and C. N : integer, in Number of columns in matrices B and C. K : integer, in Number of columns in A and rows in B (distributed dimension). ALPHA : double precision, in Scalar multiplier for A*B. A : double precision array, in Input matrix A (size depends on TRANSA). LDA : integer, in Leading dimension of matrix A. B : double precision array, in Input matrix B (size depends on TRANSB). LDB : integer, in Leading dimension of matrix B. BETA : double precision, in Scalar multiplier for C. C : double precision array, inout Input/output matrix C (M × N). LDC : integer, in Leading dimension of matrix C. nproc : integer, in Number of MPI processes. rank : integer, in MPI rank of current process. comm_mpi : integer, in MPI communicator.

Notes

  • The K dimension is distributed across processors for parallel computation.
  • Each processor computes a partial matrix multiplication with its local K slice.
  • Results are reduced using MPI to form the final matrix C.
  • Only rank 0 applies the BETA scaling; other ranks start with zero.
  • Supports all four combinations of transpose operations (NN, NT, TN, TT).
