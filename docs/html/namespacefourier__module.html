Detailed Description

Module for Fourier transform operations in DFT calculations.

This module contains all variables and procedures related to Fourier transforms in the DFT code. It handles Hartree potential calculations, density transforms, gradient computations, and parallel FFT operations. Supports both periodic and non-periodic boundary conditions.

◆ evalgrad()

subroutine fourier_module::evalgrad

Computes gradient of electron density in Fourier space.

This subroutine computes the gradient of the electron density using FFT operations. It is designed for GGA exchange-correlation functionals but is currently unused in the present version of the code. It performs FFT on density, multiplies by wave vector components, and transforms back to real space.

◆ evalvhartreeq()

subroutine fourier_module::evalvhartreeq

Evaluates Hartree potential in Fourier space (density-independent part)

This subroutine computes the density-independent part of the Hartree potential in Fourier space. It handles both periodic (Ewald) and non-periodic boundary conditions, includes dielectric corrections, and performs parallel FFT operations.

Initializes Fourier transform parameters and arrays.

This subroutine initializes all parameters needed for Fourier transform operations including grid dimensions, FFT array sizes, and parallel distribution parameters. It handles double mesh calculations and different scaling factors.

◆ update_vhartree()

subroutine fourier_module::update_vhartree

Updates Hartree potential in real space from density-dependent part.

This subroutine computes the density-dependent part of the Hartree potential by performing FFT operations on the electron density. It transforms density to Fourier space, multiplies by the precomputed Hartree kernel, and transforms back to real space. Supports parallel execution and includes various corrections.
