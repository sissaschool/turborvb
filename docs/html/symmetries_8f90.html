Detailed Description

Symmetry operations and Bravais lattice symmetries for TurboRVB.

Provides routines for handling symmetry operations in periodic systems, including Bravais lattice symmetries, point group operations, and symmetry-based optimizations. Based on Quantum ESPRESSO symmetry routines adapted for QMC calculations.
