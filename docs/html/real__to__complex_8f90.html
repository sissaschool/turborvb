subroutine real_to_complex::set_new_detmat ( integer, intent(in) contraction)

Sets up new determinant matrix for complex wavefunction conversion.

This subroutine prepares the determinant matrix for conversion from real to complex wavefunctions. It allocates new arrays with double the size to accommodate complex numbers and handles both contracted and uncontracted cases.

Parameters
[in]contractionFlag indicating if contraction is used
