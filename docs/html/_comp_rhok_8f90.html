Computes density in k-space from plane wave matrix.

This subroutine computes the density in k-space (rhok) by summing the plane wave matrix contributions from all particles. It separates contributions from different particle types based on the nppss array.

Parameters
[out]rhoknewTotal density in k-space
[out]rhoknew2Density in k-space separated by particle type (2*nvects, 2)
[in]npartsNumber of particles
[in]nvectsNumber of wave vectors
[in]pwmatPlane wave matrix (2*nvects, nparts)
[in]nppssNumber of particles per species
