Apply cutoff to wave function for DMC calculations.

This subroutine applies energy cutoffs to the wave function for diffusion Monte Carlo calculations. It can apply either a simple energy cutoff or a position-dependent cutoff based on electron-ion distances.

[in]lambdaLambda parameter
[in,out]diffkinKinetic energy difference
[in]vpotgePotential energy array
[in]cutregCutoff parameter

Enforce detailed balance in wave function table.

This subroutine enforces detailed balance by adjusting the wave function table entries. It computes normalization factors and applies corrections to maintain consistency between positive and negative contributions.

Parameters
[in]indtNumber of time steps
[in]nelNumber of electrons
[in]identityIdentity parameter for normalization
[in]gammaGamma parameter for detailed balance
[in,out]tablerWave function table
[out]norm_tabNormalization factor for the table
