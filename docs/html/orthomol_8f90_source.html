16!> @brief Molecular orbital orthogonalization program for TurboRVB
17!> @details This program performs orthogonalization of molecular orbitals
18!> in a TurboRVB wave function. It reads a fort.10 file, applies
19!> orthogonalization procedures, and outputs a new fort.10_new file
20!> with orthogonalized orbitals. The program supports both serial and
21!> parallel execution modes.
22!>

24!> @date 2022
