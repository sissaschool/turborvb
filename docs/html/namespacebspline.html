Detailed Description

Main B-spline interpolation module.

Provides comprehensive B-spline functionality for interpolation, evaluation, and derivative computation in 1D, 2D, and 3D.

The following routines are included:

  • dbsnak: Compute "not-a-knot" spline knot sequence
  • dbsint: Compute spline interpolant and B-spline coefficients
  • dbsval: Evaluate spline at a point
  • dbsder: Evaluate spline derivatives
  • dbs1gd: Evaluate spline derivatives on a grid
  • dbs2in: 2D tensor-product spline interpolation
  • dbs2dr: 2D spline derivative evaluation
  • dbs2vl: 2D spline evaluation
  • dbs2gd: 2D spline evaluation on a grid
  • dbs3in: 3D tensor-product spline interpolation
  • dbs3vl: 3D spline evaluation
  • dbs3dr: 3D spline derivative evaluation
  • dbs3gd: 3D spline evaluation on a grid

Evaluate the derivative of a spline on a grid.

Evaluates the derivative of a B-spline at multiple points efficiently. This routine is optimized for evaluating splines on regular grids by reusing knot interval searches and basis function computations.

The grid evaluation uses the hunt algorithm to efficiently locate knot intervals for consecutive grid points, significantly improving performance compared to individual point evaluation.

Parameters
[in]iderxOrder of the derivative to be evaluated (0 = function value)
[in]nxvecLength of vector xvec
[in]xvecArray of length nxvec containing evaluation points (strictly increasing)
[in]kxOrder of the spline
[in]xknotArray of length nx+kx containing the knot sequence (non-decreasing)
[in]nxNumber of B-spline coefficients
[in]bcoefArray of length nx containing the B-spline coefficients
[out]valArray of length nxvec containing the derivative values
Note
xvec should be strictly increasing for optimal performance
Warning
All points in xvec must be within the knot range
See also
huntn subroutine for efficient knot interval searching

Compute a two-dimensional tensor-product spline interpolant.

Computes B-spline coefficients for 2D tensor-product spline interpolation. The algorithm constructs a 2D spline that interpolates data on a rectangular grid by applying 1D spline interpolation sequentially in each direction.

The tensor-product approach allows efficient construction of 2D splines by combining 1D B-splines in the x and y directions.

Evaluate the derivative of a spline at a given point.

Evaluates the derivative of a B-spline at a specified point. The function can compute derivatives of any order up to (spline order - 1). For iderx = 0, it returns the spline value itself.

The derivative computation uses the relationship between B-spline derivatives and lower-order B-splines, combined with the de Boor algorithm.

Parameters
[in]iderxOrder of the derivative to be evaluated (0 = function value)
[in]xPoint at which the spline is to be evaluated
[in]kxOrder of the spline
[in]xknotArray of length nx+kx containing the knot sequence (non-decreasing)
[in]nxNumber of B-spline coefficients
[in]bcoefArray of length nx containing the B-spline coefficients
Returns
Value of the iderx-th derivative of the spline at x
Note
For iderx >= kx, the result is zero
Warning
x must be within the knot range [xknot(1), xknot(nx+kx)]
See also
de Boor, C. (1978). A practical guide to Splines. Springer-Verlag.

Compute the spline interpolant, returning the B-spline coefficients.

Computes B-spline coefficients that interpolate the given data points. The algorithm constructs a linear system and solves it to find the coefficients that ensure the spline passes through all data points.

The method uses the B-spline basis functions to construct a banded linear system which is then solved using LU decomposition for banded matrices.

Parameters
[in]nxNumber of data points
[in]xvecArray of length nx containing the data point abscissas
[in]xdataArray of length nx containing the data point ordinates
[in]kxOrder of the spline (must be <= nx)
[in]xknotArray of length nx+kx containing the knot sequence (non-decreasing)
[out]bcoefArray of length nx containing the B-spline coefficients
Note
The knot sequence must be non-decreasing
Warning
The linear system must be solvable (iflag = 1)
See also
de Boor, C. (1978). A practical guide to Splines. Springer-Verlag.

Compute the "not-a-knot" spline knot sequence.

Generates a knot sequence for B-spline interpolation using the "not-a-knot" end condition. This condition ensures smooth interpolation by setting the first and last k knots to be equal, where k is the spline order.

The algorithm follows de Boor's method (p. 167) for constructing appropriate knot sequences that avoid oscillations at the boundaries.

Parameters
[in]nxNumber of data points
[in]xvecArray of length nx containing the location of data points
[in]kxordOrder of the spline (must be <= nx)
[out]xknotArray of length nx+kxord containing the knot sequence
Note
The knot sequence is non-decreasing and follows the "not-a-knot" condition
Warning
kxord must satisfy 0 <= kxord <= nx
See also
de Boor, C. (1978). A practical guide to Splines. Springer-Verlag.
