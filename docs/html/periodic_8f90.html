Apply periodic boundary conditions to ion positions.

This subroutine applies periodic boundary conditions to all ion positions using the periodic function. It updates ion coordinates and accumulates the sum of squared displacements weighted by mass for each ion.

Parameters
[in,out]rionIon positions (3, nion)
[in]nionNumber of ions
[in]cellscaleCell dimensions
[in]dt4Time step parameter
[in]massIon masses (3, nion)
[out]sumx2Sum of squared displacements weighted by mass

Apply periodic boundary condition to a single coordinate.

This subroutine applies periodic boundary conditions to a single coordinate using a Gaussian-weighted sum over periodic images. It finds the representative in [-L/2, L/2] and computes both the periodic coordinate and its square.

Parameters
[in]xInput coordinate
[in]LPeriod length
[in]dt4Time step parameter for Gaussian weighting
[out]periodicxPeriodic coordinate
[out]periodicx2Square of periodic coordinate
