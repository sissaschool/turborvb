Complex wave function constraint builder with sparse matrix indexing.

This subroutine constructs constraints for complex wave functions using sparse matrix indexing. It handles Jastrow factor derivatives and maps them to wave function parameters with support for different symmetry configurations and parameter types.

Parameters
[in]iesfreerNumber of free parameters in the wave function
[in]n3bodyNumber of three-body terms (Jastrow factors)
[in]jbrajArray mapping Jastrow terms to parameter indices
[in]nozerojArray of sparse matrix indices for non-zero elements
[in]derjasArray of Jastrow derivatives
[in,out]econfEnergy configuration array to be updated
[in]nwNumber of walkers
[in]ioptOperation mode flag

The subroutine handles different configurations based on the following parameters:

Parameter Types (ipc):

  • ipc = 1: Real parameters (single array element per parameter)
  • ipc = 2: Complex parameters (two array elements per parameter)

Symmetry Configurations (symmagp):

  • symmagp = .true.: AGP symmetry (4 array elements per parameter)
  • symmagp = .false.: Standard complex (2 array elements per parameter)

Operation Modes (iopt):

  • iopt = 0: Accumulate derivatives (add to existing values)
  • iopt ≠ 0: Replace derivatives (set new values)

Parameter Mapping Schemes:

  • Real parameters (ipc = 1): Direct mapping to single array element
  • Complex AGP (ipc = 2, symmagp = .true.): 4-element mapping (4*j-3, 4*j-1)
  • Complex standard (ipc = 2, symmagp = .false.): 2-element mapping (2*j-1, 2*j)
Note
The subroutine always initializes the energy configuration array to zero.
Complex parameters require special handling for real and imaginary parts.
AGP symmetry introduces additional parameter constraints.
