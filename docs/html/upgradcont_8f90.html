Update gradient with cutoff for DMC calculations.

Computes and updates gradients with cutoff for each electron. Implements the gradient cutoff scheme based on proximity to nuclei and applies scaling factors for DMC calculations. Uses Eq.36 from Umrigar J.Chem.Phys. vol.99 p.2866 for cutoff calculations.

Parameters
[out]gradpsibarGradient with cutoff for each electron
[out]gradpsiRaw gradient for each electron
[in]indtIndex offset for derivatives
