Detailed Description

Initial configuration generator for periodic boundary conditions (PBC)

This module provides routines to generate initial electron configurations for quantum Monte Carlo simulations with periodic boundary conditions. It ensures fair and randomized placement of electrons around ions, handles spin and occupation constraints, and applies PBC as needed.

Author
TurboRVB group
Date
2022

Features

  • Randomized and fair electron placement around ions
  • Handles spin-up and spin-down electron constraints
  • Supports electron affinity calculations (nel > ztot)
  • Applies periodic boundary conditions (PBC) if enabled
  • Lattice-based initialization if alat is specified
  • Ensures no duplicate electron positions
  • Computes electron-ion distances for all walkers

Generate initial electron configuration for PBC QMC simulations.

Places electrons around ions with randomized but fair distribution, respecting spin and occupation constraints. Applies PBC and lattice initialization as needed. Ensures no duplicate electron positions. Computes electron-ion distances for all walkers.

Parameters
[in]nelTotal number of electrons
[in]nelupNumber of spin-up electrons
[out]psilnLogarithm of initial wave function (per walker)
[out]psisnInitial sign of wave function (per walker)
[out]kelElectron coordinates (3, nel, 0:indt, *)
[out]wconfWalker weights
[in]rionIon coordinates (3, nion)
[out]distElectron-ion distances (nion, nel, *)
[in]indtNumber of time slices (for PIMC)
[in]nionNumber of ions
[in]zetaIon charges
[in]in1Number of walkers per process
[in]rankMPI rank
[out]ierrError flag
[in]LBoxSimulation box length (PBC)
[in]alatLattice constant (if > 0, use lattice init)
[in]rion_refReference ion position for lattice init
[in]iesrandomaLogical flag for random initialization
[in]itestTest mode flag
Note
Ensures no two electrons are placed at the same position
Applies PBC using ApplyPBC subroutine if LBox > 0
Handles both random and lattice-based initialization
Computes and stores electron-ion distances for all walkers
