38*
39* Purpose
40* =======
41*
42* DSKTRF computes the factorization of a skew-symmetric matrix A
43* using the Parlett-Reid algorithm:
44*
45* P*A*P^T = U*T*U^T or P*A*P^T = L*T*L^T
46*
47* where U (or L) unit upper (lower) triangular matrix (^T denotes
48* the transpose), T is a skew-symmetric tridiagonal matrix and P
49* is a permutation matrix. In addition to being unit triangular,
50* U(1:n-1,n)=0 and L(2:n,1)=0.
51* Instead of a full tridiagonalization, DSKTRF can also compute a
52* partial tridiagonal form for computing the Pfaffian.
53*
54* This is the blocked version of the algorithm, calling Level 3 BLAS.
55*
56* Arguments
57* =========
58*
59* UPLO (input) CHARACTER*1
60* Specifies whether the upper or lower triangular part of the
61* symmetric matrix A is stored:
62* = 'U': Upper triangular
63* = 'L': Lower triangular
64*
65* MODE (input) CHARACTER*1
66* = 'N': A is fully tridiagonalized
67* = 'P': A is partially tridiagonalized for Pfaffian computation
68* (details see below)
69*
70* N (input) INTEGER
71* The order of the matrix A. N >= 0. N must be even if MODE = 'P'.
72*
73* A (input/output) DOUBLE PRECISION array, dimension (LDA,N)
74* On entry, the symmetric matrix A.
75* If UPLO = 'U', the leading n-by-n upper triangular part
76* of A contains the upper triangular part of the matrix A,
77* and the strictly lower triangular part of A is not referenced.
78* If UPLO = 'L', the leading n-by-n lower triangular part
79* of A contains the lower triangular part of the matrix A,
80* and the strictly upper triangular part of A is not referenced.
81*
82* On exit, the tridiagonal matrix T and the multipliers used
83* to obtain the factor U or L (see below for further details).
84*
85* LDA (input) INTEGER
86* The leading dimension of the array A. LDA >= max(1,N).
87*
88* IPIV (output) INTEGER array, dimension (N)
89* Information about the permutation matrix P: row and column
90* i are interchanged with IPIV(i). If UPLO = 'U', those
91* interchanges are done in the order i = N ... 1, if UPLO = 'L'
92* in the order i = 1 ... N.
93*
94* WORK (workspace/output) DOUBLE PRECISION array, dimension (MAX(1,LWORK))
95* On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
96*
97* LWORK (input) INTEGER
98* The length of WORK. LWORK >=1. For best performance
99* LWORK >= N*NB, where NB is the block size returned by ILAENV
100* (at the moment, uses the same block size as DSYTRF from Lapack).
101*
102* If LWORK = -1, then a workspace query is assumed; the routine
103* only calculates the optimal size of the WORK array, returns
104* this value as the first entry of the WORK array, and no error
105* message related to LWORK is issued by XERBLA.
106*
107* INFO (output) INTEGER
108* = 0: successful exit
109* < 0: if INFO = -k, the k-th argument had an illegal value
110* > 0: if INFO = k, the off-diagonal entry in the k-th row
111* (UPLO = 'U') or k-th column (UPLO = 'L')
112* is exactly zero.
113*
114* Further Details
115* ===============
116*
117*
118* The normal use for DSKTRF is to compute the U T U^T or L T L^T
119* decomposition of a skew-symmetric matrix with pivoting. This mode
120* is chosen by setting MODE = 'N' ("normal" mode). The other
121* use of DSKTRF is the computation the Pfaffian of a skew-symmetric matrix,
122* which only requires a partial computation of T, this mode is chosen
123* by setting MODE = 'P' ("Pfaffian" mode).
124*
125* Normal mode (MODE = 'N'):
126* ========================
127*
128* If UPLO = 'U', the U*T*U^T decomposition of A is computed. U is a
129* upper triangular unit matrix with the additional constraint
130* U(1:n-1,n) = 0, and T a tridiagonal matrix. The upper diagonal
131* of T is stored on exit in A(i,i+1) for i = 1 .. n-1. The column
132* U(1:i-1, i) is stored in A(1:i-1,i+1).
133*
134* If UPLO = 'L', the L*T*L^T decomposition of A is computed. L is a
135* lower triangular unit matrix with the additional constraint
136* L(2:n,1) = 0, and T a tridiagonal matrix. The lower diagonal
137* of T is stored on exit in A(i+1,i) for i = 1 .. n-1. The column
138* L(i+1:n, i) is stored in A(i+1:n,i-1).
139*
140* The contents of A on exit are illustrated by the following examples
141* with n = 5:
142*
143* if UPLO = 'U': if UPLO = 'L':
144*
145* ( 0 e u2 u3 u4 ) ( 0 )
146* ( 0 e u3 u4 ) ( e 0 )
147* ( 0 e u4 ) ( l2 e 0 )
148* ( 0 e ) ( l2 l3 e 0 )
149* ( 0 ) ( l2 l3 l4 e 0 )
150*
151* where e denotes the off-diagonal elements of T, and ui (li)
152* denotes an element of the i-th column of U (L).
153*
154* Pfaffian mode (MODE = 'P'):
155* ==========================
156*
157* For computing the Pfaffian, it is enough to bring A into a partial
158* tridiagonal form. In particular, assuming n even, it is enough to
159* bring A into a form with A(i,j) = A(j,i) = 0 for i > j+1 with j odd
160* (this is computed if UPLO = 'L'), or A(i,j) = A(j,i) = 0 for
161* i > j-1 with j even (this is computed if UPLO = 'U'). Note that
162* only the off-diagonal entries in the odd columns (if UPLO = 'L')
163* or in the even columns (if UPLU = 'U') are properly computed by DSKTRF.
164*
165* If UPLO = 'U', the U*pT*U^T decomposition of A is computed. U is a
166* upper triangular unit matrix with the additional constraint
167* U(1:i-1,i) = 0 for even i, and pT a partially tridiagonal matrix.
168* The entries in the odd rows of the upper diagonal of pT are stored
169* on exit in A(i,i+1) for i odd. The column U(1:i-1, i) for odd i
170* is stored in A(1:i-1,i+1).
171*
172* If UPLO = 'L', the L*pT*L^T decomposition of A is computed. L is a
173* lower triangular unit matrix with the additional constraint
174* L(i+1:n,i) = 0 for odd i, and pT a partially tridiagonal matrix.
175* The entries in odd columns in the lower diagonal of pT are stored
176* on exit in A(i+1,i) for i odd. The column L(i+1:n, i) for i odd
177* is stored in A(i+1:n,i-1).
178*
179* The contents of A on exit are illustrated by the following examples
180* with n = 6:
181*
182* if UPLO = 'U': if UPLO = 'L':
183*
184* ( 0 e x u3 x u5 ) ( 0 )
185* ( 0 x u3 x u5 ) ( e 0 )
186* ( 0 e x u5 ) ( l2 x 0 )
187* ( 0 x u5 ) ( l2 x e 0 )
188* ( 0 e ) ( l2 x l4 x 0 )
189* ( 0 ) ( l2 x l4 x e 0 )
190*
191* where e denotes the off-diagonal elements of T, ui (li)
192* denotes an element of the i-th column of U (L), and x denotes an
