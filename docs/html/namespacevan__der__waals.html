Detailed Description

Van der Waals module for intermolecular interactions.

This module provides data structures and variables for handling van der Waals interactions in QM/MM calculations, including Lennard-Jones parameters and statistical averages.

The module contains:

  • Lennard-Jones parameters (C12, C6)
  • Van der Waals coordinates and connectivity
  • Statistical averages and error estimates
  • Support for GROMOS and CPMD force fields
Note
Used in QM/MM calculations with van der Waals interactions
Supports various force field parameter sets
