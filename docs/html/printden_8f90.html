Prints electron density data to XCrySDen format.

This subroutine processes electron density data and writes it to a file compatible with XCrySDen visualization software. It handles both periodic and non-periodic systems, applies appropriate coordinate transformations, and manages parallel data collection from multiple MPI processes.

Parameters
[in]rion_refReference ion positions for coordinate system
[in]rion_shiftShift vector for ion positions
[in]nxlLocal grid dimension for parallel calculations
[in]dentLocal density array from each MPI process
