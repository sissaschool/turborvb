Detailed Description

Classical restraints module for QM/MM calculations.

This module provides variables for handling classical restraints in QM/MM calculations, including bond, angle, dihedral, and improper dihedral restraints.

The module contains:

  • Number of different types of restraints
  • Restraint force constants and equilibrium values
  • Restraint forces for each type of interaction
  • Scaling factor for MM contributions
Note
Used in QM/MM calculations with restraint potentials
Supports harmonic and other restraint functional forms
