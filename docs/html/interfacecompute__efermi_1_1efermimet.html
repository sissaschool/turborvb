Calculates Fermi energy with smearing using k-point averaging.

This subroutine calculates the Fermi energy using smearing functions with k-point averaging. It uses a bisection method to find the Fermi energy that gives the correct number of electrons.

Parameters
[in]eigEigenvalues array (bands, nk)
[in]bandsNumber of bands
[in]nelNumber of electrons
[in]dtSmearing parameter
[in,out]efFermi energy (initial guess, updated on output)
