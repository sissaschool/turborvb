Detailed Description

Splines module for interpolation of external potentials.

This module provides data structures and variables for handling spline interpolation of external potentials on 3D grids.

The module contains:

  • Spline orders and knot numbers for each dimension
  • Spline coefficients for 3D interpolation
  • Knot positions and grid spacing
  • Current position for interpolation
Note
Used for efficient evaluation of external potentials
Supports cubic spline interpolation in 3D
