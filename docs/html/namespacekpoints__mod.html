Check consistency between wavefunction phases and k-points.

Verifies that the wavefunction phases in fort.10 files correspond to the input k-points for all MPI processes. Ensures that the k-point grid and the wavefunction phases are consistent across the pool. Calls error routine if any mismatch is detected.

Parameters
[in]idProcess ID in the k-point pool
[in]commMPI communicator
[in]rankMPI rank
Note
Uses reduce_base_real for collective communication. Writes error and aborts if phases do not match k-points.

Namelist for k-points grid definition.

Initialize k-points for all kp_type methods

Initializes the k-point grid and related arrays for periodic boundary condition calculations. Handles various k-point generation schemes: Monkhorst-Pack, custom input, band structure paths, random, and flavor twist. Also sets up symmetry operations and transforms coordinates as needed.

Parameters
[in,out]iflagInteger flag for error handling (0=success, 1=error)
[in]nelNumber of electrons
[in]nionNumber of ions
[in]rionIon positions (3, nion)
[in]atom_numberAtomic numbers (nion)
[in]rsWigner-Seitz radius parameter
Note
K-points are left in crystal coordinates and must be transformed to cartesian coordinates (multiply by 2*pi/cell_scale) for use in other routines.
Handles symmetry reduction, time reversal, and double grid for up/down spins.
Writes symmetry information to stdout for user reference.
See also
kpoint_grid, generate_kp_path, set_sym_bl, purge_isymm

◆ kp_type

integer kpoints_mod::kp_type

K-points generation method identifier.

Methods used to generate k-points:

  • 0 = gamma point or single phase calculation (phase read from fort.10)
  • 1 = Monkhorst-Pack algorithm
  • 2 = read k-points in crystal coordinates from datasmin.input
  • 3 = read k-points path in 1BZ for band structure calculations
  • 4 = generate random k-points
  • 5 = generate nk*nk matrix for flavor twisted boundary conditions
