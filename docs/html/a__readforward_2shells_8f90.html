Computes vectors within a cutoff radius in reciprocal space.

Computes vectors x(ndim)=(a(1)*n(1),...,a(ndim)*n(ndim)) where n(i) are integers and x(1)^2 + ... + x(ndim)^2 <= cut^2. The vectors are stored in rkcomp ordered by their norms. Also computes the number of different norm values (nshlls) and stores the norms in rknorm with their multiplicities in kmult.

Parameters
[in]ndimDimension of space
[in]aArray of lattice parameters (mdim)
[in]cutCutoff radius
[out]nshllsNumber of different norm values found
[out]rkcompArray storing the computed vectors (mdim,mnkv)
[out]rknormArray storing the different norm values (0:mnsh)
[out]kmultArray storing multiplicities of each norm (0:mnsh)
[out]nvectsTotal number of vectors found
[in]mnkvMaximum number of vectors allowed
[in]mnshMaximum number of shells allowed
[in]mdimDimension of arrays
[in]rankMPI rank
