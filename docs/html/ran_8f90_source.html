16!> @brief Portable random number generator for quantum Monte Carlo
17!>
18!> This function implements a portable random number generator based on
19!> the Park-Miller minimal standard multiplicative linear congruential
20!> generator combined with a Marsaglia shift sequence. It provides
21!> uniform random numbers in the interval (0,1) for use in quantum
22!> Monte Carlo calculations.
23!>
24!> @param[in,out] idum Seed for random number generation:
25!> - idum ≤ 0: Initialize generator with |idum|
26!> - idum > 0: Generate next random number
27!> @return Real random number in the interval (0,1)
28!>
29!> @details
30!> The function implements a combined generator with the following features:
31!> 1. Park-Miller multiplicative linear congruential generator:
32!> - Parameters: IA = 16807, IM = 2147483647, IQ = 127773, IR = 2836
33!> - Recurrence: iy = IA * (iy - k*IQ) - IR*k (mod IM)
34!> 2. Marsaglia shift sequence for ix:
35!> - Uses XOR and bit shifts for additional randomness
36!> 3. Combined output: ran = am * (ix XOR iy OR 1)
37!>
38!> @note The generator has a period of approximately 2^31 - 1
39!> @note The function uses saved variables to maintain state between calls
40!> @note Initialization occurs when idum ≤ 0 or iy < 0
41!> @note The function is portable across different platforms and compilers
42!> @note Used extensively in Monte Carlo sampling and random walk algorithms
43function ran(idum)
44 implicit none
45 integer, parameter :: K4B = selected_int_kind(9)
46 integer(K4B), intent(INOUT) :: idum
47 real :: ran
48 integer(K4B), parameter :: IA = 16807, im = 2147483647, iq = 127773, ir = 2
49 real, save :: am
50 integer(K4B), save :: ix = -1, iy = -1, k
51 if (idum <= 0 .or. iy < 0) then
52 am = nearest(1.0, -1.0)/im
53 iy = ior(ieor(888889999, abs(idum)), 1)
54 ix = ieor(777755555, abs(idum))
55 idum = abs(idum) + 1
56 end if
57 ix = ieor(ix, ishft(ix, 13))
58 ix = ieor(ix, ishft(ix, -17))
59 ix = ieor(ix, ishft(ix, 5))
60 k = iy/iq
61 iy = ia*(iy - k*iq) - ir*k
62 if (iy < 0) iy = iy + im
63 ran = am*ior(iand(im, ieor(ix, iy)), 1)
64end
