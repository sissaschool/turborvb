subroutine berry_phase::berry_phase_update ( real*8, dimension(3*nel), intent(in) kelw,
integer, intent(in) nel )

Updates Berry phase calculation for a walker.

This subroutine computes z_N according to Resta & Sorella PRL 82, 370 (1999). It computes k.x, the argument of the exponential, and evaluates e^{i*k.x} for each direction.

Parameters
[in]kelwElectronic positions for a single walker (3*nel)
[in]nelNumber of electrons

subroutine berry_phase::init_berry_phase ( integer, intent(in) nel)

Initializes Berry phase calculation vectors.

This subroutine allocates and initializes the constant vector with reciprocal cell dimensions used in z_N calculations. It creates nel copies of the 3D vector made by the orthogonal dimensions of the reciprocal cell.

Parameters
[in]nelNumber of electrons
