Transform psi parameters for real wave functions.

Transforms psi parameters (psip) for real wave functions by reorganizing the parameter array according to transformation indices. First copies zeta parameters using iesuptrans mapping, then processes mu_c coefficients using transpip and multranspip arrays. Handles real parameter transformations for wave function optimization.

Parameters
[in,out]psipPsi parameter array to transform
[in]iesuprNumber of real parameters
[in]iesupcNumber of complex parameters
[in]iesuptransTransformation indices for real parameters
[in]multranspipMultiplicity array for complex parameters
[in]transpipTransformation array for complex parameters
[in]derdet_muDerivative determinant mu array
