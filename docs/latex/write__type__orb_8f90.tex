Assign orbital types for Jastrow orbitals based on shell structure. 

This subroutine assigns orbital type indices to Jastrow orbitals based on their shell multiplicity and occupation. The orbital types follow a specific numbering scheme for different angular momentum shells (s, p, d, f, g).\hypertarget{write__type__orb_8f90_autotoc_md99}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{write__type__orb_8f90_autotoc_md99}
NSHELLJ \+: integer, in Number of shells in the Jastrow basis. MULTIJ \+: integer array, in Multiplicity of each shell (1=s, 3=p, 5=d, 7=f, 9=g). IOCCJ \+: integer array, in Occupation numbers for each orbital (0=unoccupied, 1=occupied). TYPEORB \+: integer array, out Assigned orbital type indices for occupied orbitals.\hypertarget{write__type__orb_8f90_autotoc_md100}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{write__type__orb_8f90_autotoc_md100}

\begin{DoxyItemize}
\item Only occupied orbitals (IOCCJ ≠ 0) are assigned type indices.
\item The orbital type numbering follows the scheme\+:
\begin{DoxyItemize}
\item s orbitals (multiplicity 1)\+: type = 0
\item p orbitals (multiplicity 3)\+: type = 1, 2, 3
\item d orbitals (multiplicity 5)\+: type = 4, 5, 6, 7, 8
\item f orbitals (multiplicity 7)\+: type = 9, 10, 11, 12, 13, 14, 15
\item g orbitals (multiplicity 9)\+: type = 16, 17, 18, 19, 20, 21, 22, 23, 24
\end{DoxyItemize}
\item The subroutine processes shells sequentially and assigns types incrementally.
\item Used in Jastrow factor construction for quantum Monte Carlo.
\end{DoxyItemize}\hypertarget{write__type__orb_8f90_autotoc_md101}{}\doxysubsubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{write__type__orb_8f90_autotoc_md101}
