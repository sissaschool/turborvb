Add sine and cosine contributions to sum\+Img\+Real array. 

This subroutine computes and adds sine and cosine contributions to the sum\+Img\+Real array for wave vector summations. It was created by Sandro Sorella on 27th Nov. 2007. The subroutine loops over kx, ky, kz wave vectors and accumulates the contributions to the real and imaginary parts of the sum.
