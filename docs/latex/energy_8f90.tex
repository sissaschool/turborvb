Compute energy components for real wave function matrix elements. 

This subroutine computes various energy components from matrix elements table. It calculates wtot as the sum of \texorpdfstring{$\vert$}{|}\+G\+\_\+x\textquotesingle{},x\texorpdfstring{$\vert$}{|} where G\+\_\+x,x (diagonal part) is given by the lattice FN approximation\+: G\+\_\+x,x = diag + (1+gamma) \texorpdfstring{$\ast$}{*} veff. The matrix elements are processed differently based on their sign and position relative to the effective interaction range defined by istart and indtm.

Compute energy components for complex wave function matrix elements. 

This subroutine computes various energy components from complex matrix elements table. Similar to the real version but handles complex matrix elements.
