Copy and transform AGP (Antisymmetrized Geminal Power) matrices. 

This subroutine handles copying and transformation between different representations of AGP matrices. It can convert between a small matrix representation and a full matrix representation, including Pfaffian matrix elements.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em small2big} & Direction flag for matrix transformation \\
\hline
\mbox{\texttt{in}}  & {\em ipc} & Parameter type flag (1=real, 2=complex) \\
\hline
\mbox{\texttt{in}}  & {\em nelorb\+\_\+c} & Number of orbitals in the core \\
\hline
\mbox{\texttt{in}}  & {\em nelcol\+\_\+c} & Number of columns in the full matrix \\
\hline
\mbox{\texttt{in,out}}  & {\em detmat\+\_\+small} & Small matrix representation (nelorb\+\_\+c × nelcol\+\_\+c) \\
\hline
\mbox{\texttt{in,out}}  & {\em eagp\+\_\+pfaff} & Pfaffian matrix elements ((nelcol\+\_\+c-\/nelorb\+\_\+c) × (nelcol\+\_\+c-\/nelorb\+\_\+c)) \\
\hline
\mbox{\texttt{in,out}}  & {\em detmat\+\_\+big} & Full matrix representation (nelcol\+\_\+c × nelcol\+\_\+c)\\
\hline
\end{DoxyParams}
The subroutine performs different operations based on the small2big flag\+:

{\bfseries{small2big = .true. (Small to Big transformation)\+:}}
\begin{DoxyEnumerate}
\item Copy the small matrix to the upper-\/left block of the big matrix
\item Apply antisymmetry\+: detmat\+\_\+big(i,j) = -\/detmat\+\_\+small(j,i) for i \texorpdfstring{$>$}{>} nelorb\+\_\+c, j ≤ nelorb\+\_\+c
\item Copy Pfaffian elements to the lower-\/right block of the big matrix
\end{DoxyEnumerate}

{\bfseries{small2big = .false. (Big to Small transformation)\+:}}
\begin{DoxyEnumerate}
\item Copy the upper-\/left block of the big matrix to the small matrix
\item Extract Pfaffian elements from the lower-\/right block of the big matrix
\end{DoxyEnumerate}

{\bfseries{Parameter Handling\+:}}
\begin{DoxyItemize}
\item ipc = 1\+: Real matrices (single precision elements)
\item ipc = 2\+: Complex matrices (double precision elements, real/imaginary parts)
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The subroutine assumes proper matrix dimensions and memory allocation. 

For complex matrices (ipc=2), the transformation handles real and imaginary parts. 

The antisymmetry property is enforced during the transformation. 

This subroutine is essential for AGP wave function calculations. 
\end{DoxyNote}
