Print eigenvalues and determine matrix rank for quantum Monte Carlo. 

This subroutine prints eigenvalues to output and determines the effective rank of a matrix by counting non-\/zero eigenvalues. It is used in quantum Monte Carlo calculations for analyzing matrix properties and numerical stability.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em rank} & MPI rank of the calling process \\
\hline
\mbox{\texttt{in}}  & {\em eig} & Array of eigenvalues to be printed \\
\hline
\mbox{\texttt{in}}  & {\em maxdimeig} & Maximum dimension of eigenvalue array \\
\hline
\mbox{\texttt{out}}  & {\em irankdet} & Effective rank of the matrix (number of non-\/zero eigenvalues)\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Initializes irankdet to 0
\item Iterates through all eigenvalues from 1 to maxdimeig\+:
\begin{DoxyItemize}
\item Checks if eigenvalue magnitude is greater than 1.\+0e-\/11
\item Increments irankdet for each non-\/zero eigenvalue
\item Prints eigenvalue index and value (only from rank 0)
\end{DoxyItemize}
\item Returns the effective rank of the matrix
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Only rank 0 prints eigenvalues to avoid duplicate output in parallel 

Uses a threshold of 1.\+0e-\/11 to determine non-\/zero eigenvalues 

The effective rank represents the number of linearly independent components in the matrix 

Used for analyzing overlap matrices, Hamiltonian matrices, and other matrices in quantum Monte Carlo calculations 

The subroutine is useful for debugging and numerical stability analysis 
\end{DoxyNote}
