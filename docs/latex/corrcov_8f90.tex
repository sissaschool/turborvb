\doxysubsection{Detailed Description}
Program for computing force correlation functions with covariance analysis. 

This program reads energy and derivative data from fort.\+21 files and computes force correlation functions using jackknife resampling. It constructs covariance matrices for force parameters, diagonalizes them to find optimal directions, and applies signal-\/to-\/noise optimization for force calculations in quantum Monte Carlo.
