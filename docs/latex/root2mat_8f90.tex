Compute square root of a positive definite symmetric 2x2 matrix. 

This subroutine computes the square root of a positive definite symmetric 2x2 matrix A. The output is the unique 2x2 symmetric positive definite matrix B such that B\texorpdfstring{$^\wedge$}{\string^}2 = A. If the input is positive definite the output replaces the input, otherwise the input matrix is unchanged.
