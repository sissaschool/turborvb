\doxysubsection{Detailed Description}
Link atoms module for QM/\+MM interface. 

This module defines data structures and variables for handling link atoms in quantum mechanics/molecular mechanics (QM/\+MM) hybrid calculations. Link atoms are used to cap the QM region at the boundary with the MM region.

The module contains\+:
\begin{DoxyItemize}
\item Link atom definitions (cap, QM, MM atoms)
\item Capping atom parameters and flags
\item Arrays for managing link atom connectivity
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Used in QM/\+MM hybrid calculations 

Supports various capping schemes for different force fields 
\end{DoxyNote}
