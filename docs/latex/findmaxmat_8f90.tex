Find maximum matrix indices for sparse matrix operations. 

This subroutine determines the maximum row and column indices used in a sparse matrix representation, which is useful for allocating memory and optimizing matrix operations in quantum Monte Carlo calculations.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em iessw} & Number of active orbitals to consider (0 = skip calculation) \\
\hline
\mbox{\texttt{in}}  & {\em nnozero} & Number of non-\/zero elements in the sparse matrix \\
\hline
\mbox{\texttt{in}}  & {\em nozero} & Array containing linear indices of non-\/zero matrix elements \\
\hline
\mbox{\texttt{in}}  & {\em nelorbh} & Number of orbitals (matrix dimension) \\
\hline
\mbox{\texttt{in}}  & {\em jbradet} & Array mapping sparse matrix indices to orbital indices \\
\hline
\mbox{\texttt{in,out}}  & {\em lastmol} & Maximum row/column index found (updated on output)\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Checks if calculation should be performed (iessw \texorpdfstring{$>$}{>} 0)
\item Iterates through all non-\/zero matrix elements
\item For each element with valid jbradet mapping (1 ≤ jbradet(j) ≤ iessw)\+:
\begin{DoxyItemize}
\item Converts linear index to (row, column) coordinates
\item Updates lastmol with the maximum of current lastmol, row, and column
\end{DoxyItemize}
\item Only considers elements where both row and column are ≤ nelorbh
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The subroutine uses linear indexing where element (i,j) corresponds to index (j-\/1)\texorpdfstring{$\ast$}{*}nelorbh + i 

If iessw = 0, the subroutine returns immediately without calculation 

The subroutine updates lastmol in-\/place with the maximum value found 

This is typically used for memory allocation and optimization purposes 
\end{DoxyNote}
