integer function iesdr2iesd (\begin{DoxyParamCaption}\item[{integer}]{iesdr}{}\end{DoxyParamCaption})}



Jastrow factor type mapping function for two-\/body terms. 

This function maps Jastrow factor type codes (iesdr) to specific two-\/body Jastrow factor implementations used in quantum Monte Carlo calculations. It provides a standardized way to determine the appropriate two-\/body Jastrow factor type based on the input parameter.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em iesdr} & Jastrow factor type code \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Integer code representing the specific two-\/body Jastrow factor type
\end{DoxyReturn}
The function performs the following mapping\+:
\begin{DoxyItemize}
\item Default\+: Returns the input iesdr value unchanged
\item iesdr = -\/15\+: Maps to Type 1 two-\/body Jastrow factor
\item iesdr = -\/5\+: Maps to Type 1 two-\/body Jastrow factor
\item iesdr = -\/6\+: Maps to Type 4 two-\/body Jastrow factor
\item iesdr = -\/7\+: Maps to Type 4 two-\/body Jastrow factor
\item iesdr = -\/17\+: Maps to Type -\/1 two-\/body Jastrow factor
\item iesdr = -\/20\+: Maps to Type -\/1 two-\/body Jastrow factor
\item iesdr = -\/21\+: Maps to Type 2 two-\/body Jastrow factor
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The function provides backward compatibility for different Jastrow factor implementations in Turbo\+RVB 

Type 1 corresponds to standard two-\/body Jastrow factors 

Type 4 corresponds to extended two-\/body Jastrow factors 

Type -\/1 corresponds to alternative two-\/body Jastrow factor forms 

Type 2 corresponds to specialized two-\/body Jastrow factor forms 

The function is used in wave function setup and optimization 
\end{DoxyNote}
