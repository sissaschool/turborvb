Calculate electron-\/ion potential energy with Yukawa potential. 

This subroutine computes the electron-\/ion potential energy for a given electron position using a Yukawa potential with periodic boundary conditions. The potential includes a screening parameter and can handle both isolated and periodic systems.\hypertarget{upvpot__ei_8f90_autotoc_md66}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{upvpot__ei_8f90_autotoc_md66}
RKEL \+: real\texorpdfstring{$\ast$}{*}8 array, in Position of the electron (3 coordinates). ZETA \+: real\texorpdfstring{$\ast$}{*}8 array, in Array of ion charges (NION). RION \+: real\texorpdfstring{$\ast$}{*}8 array, in Positions of ions (3 × NION). VPOT \+: real\texorpdfstring{$\ast$}{*}8, out Computed electron-\/ion potential energy. NION \+: integer, in Number of ions in the system. LBOX \+: real\texorpdfstring{$\ast$}{*}8, in Box length for periodic boundary conditions. EPSVPOT \+: real\texorpdfstring{$\ast$}{*}8, in Screening parameter for Yukawa potential. If EPSVPOT = 0\+: returns VPOT = 1.\+0 (no interaction). If EPSVPOT \texorpdfstring{$>$}{>} 0\+: computes Yukawa potential.\hypertarget{upvpot__ei_8f90_autotoc_md67}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{upvpot__ei_8f90_autotoc_md67}

\begin{DoxyItemize}
\item Uses Yukawa potential\+: V(r) = Z\texorpdfstring{$\ast$}{*}exp(-\/κr)/r for each ion.
\item Handles periodic boundary conditions through the NGIVEJ function.
\item The total potential is the square root of the sum of individual contributions.
\item For EPSVPOT = 0, returns a constant value (no electron-\/ion interaction).
\item Optimized for quantum Monte Carlo applications.
