\doxysubsection{Detailed Description}
Ewald summation module for long-\/range Coulomb interactions in periodic systems. 

This module implements the Ewald summation method for efficiently computing long-\/range Coulomb interactions in periodic boundary conditions. It provides both real-\/space and reciprocal-\/space contributions to the electrostatic energy, along with self-\/energy corrections and efficient parallelization support. The implementation is optimized for quantum Monte Carlo calculations and supports both ionic and electronic charge distributions. \begin{DoxyAuthor}{Author}
Turbo\+RVB group 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2022 
\end{DoxyDate}
\hypertarget{ewald_8f90_Algorithm}{}\doxysubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{ewald_8f90_Algorithm}
The Ewald summation splits the Coulomb interaction into three parts\+:
\begin{DoxyItemize}
\item Real-\/space sum\+: Short-\/range interactions with Gaussian screening
\item Reciprocal-\/space sum\+: Long-\/range interactions in Fourier space
\item Self-\/energy correction\+: Removal of self-\/interaction terms

Find optimal condition number for non-\/orthogonal cell. 

This function computes the optimal condition number for determining the G-\/vector cutoff in non-\/orthogonal cells. It tries all possible permutations of the reciprocal lattice vectors to find the minimum condition number, which ensures the cutoff sphere fits within the cell.
