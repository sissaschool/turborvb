Set specific elements of a vector to a constant value. 

This subroutine sets every m-\/th element of a vector to a specified value. It is used for initializing arrays with a specific pattern, particularly useful in quantum Monte Carlo calculations for setting up initial conditions or clearing specific array elements.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em n} & Number of elements to set \\
\hline
\mbox{\texttt{in}}  & {\em zero} & Value to assign to the selected elements \\
\hline
\mbox{\texttt{in,out}}  & {\em vet} & Vector to be modified (m\texorpdfstring{$\ast$}{*}(n-\/1)+1) \\
\hline
\mbox{\texttt{in}}  & {\em m} & Stride between elements to be set\\
\hline
\end{DoxyParams}
The subroutine sets vet(m\texorpdfstring{$\ast$}{*}(i-\/1)+1) = zero for i = 1 to n. This effectively sets every m-\/th element starting from the first element. For m=1, all n elements are set to zero. For m=2, elements 1, 3, 5, ... are set to zero.

\begin{DoxyNote}{Note}
This is a serial version without Open\+MP parallelization 
\end{DoxyNote}
