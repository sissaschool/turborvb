\doxysubsection{Detailed Description}
Program for computing complex force correlation functions using bootstrap analysis. 

This program reads complex energy and derivative data from fort.\+21 files and computes complex force correlation functions using bootstrap resampling. It calculates both real and imaginary parts of the Pulay correction term for complex wave functions in quantum Monte Carlo.
