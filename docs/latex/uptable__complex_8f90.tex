Update table and tabler for complex wave function ratios. 

Updates the table and tabler arrays for complex wave function ratios. The bosonic regularizing wfb is Sqrt(Det\texorpdfstring{$^\wedge$}{\string^}2+exp(2 epscut)) and the guiding is the fermionic one wf = Sign Det x Sqrt(Det\texorpdfstring{$^\wedge$}{\string^}2+exp(2 epscut)). abs(table) are the ratio of the bosonic wf. Handles complex matrices for up and down electrons with regularization options.
