Performs Gram-\/\+Schmidt orthogonalization for real matrices using SCALAPACK. 

This subroutine performs Gram-\/\+Schmidt orthogonalization in a metric given by the overlap matrix. It orthogonalizes vectors such that sum\+\_\+kl \mbox{[}over(k,l) \texorpdfstring{$\ast$}{*} psi(k,i) \texorpdfstring{$\ast$}{*} psi(l,j)\mbox{]} = 1 if i=j, 0 otherwise. Supports both serial and parallel (SCALAPACK) execution.
