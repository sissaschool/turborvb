Computes cosine and sine values for plane wave evaluation. 

This subroutine calculates nk pairs of cosine and sine values for a particle located at position x. It evaluates plane wave contributions exp(i\texorpdfstring{$\ast$}{*}k\texorpdfstring{$\ast$}{*}r) = cos(k\texorpdfstring{$\ast$}{*}r) + i\texorpdfstring{$\ast$}{*}sin(k\texorpdfstring{$\ast$}{*}r) for correlation function calculations. Supports 1D, 2D, and 3D systems.
