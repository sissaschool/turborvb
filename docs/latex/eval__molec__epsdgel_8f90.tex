Solve generalized eigenvalue problem for molecular orbitals. 

This subroutine solves the generalized eigenvalue problem for molecular orbitals using singular value decomposition (SVD). It handles both real and complex wavefunctions, symmetric and non-\/symmetric cases, and Pfaffian wavefunctions. The routine performs matrix preconditioning, diagonalization, and eigenvector sorting with proper gauge fixing.
