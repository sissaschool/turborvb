Real Gram-\/\+Schmidt orthogonalization with Euclidean metric

This subroutine performs Gram-\/\+Schmidt orthogonalization of real vectors using the standard Euclidean metric (identity overlap matrix). The algorithm includes numerical stability checks and proper handling of linearly dependent vectors.
