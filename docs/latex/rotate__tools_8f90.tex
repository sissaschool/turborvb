\doxysubsection{Detailed Description}
Tools for rotating atomic and orbital coordinates in Turbo\+RVB. 

Provides routines for rotating atomic positions, molecular orbitals, and determinant matrices using arbitrary rotation angles and axes. Supports real and complex wave functions, and handles all relevant angular momentum channels (s, p, d, f, g, etc.). \begin{DoxyAuthor}{Author}
Turbo\+RVB group 
\end{DoxyAuthor}

2022 
\end{DoxyDate}
