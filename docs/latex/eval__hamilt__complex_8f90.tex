Evaluates complex Hamiltonian eigenvalues and eigenvectors in non-\/orthogonal basis. 

This subroutine computes the first bands eigenvectors of a complex Hamiltonian defined in a non-\/orthogonal basis. It uses the same stable diagonalization algorithm as the real version but handles complex matrices. Supports both serial and parallel (SCALAPACK) execution with k-\/point sampling.
