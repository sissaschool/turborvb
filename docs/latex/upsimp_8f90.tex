Matrix increment utilities for quantum Monte Carlo calculations. 

This module provides subroutines for incrementing matrix elements in quantum Monte Carlo calculations, supporting both real and complex matrices. It handles different matrix types including standard matrices and Pfaffian matrices for paired and unpaired electrons.

The module includes\+:
\begin{DoxyItemize}
\item Real matrix increment with symmetry handling
\item Complex matrix increment with Hermitian/transpose symmetry
\item Support for Pfaffian matrices with up/down electron blocks
\item Proper handling of paired and unpaired electron configurations
\end{DoxyItemize}

This subroutine increments matrix elements in a real matrix, handling different matrix types and symmetry conditions. It supports both standard matrices and Pfaffian matrices for quantum Monte Carlo calculations.

Increment complex matrix elements with symmetry handling. 

This subroutine increments matrix elements in a complex matrix, handling different matrix types and symmetry conditions. It supports both standard matrices and Pfaffian matrices with proper handling of Hermitian and transpose symmetries.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in,out}}  & {\em amat} & Complex matrix to be updated (ndim, \texorpdfstring{$\ast$}{*}) \\
\hline
\mbox{\texttt{in}}  & {\em ndim} & Leading dimension of the matrix \\
\hline
\mbox{\texttt{in}}  & {\em ind} & Linear index of the matrix element to update \\
\hline
\mbox{\texttt{in}}  & {\em value} & Array containing complex value to add to the matrix element \\
\hline
\mbox{\texttt{in}}  & {\em symmagp} & Flag for symmetric matrix updates \\
\hline
\mbox{\texttt{in}}  & {\em ipf} & Flag indicating matrix type\+:
\begin{DoxyItemize}
\item ipf = 1\+: Standard matrix
\item ipf ≠ 1\+: Pfaffian matrix
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Converts linear index to (i,j) matrix coordinates
\item For standard matrices (ipf = 1)\+:
\begin{DoxyItemize}
\item For diagonal elements with Hermitian symmetry, adds real part only
\item For off-\/diagonal elements, adds value(1) to amat(i,j)
\item If symmagp is true, applies Hermitian or transpose symmetry
\end{DoxyItemize}
\item For Pfaffian matrices (ipf ≠ 1)\+:
\begin{DoxyItemize}
\item Adds value(1) to amat(i,j) and subtracts from amat(j,i)
\item Handles up/down electron blocks with proper symmetry
\item Applies Hermitian or transpose symmetry based on yes\+\_\+hermite flag
\item Manages paired and unpaired electron configurations
\end{DoxyItemize}
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
For Hermitian matrices (yes\+\_\+hermite = .true.), uses conjugate symmetry 

For non-\/\+Hermitian matrices, uses transpose symmetry 

Diagonal elements in Hermitian matrices are constrained to be real 

The subroutine handles antisymmetry of Pfaffian matrices 

Used in complex wave function optimization and gradient calculations 
\end{DoxyNote}
