subroutine constrbra\+\_\+complex (\begin{DoxyParamCaption}\item[{integer}]{iesfreer}{, }\item[{integer}]{n3body}{, }\item[{integer, dimension(\texorpdfstring{$\ast$}{*})}]{jbraj}{, }\item[{integer, dimension(\texorpdfstring{$\ast$}{*})}]{nozeroj}{, }\item[{real\texorpdfstring{$\ast$}{*}8, dimension(\texorpdfstring{$\ast$}{*})}]{derjas}{, }\item[{real\texorpdfstring{$\ast$}{*}8, dimension(nw, \texorpdfstring{$\ast$}{*})}]{econf}{, }\item[{integer}]{nw}{, }\item[{integer}]{iopt}{}\end{DoxyParamCaption})}



Complex wave function constraint builder with sparse matrix indexing. 

This subroutine constructs constraints for complex wave functions using sparse matrix indexing. It handles Jastrow factor derivatives and maps them to wave function parameters with support for different symmetry configurations and parameter types.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em iesfreer} & Number of free parameters in the wave function \\
\hline
\mbox{\texttt{in}}  & {\em n3body} & Number of three-\/body terms (Jastrow factors) \\
\hline
\mbox{\texttt{in}}  & {\em jbraj} & Array mapping Jastrow terms to parameter indices \\
\hline
\mbox{\texttt{in}}  & {\em nozeroj} & Array of sparse matrix indices for non-\/zero elements \\
\hline
\mbox{\texttt{in}}  & {\em derjas} & Array of Jastrow derivatives \\
\hline
\mbox{\texttt{in,out}}  & {\em econf} & Energy configuration array to be updated \\
\hline
\mbox{\texttt{in}}  & {\em nw} & Number of walkers \\
\hline
\mbox{\texttt{in}}  & {\em iopt} & Operation mode flag\\
\hline
\end{DoxyParams}
The subroutine handles different configurations based on the following parameters\+:

{\bfseries{Parameter Types (ipc)\+:}}
\begin{DoxyItemize}
\item ipc = 1\+: Real parameters (single array element per parameter)
\item ipc = 2\+: Complex parameters (two array elements per parameter)
\end{DoxyItemize}

{\bfseries{Symmetry Configurations (symmagp)\+:}}
\begin{DoxyItemize}
\item symmagp = .true.\+: AGP symmetry (4 array elements per parameter)
\item symmagp = .false.\+: Standard complex (2 array elements per parameter)
\end{DoxyItemize}

{\bfseries{Operation Modes (iopt)\+:}}
\begin{DoxyItemize}
\item iopt = 0\+: Accumulate derivatives (add to existing values)
\item iopt ≠ 0\+: Replace derivatives (set new values)
\end{DoxyItemize}

{\bfseries{Parameter Mapping Schemes\+:}}
\begin{DoxyItemize}
\item Real parameters (ipc = 1)\+: Direct mapping to single array element
\item Complex AGP (ipc = 2, symmagp = .true.)\+: 4-\/element mapping (4\texorpdfstring{$\ast$}{*}j-\/3, 4\texorpdfstring{$\ast$}{*}j-\/1)
\item Complex standard (ipc = 2, symmagp = .false.)\+: 2-\/element mapping (2\texorpdfstring{$\ast$}{*}j-\/1, 2\texorpdfstring{$\ast$}{*}j)
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The subroutine always initializes the energy configuration array to zero. 

Complex parameters require special handling for real and imaginary parts. 

AGP symmetry introduces additional parameter constraints. 
\end{DoxyNote}
