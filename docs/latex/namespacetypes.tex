\doxysubsection{Detailed Description}
Module defining derived data types for Turbo\+RVB. 

This module contains the definition of various derived data types used throughout the Turbo\+RVB codebase for managing arrays, ion components, k-\/point grids, and wave function factors.\hypertarget{namespacetypes_autotoc_md35}{}\doxysubsubsection{\texorpdfstring{Types}{Types}}\label{namespacetypes_autotoc_md35}
ARRAY\+\_\+\+INT \+: Dynamic integer array Contains an allocatable integer array for flexible storage.

ION\+\_\+\+COMP \+: Ion component information Stores multiplicity and arrays of ion indices and components.

NKGRID \+: k-\/point grid structure Manages k-\/point grid dimensions and processing status.

WF\+\_\+\+FACTOR \+: Wave function factor object Contains parameters and matrices for Jastrow/determinant factors.\hypertarget{namespacetypes_autotoc_md36}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{namespacetypes_autotoc_md36}

\begin{DoxyItemize}
\item All types use allocatable arrays for dynamic memory management.
\item The WF\+\_\+\+FACTOR type is used for both Jastrow and determinant factors.
\item Provides a structured approach to data organization in Turbo\+RVB.
