subroutine convertdec (\begin{DoxyParamCaption}\item[{integer}]{imax}{, }\item[{integer, dimension(6)}]{idigit}{}\end{DoxyParamCaption})}



Convert decimal integer to ASCII digit array. 

This subroutine converts a decimal integer to an array of ASCII digit characters. It extracts each digit from the integer and converts it to its corresponding ASCII representation.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em imax} & Input integer to be converted (0 ≤ imax ≤ 999999) \\
\hline
\mbox{\texttt{out}}  & {\em idigit} & Array of 6 ASCII digit characters (ASCII codes 48-\/57)\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:

{\bfseries{Algorithm\+:}}
\begin{DoxyEnumerate}
\item Extract the most significant digit (100000s place)
\item Calculate remainder and extract next digit (10000s place)
\item Continue for all 6 digits (1000s, 100s, 10s, 1s places)
\item Convert each digit to ASCII by adding 48 (ASCII \textquotesingle{}0\textquotesingle{} = 48)
\end{DoxyEnumerate}

{\bfseries{Digit Extraction\+:}}
\begin{DoxyItemize}
\item idigit(1)\+: 100000s place (imax/100000)
\item idigit(2)\+: 10000s place (remainder/10000)
\item idigit(3)\+: 1000s place (remainder/1000)
\item idigit(4)\+: 100s place (remainder/100)
\item idigit(5)\+: 10s place (remainder/10)
\item idigit(6)\+: 1s place (final remainder)
\end{DoxyItemize}

{\bfseries{ASCII Conversion\+:}} Each digit is converted to ASCII by adding 48\+:
\begin{DoxyItemize}
\item 0 → 48 (ASCII \textquotesingle{}0\textquotesingle{})
\item 1 → 49 (ASCII \textquotesingle{}1\textquotesingle{})
\item ... → ...
\item 9 → 57 (ASCII \textquotesingle{}9\textquotesingle{})
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The input integer should be in the range \mbox{[}0, 999999\mbox{]}. 

The output array contains 6 elements regardless of input value. 

Leading zeros are preserved in the output array. 

This subroutine is commonly used for file naming and string formatting. 
\end{DoxyNote}
