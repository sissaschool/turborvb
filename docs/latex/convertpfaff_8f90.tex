program convertpfaff}



Main program for converting AGP wave functions to Pfaffian wave functions. 

This program converts Antisymmetrized Geminal Power (AGP) wave functions to Pfaffian wave functions. It reads an input fort.\+10\+\_\+in file containing AGP parameters and generates a new fort.\+10\+\_\+new file with Pfaffian parameters.

The conversion process includes\+:
\begin{DoxyItemize}
\item Matrix transformation from AGP to Pfaffian format
\item Spin rotation handling for magnetic systems
\item Unpaired orbital processing
\item Symmetry considerations for up-\/up and down-\/down correlations
\end{DoxyItemize}

Key features\+:
\begin{DoxyItemize}
\item Support for both real and complex wave functions
\item Magnetic moment rotation capabilities
\item Unpaired orbital handling
\item Contracted and uncontracted basis set support 
\end{DoxyItemize}
