\doxysubsection{Detailed Description}
MPI sub-\/communicator management for parallel quantum Monte Carlo. 

This module provides functionality for creating and managing MPI sub-\/communicators used in parallel quantum Monte Carlo calculations. It allows for dynamic creation of smaller communication groups from larger parent communicators, enabling efficient parallel processing with different group sizes.

The module includes\+:
\begin{DoxyItemize}
\item Derived type for sub-\/communicator information
\item Subroutine for creating sub-\/communicators
\item Subroutine for freeing sub-\/communicators
\item Support for both parallel and serial execution modes
\end{DoxyItemize}

Create a new MPI sub-\/communicator from a parent communicator. 

This subroutine creates a new MPI sub-\/communicator containing a subset of processes from the parent communicator. It is useful for creating smaller communication groups for specific parallel operations.


\begin{DoxyParams}[1]{Parameters}

\hline
\mbox{\texttt{out}}  & {\em ierror} & MPI error code\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Allocates rank array for the new communicator
\item Assigns ranks 0 to new\+\_\+size-\/1 to the sub-\/communicator
\item Creates MPI group from the parent communicator
\item Creates new group with specified ranks
\item Creates new communicator from the group
\item Determines rank and membership in the new communicator
\item Frees temporary groups and deallocates arrays
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}

The subroutine handles both parallel and serial execution modes 

Used for creating specialized communication groups in parallel QMC 
\end{DoxyNote}

Free an MPI sub-\/communicator. 

This subroutine properly frees an MPI sub-\/communicator and its associated resources. It ensures clean deallocation of MPI communicator handles to prevent memory leaks.


\begin{DoxyParams}[1]{Parameters}

\hline
\mbox{\texttt{out}}  & {\em ierror} & MPI error code\\

The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Checks if the current process is a member of the sub-\/communicator
\item If yesin = .true., calls MPI\+\_\+\+COMM\+\_\+\+FREE to deallocate the communicator
\item Handles both parallel and serial execution modes
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}

The subroutine is safe to call even if the communicator was not properly created 

Used for cleanup after parallel operations are complete 
\end{DoxyNote}
