Recompute inverse matrix from scratch to avoid deterioration. 

Recomputes the inverse matrix ainv from scratch to avoid deterioration that can occur with many rank-\/1 updates. Handles both real and complex matrices, and supports Pfaffian calculations for paired wave functions. Uses matrix multiplication and factorization to rebuild the inverse.
