\doxysubsection{Detailed Description}
Crystal lattice and coordinate transformation module. 

This module provides comprehensive functionality for handling crystal lattice operations, coordinate transformations between Cartesian and crystal coordinates, periodic boundary conditions, and mapping functions for quantum Monte Carlo calculations in periodic systems.

The module manages\+:
\begin{DoxyItemize}
\item Direct and reciprocal lattice vectors
\item Coordinate transformation matrices
\item Periodic boundary conditions
\item Mapping functions for smooth periodic functions
\item Cell parameters and volume calculations
\end{DoxyItemize}

subroutine cell\+::applypbc (\begin{DoxyParamCaption}\item[{double precision, dimension(3, howmany)}]{s}{, }\item[{integer, intent(in)}]{howmany}{}\end{DoxyParamCaption})}



Apply periodic boundary conditions to coordinates. 

This subroutine applies periodic boundary conditions to a set of coordinates by finding the nearest image within the unit cell.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in,out}}  & {\em s} & Array of coordinates to apply PBC to (3, howmany) \\
\hline
\mbox{\texttt{in}}  & {\em howmany} & Number of coordinate sets to process\\
\hline
\end{DoxyParams}
The algorithm performs the following steps\+:
\begin{DoxyEnumerate}
\item Transform coordinates to crystal coordinates
\item Round to nearest integer multiples of cell dimensions
\item Subtract the integer multiples of lattice vectors
\end{DoxyEnumerate}

This ensures all coordinates lie within the primary unit cell. The method uses conventional distance calculations rather than Wigner-\/\+Seitz cell boundaries, which is valid for most practical purposes since differences only occur at cell boundaries where contributions typically vanish.

\begin{DoxyNote}{Note}
This subroutine is not designed for GPU execution. 

The input array s is modified in-\/place. 
\end{DoxyNote}

subroutine cell\+::initcell (\begin{DoxyParamCaption}\item[{integer}]{nion}{, }\item[{integer}]{nel}{, }\item[{logical}]{yes\+\_\+complex}{}\end{DoxyParamCaption})}



Initialize cell parameters and transformation matrices. 

This subroutine sets up the crystal lattice parameters, computes transformation matrices between Cartesian and crystal coordinates, calculates reciprocal lattice vectors, and initializes periodic boundary condition arrays.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em nion} & Number of ions in the system \\
\hline
\mbox{\texttt{in}}  & {\em nel} & Number of electrons \\
\hline
\mbox{\texttt{in}}  & {\em yes\+\_\+complex} & Flag for complex wave function calculations\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Computes cell parameters from celldm array or uses provided s2r matrix
\item Calculates direct and reciprocal lattice vectors
\item Sets up coordinate transformation matrices
\item Initializes periodic boundary condition neighbor arrays
\item Computes phase factors for wave function periodicity
\item Sets up mapping function parameters
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
For orthorhombic cells, the subroutine assumes a is parallel to x-\/axis and b lies in the xy-\/plane. For general cells, the s2r matrix must be provided. 
\end{DoxyNote}

Core periodic mapping function with multiple variants. 

This function implements various periodic mapping schemes for smooth periodic functions in quantum Monte Carlo calculations. The function ensures f\textquotesingle{}(0) = 1 and f(1/2) = 0 for proper boundary behavior.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em x} & Input coordinate (typically in \mbox{[}-\/0.\+5, 0.\+5\mbox{]} range) \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
map0 Mapped coordinate
\end{DoxyReturn}
The function supports multiple mapping schemes controlled by case\+\_\+map\+:


\begin{DoxyItemize}
\item case 0\+: Sine mapping -\/ f(x) = sin(πx)/π
\item case 1\+: Rational mapping with parameters amap, bmap
\item case 2\+: Power law mapping with 1/6 threshold
\item case 3\+: Double sine mapping -\/ f(x) = sin(2πx)/(2π)
\item case 4\+: Linear-\/rational mapping with 1/4 threshold
\item case 5\+: Cubic-\/rational mapping with 1/4 threshold
\item default\+: Exponential mapping with parameter p = case\+\_\+map -\/ 5
\end{DoxyItemize}

Each mapping ensures\+:
\begin{DoxyItemize}
\item Smooth periodicity over the unit interval
\item Continuous derivatives at boundaries
\item Proper behavior for quantum Monte Carlo sampling
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The function first reduces x to the range \mbox{[}-\/0.\+5, 0.\+5\mbox{]} using xc = x -\/ anint(x), then applies the appropriate mapping. 
\end{DoxyNote}
