\doxysubsection{Detailed Description}
Crystal lattice and coordinate transformation module. 

This module provides comprehensive functionality for handling crystal lattice operations, coordinate transformations between Cartesian and crystal coordinates, periodic boundary conditions, and mapping functions for quantum Monte Carlo calculations in periodic systems.

The module manages\+:
\begin{DoxyItemize}
\item Direct and reciprocal lattice vectors
\item Coordinate transformation matrices
\item Periodic boundary conditions
\item Mapping functions for smooth periodic functions
\item Cell parameters and volume calculations
\end{DoxyItemize}

Apply periodic boundary conditions to coordinates. 

This subroutine applies periodic boundary conditions to a set of coordinates by finding the nearest image within the unit cell.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in,out}}  & {\em s} & Array of coordinates to apply PBC to (3, howmany) \\
\hline
\mbox{\texttt{in}}  & {\em howmany} & Number of coordinate sets to process\\
\hline
\end{DoxyParams}
The algorithm performs the following steps\+:
\begin{DoxyEnumerate}
\item Transform coordinates to crystal coordinates
\item Round to nearest integer multiples of cell dimensions
\item Subtract the integer multiples of lattice vectors
\end{DoxyEnumerate}

This ensures all coordinates lie within the primary unit cell. The method uses conventional distance calculations rather than Wigner-\/\+Seitz cell boundaries, which is valid for most practical purposes since differences only occur at cell boundaries where contributions typically vanish.

\begin{DoxyNote}{Note}
This subroutine is not designed for GPU execution. 

The input array s is modified in-\/place. 
\end{DoxyNote}

Transform coordinates between crystal and Cartesian systems. 

This subroutine transforms atomic positions or k-\/point components between crystallographic and Cartesian coordinates for a set of vectors.


\begin{DoxyParams}[1]{Parameters}

\hline

The transformation is performed using the matrix equation\+:
\begin{DoxyItemize}

The function supports multiple mapping schemes controlled by case\+\_\+map\+:


\begin{DoxyItemize}
\item case 0\+: Sine mapping -\/ f(x) = sin(πx)/π
\item case 1\+: Rational mapping with parameters amap, bmap
\item case 2\+: Power law mapping with 1/6 threshold
\item case 3\+: Double sine mapping -\/ f(x) = sin(2πx)/(2π)
\item case 4\+: Linear-\/rational mapping with 1/4 threshold
\item case 5\+: Cubic-\/rational mapping with 1/4 threshold

\end{DoxyItemize}
