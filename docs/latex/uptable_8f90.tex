Update table and tabler for real wave function ratios. 

Updates the table and tabler arrays for real wave function ratios. The bosonic regularizing wfb is Sqrt(Det\texorpdfstring{$^\wedge$}{\string^}2+exp(2 epscut)) and the guiding is the fermionic one wf = Sign Det x Sqrt(Det\texorpdfstring{$^\wedge$}{\string^}2+exp(2 epscut)). abs(table) are the ratio of the bosonic wf. Handles real matrices for up and down electrons with regularization options.
