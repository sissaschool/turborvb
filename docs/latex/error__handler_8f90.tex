Write and handle error messages for parallel and serial execution. 

This subroutine writes an error message to output. If ierr \texorpdfstring{$<$}{<}= 0, it does nothing. If ierr \texorpdfstring{$>$}{>} 0, it prints the error and stops execution. In parallel execution, it also writes to a crash file and aborts MPI if available.
