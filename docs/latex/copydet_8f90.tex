\doxysubsection{Detailed Description}
Program for copying determinant parameters between Turbo\+RVB wave functions. 

This program reads two Turbo\+RVB wave functions (fort.\+10 and fort.\+10\+\_\+new) and copies determinant parameters from one to the other. It handles orbital mapping, parameter scaling, and supports various modes including k-\/points calculations, ion position copying, and contracted orbital parameter transfer. Similar to \doxylink{copyjas_8f90}{copyjas.\+f90} but for determinant parts.
