\doxysubsection{Detailed Description}
Initial configuration generator for periodic boundary conditions (PBC) 

This module provides routines to generate initial electron configurations for quantum Monte Carlo simulations with periodic boundary conditions. It ensures fair and randomized placement of electrons around ions, handles spin and occupation constraints, and applies PBC as needed. \begin{DoxyAuthor}{Author}
Turbo\+RVB group 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2022 
\end{DoxyDate}
\hypertarget{invsymeps_8f90_Features}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{invsymeps_8f90_Features}

\begin{DoxyItemize}
\item Randomized and fair electron placement around ions
\item Handles spin-\/up and spin-\/down electron constraints
\item Supports electron affinity calculations (nel \texorpdfstring{$>$}{>} ztot)
\item Applies periodic boundary conditions (PBC) if enabled
\item Lattice-\/based initialization if alat is specified
\item Ensures no duplicate electron positions
\item Computes electron-\/ion distances for all walkers 
\end{DoxyItemize}

Generate initial electron configuration for PBC QMC simulations. 

Places electrons around ions with randomized but fair distribution, respecting spin and occupation constraints. Applies PBC and lattice initialization as needed. Ensures no duplicate electron positions. Computes electron-\/ion distances for all walkers.
