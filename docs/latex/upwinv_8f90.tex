Update wave function inverse matrix for real wave functions. 

This subroutine updates the wave function inverse matrix WINV when a single electron (JEL) is moved. The update follows the Sherman-\/\+Morrison formula for rank-\/1 updates of matrix inverses.\hypertarget{upwinv_8f90_autotoc_md75}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{upwinv_8f90_autotoc_md75}
NEL \+: integer, in Number of electrons. JEL \+: integer, in Index of the electron being moved. INDT \+: integer, in Number of basis functions (dimension of orbital space). NELORB \+: integer, in Number of orbitals (unused in current implementation). WINV \+: real\texorpdfstring{$\ast$}{*}8 array, inout Wave function inverse matrix (NEL × INDT). On entry\+: current inverse matrix. On exit\+: updated inverse matrix. V \+: real\texorpdfstring{$\ast$}{*}8 array, in Vector of coefficients for the update (NEL). PSI \+: real\texorpdfstring{$\ast$}{*}8 array, in Wave function matrix (INDT × NEL).\hypertarget{upwinv_8f90_autotoc_md76}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{upwinv_8f90_autotoc_md76}
