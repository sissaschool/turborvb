Updates occupations for k-\/point calculations with Fermi level determination. 

This subroutine computes the Fermi level and Kohn-\/\+Sham orbital occupations for both fixed occupations and smearing methods. It handles both coupled and decoupled k-\/point runs, supports LSDA calculations, and computes entropic contributions for smearing methods.
