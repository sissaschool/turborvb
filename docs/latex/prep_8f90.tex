Main program for DFT preparation and calculations. 

This is the main program for Turbo\+RVB DFT calculations. It initializes the parallel environment, reads input parameters, sets up the calculation environment, and performs either self-\/consistent or non-\/self-\/consistent calculations depending on the input options. Supports both real and complex wavefunctions with k-\/point sampling and LSDA calculations.
