integer function iesdr1iesd (\begin{DoxyParamCaption}\item[{integer}]{iesdr}{}\end{DoxyParamCaption})}



Jastrow factor type mapping function for one-\/body terms. 

This function maps Jastrow factor type codes (iesdr) to specific one-\/body Jastrow factor implementations used in quantum Monte Carlo calculations. It provides a standardized way to determine the appropriate one-\/body Jastrow factor type based on the input parameter.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em iesdr} & Jastrow factor type code \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Integer code representing the specific one-\/body Jastrow factor type
\end{DoxyReturn}
The function performs the following mapping\+:
\begin{DoxyItemize}
\item iesdr = 0\+: No one-\/body Jastrow factor (return 0)
\item iesdr = -\/1\+: Type 1 one-\/body Jastrow factor
\item iesdr = -\/5\+: Type 1 one-\/body Jastrow factor
\item iesdr = -\/15\+: Type 4 one-\/body Jastrow factor (default short range)
\item iesdr = -\/6\+: Type 4 one-\/body Jastrow factor
\item iesdr = -\/7\+: Type 4 one-\/body Jastrow factor
\item iesdr = -\/17\+: Type 1 one-\/body Jastrow factor
\item iesdr = -\/20\+: Type 4 one-\/body Jastrow factor
\item iesdr = -\/21\+: Type 4 one-\/body Jastrow factor
\item Default\+: Type 4 one-\/body Jastrow factor (short range exponential)
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The function provides backward compatibility for different Jastrow factor implementations in Turbo\+RVB 

Type 4 corresponds to the default short range one-\/body exponential Jastrow factor 

Type 1 corresponds to alternative one-\/body Jastrow factor forms 

The function is used in wave function setup and optimization 
\end{DoxyNote}
