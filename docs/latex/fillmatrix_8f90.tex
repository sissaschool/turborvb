subroutine fillmatrix (\begin{DoxyParamCaption}\item[{real\texorpdfstring{$\ast$}{*}8, dimension(3, 3)}]{rotmatrix}{}\end{DoxyParamCaption})}



Generate random 3D rotation matrix with uniform distribution. 

This subroutine creates a random 3x3 rotation matrix with uniform distribution over the SO(3) group. The algorithm generates three orthonormal vectors to form the rotation matrix columns.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{out}}  & {\em rotmatrix} & 3x3 rotation matrix to be filled\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Generates a random unit vector x using spherical coordinates\+:
\begin{DoxyItemize}
\item Random cos(theta) from \mbox{[}-\/1, 1\mbox{]}
\item Random phi from \mbox{[}0, 2π\mbox{]}
\end{DoxyItemize}
\item Finds a stable orthogonal vector y to x by choosing the component with maximum magnitude and setting others appropriately
\item Applies a random rotation around the x-\/axis to y
\item Computes the third vector z as the cross product x × y
\item Normalizes all vectors and assembles the rotation matrix
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The algorithm ensures numerical stability by choosing the largest component for orthogonalization 

The resulting matrix is guaranteed to be orthogonal with determinant +1 (proper rotation) 

The distribution is uniform over the SO(3) group 

The subroutine includes error checking for orthogonality 
\end{DoxyNote}

Matrix generation utilities for rotation matrices. 

This module provides subroutines for generating rotation matrices used in quantum Monte Carlo calculations. It includes functions for creating random rotation matrices and rotation matrices around specific axes.

The module implements algorithms for\+:
\begin{DoxyItemize}
\item Generating random 3D rotation matrices with uniform distribution
\item Creating rotation matrices that preserve a given axis direction
\item Ensuring orthogonality and proper normalization of rotation matrices
\end{DoxyItemize}

Generate rotation matrix preserving a given axis direction

This subroutine creates a unitary rotation matrix that leaves unchanged the axis defined by the input vector vecr. The rotation is performed around this axis with a random angle.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in,out}}  & {\em rotmatrix} & 3x3 rotation matrix to be filled \\
\hline
\mbox{\texttt{in}}  & {\em vecr} & 3D vector defining the rotation axis\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Normalizes the input vector vecr to unit length
\item Constructs a complex anti-\/\+Hermitian matrix A from the normalized vector
\item Diagonalizes A to find eigenvalues and eigenvectors
\item Applies a random phase factor to the eigenvalues
\item Reconstructs the rotation matrix using the formula R = exp(i\texorpdfstring{$\ast$}{*}\+A)
\item Multiplies the result with the existing rotation matrix
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The algorithm uses complex matrix diagonalization to ensure proper rotation matrix properties 

The rotation angle is randomly chosen from \mbox{[}0, 2π\mbox{]} 

The input vector is automatically normalized if non-\/zero 

If the input vector is zero, the result is undefined 
\end{DoxyNote}
