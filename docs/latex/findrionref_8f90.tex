Ion reference position optimization for periodic boundary conditions. 

This module provides functionality for finding optimal reference positions for ions in periodic systems, particularly useful for quantum Monte Carlo calculations with periodic boundary conditions.

The module includes\+:

Find optimal reference position for ions in periodic system

This subroutine determines an optimal reference position that maximizes the minimum distance between ions in a periodic system. It analyzes the gaps between ion positions along a given direction and shifts the reference to the center of the largest gap.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em nion} & Number of ions in the system \\
\hline
\mbox{\texttt{in}}  & {\em a} & Periodicity length along the direction of interest \\
\hline
\mbox{\texttt{in}}  & {\em rion} & Array of ion positions (3, nion) \\
\hline
\mbox{\texttt{in,out}}  & {\em ref} & Reference position (updated to optimal position) \\
\hline
\mbox{\texttt{out}}  & {\em mindist} & Minimum distance between ions after optimization\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Computes periodic coordinates for all ions using setint function
\item Sorts ions by their periodic coordinates
\item Calculates gaps between consecutive ions in periodic space
\item Handles the wrap-\/around gap between the last and first ion
\item Finds the largest gap and its center position
\item Shifts the reference position to the center of the largest gap
\item Updates mindist to half the largest gap size
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The subroutine works in 1D along the x-\/direction of ion positions 

For single ion systems, the gap is set to the full periodicity length 

The optimal reference maximizes the minimum distance between any two ions 

The subroutine modifies the input ref parameter to the optimal position 

mindist represents the radius of the largest possible sphere around any ion that doesn\textquotesingle{}t contain other ions 
\end{DoxyNote}

Compute periodic modulo operation. 

This function computes the periodic modulo operation, mapping any real number to the interval \mbox{[}0, a) where a is the periodicity length. It handles both positive and negative input values correctly.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em x} & Input value to be mapped to periodic interval \\
\hline
\mbox{\texttt{in}}  & {\em a} & Periodicity length \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Real value in the interval \mbox{[}0, a)
\end{DoxyReturn}
The function performs the following operations\+:
\begin{DoxyEnumerate}
\item For positive x\+: computes x mod a using integer division
\item For negative x\+: computes (x + n\texorpdfstring{$\ast$}{*}a + a) mod a where n = floor(-\/x/a)
\item Ensures the result is always in the interval \mbox{[}0, a)
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The function is equivalent to fmod(x, a) but handles negative values correctly for periodic boundary conditions 

For x ≥ 0\+: result = x -\/ floor(x/a) \texorpdfstring{$\ast$}{*} a 

For x \texorpdfstring{$<$}{<} 0\+: result = x + floor(-\/x/a) \texorpdfstring{$\ast$}{*} a + a 

The result is always non-\/negative and less than a 
\end{DoxyNote}
