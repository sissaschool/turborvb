\doxysubsection{Detailed Description}
Matrix descriptor module for parallel block-\/cyclic distribution. 

This module provides data structures and utility routines for describing and managing block-\/cyclic distributed matrices on a 2D processor grid. It is designed for use with Cannon\textquotesingle{}s algorithm and other parallel matrix operations in scientific computing. The module supports both real and complex matrices, and provides routines for descriptor initialization, local/global index mapping, and parallel redistribution.

The descriptor array encodes the local/global structure of a distributed matrix, including block sizes, processor grid coordinates, and MPI communicator information. This enables efficient parallel matrix multiplication and redistribution, especially in quantum chemistry and electronic structure calculations.

\begin{DoxyNote}{Note}
This module is used throughout Turbo\+RVB for distributed linear algebra. 
\end{DoxyNote}

Redistribute a real matrix from block-\/cyclic to cyclic distribution. 

This subroutine redistributes a real matrix B, initially distributed in block-\/cyclic fashion on a 2D processor grid, into a cyclically distributed matrix A by rows across processors. subroutine descriptors\+::cyc2blk\+\_\+zredist (\begin{DoxyParamCaption}\item[{integer, intent(in)}]{n}{, }\item[{\mbox{\hyperlink{structcomplex}{complex}}(8), dimension(lda, \texorpdfstring{$\ast$}{*})}]{a}{, }\item[{integer, intent(in)}]{lda}{, }\item[{\mbox{\hyperlink{structcomplex}{complex}}(8), dimension(ldb, \texorpdfstring{$\ast$}{*})}]{b}{, }\item[{integer, intent(in)}]{ldb}{, }\item[{integer, dimension(\texorpdfstring{$\ast$}{*})}]{desc}{}\end{DoxyParamCaption})}



Redistribute a complex matrix from cyclic to block-\/cyclic distribution. 

This subroutine redistributes a complex matrix A, initially distributed cyclically by rows across processors, into a block-\/cyclic distributed matrix B on a 2D processor grid. It uses MPI communication to gather and scatter matrix blocks as needed.\hypertarget{namespacedescriptors_autotoc_md15}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{namespacedescriptors_autotoc_md15}
n \+: integer, in Global matrix dimension (number of rows/columns). a \+: complex\texorpdfstring{$\ast$}{*}16 array, in Input matrix, cyclically distributed by rows (size lda × \texorpdfstring{$\ast$}{*}). lda \+: integer, in Leading dimension of the input matrix. b \+: complex\texorpdfstring{$\ast$}{*}16 array, out Output matrix, block-\/cyclic distributed (size ldb × \texorpdfstring{$\ast$}{*}). ldb \+: integer, in Leading dimension of the output matrix. desc \+: integer array, in Descriptor array describing the block-\/cyclic distribution.\hypertarget{namespacedescriptors_autotoc_md16}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{namespacedescriptors_autotoc_md16}

\begin{DoxyItemize}
\item Only square processor grids are supported.
\item Uses MPI\+\_\+\+Allgather and MPI\+\_\+\+Gather for communication.
\item Performs error checking for block sizes and processor mesh.
\item Serial fallback simply copies the matrix.
\end{DoxyItemize}\hypertarget{namespacedescriptors_autotoc_md17}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{namespacedescriptors_autotoc_md17}

Initialize a block-\/cyclic matrix descriptor for parallel distribution. 

Sets up the descriptor array for a block-\/cyclic distributed matrix on a square processor grid. Handles both local and global matrix properties, including block sizes, processor coordinates, and MPI communicator info.\hypertarget{namespacedescriptors_autotoc_md3}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{namespacedescriptors_autotoc_md3}
desc \+: integer array, out Descriptor array to be initialized. n \+: integer, in Size of the matrix (number of rows/columns). nx \+: integer, in Maximum size among matrices sharing this descriptor. np \+: integer array(2), in Number of processors in each grid dimension (must be square). me \+: integer array(2), in Processor coordinates in the grid. comm \+: integer, in MPI communicator. includeme \+: integer, in If 1, include this processor in the distribution; else, set as inactive.\hypertarget{namespacedescriptors_autotoc_md4}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{namespacedescriptors_autotoc_md4}

\begin{DoxyItemize}
\item Only square processor grids are supported.
\item Handles both block and cyclic distributions for advanced parallelism.
\item Performs error checking on all input parameters and computed values.

This subroutine enforces symmetry (A = A\texorpdfstring{$^\wedge$}{\string^}T) on a real square matrix distributed in block-\/cyclic fashion across a 2D processor grid. subroutine descriptors\+::zsqmher (\begin{DoxyParamCaption}\item[{integer, intent(in)}]{n}{, }\item[{\mbox{\hyperlink{structcomplex}{complex}}(8), dimension(lda, lda)}]{a}{, }\item[{integer, intent(in)}]{lda}{, }\item[{integer, dimension(\mbox{\hyperlink{namespacedescriptors_a758e186675b4b0d4e1d62bb4b0f7869e}{descla\+\_\+siz\+\_\+}}), intent(in)}]{desc}{}\end{DoxyParamCaption})}



Hermitianize a distributed complex square matrix in parallel. 

This subroutine enforces Hermitian symmetry (A = A\texorpdfstring{$^\wedge$}{\string^}†) on a complex square matrix distributed in block-\/cyclic fashion across a 2D processor grid. It uses MPI communication to exchange off-\/diagonal blocks and ensures that the resulting matrix is Hermitian on all processors.\hypertarget{namespacedescriptors_autotoc_md9}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{namespacedescriptors_autotoc_md9}
n \+: integer, in Global matrix dimension (number of rows/columns). a \+: complex\texorpdfstring{$\ast$}{*}16 array, inout Local block of the distributed matrix (size lda × lda). lda \+: integer, in Leading dimension of the local block. desc \+: integer array, in Descriptor array describing the matrix distribution.\hypertarget{namespacedescriptors_autotoc_md10}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{namespacedescriptors_autotoc_md10}

\begin{DoxyItemize}
\item For diagonal blocks, Hermitian symmetry is enforced locally.
\item For off-\/diagonal blocks, MPI is used to exchange and conjugate-\/transpose blocks.
\item Only active processors (desc(lambda\+\_\+node\+\_\+) \texorpdfstring{$>$}{>} 0) participate.
\item Error checking is performed for matrix dimensions and leading dimensions.
\end{DoxyItemize}\hypertarget{namespacedescriptors_autotoc_md11}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{namespacedescriptors_autotoc_md11}
Used in distributed matrix-\/matrix multiplication to ensure Hermitian results. Only active processors participate

Super-\/diagonal block\+: send block to sub-\/diagonal processor

Sub-\/diagonal block\+: receive block, transpose and conjugate locally

Serial\+: enforce Hermitian symmetry locally for full matrix
