\doxysubsection{Detailed Description}
Matrix descriptor module for parallel block-\/cyclic distribution. 

This module provides data structures and utility routines for describing and managing block-\/cyclic distributed matrices on a 2D processor grid. It is designed for use with Cannon\textquotesingle{}s algorithm and other parallel matrix operations in scientific computing. The module supports both real and complex matrices, and provides routines for descriptor initialization, local/global index mapping, and parallel redistribution.

The descriptor array encodes the local/global structure of a distributed matrix, including block sizes, processor grid coordinates, and MPI communicator information. This enables efficient parallel matrix multiplication and redistribution, especially in quantum chemistry and electronic structure calculations.

\begin{DoxyNote}{Note}
This module is used throughout Turbo\+RVB for distributed linear algebra. 
\end{DoxyNote}
