Computes S\texorpdfstring{$^\wedge$}{\string^}2 operator for spin-\/flip calculations. 

This subroutine explores the spin-\/swaps of all anti-\/parallel e-\/e pairs and computes the S\texorpdfstring{$^\wedge$}{\string^}2 operator. It handles both determinant and Jastrow contributions to the spin-\/squared expectation value for both contracted and uncontracted cases.
