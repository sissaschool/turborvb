\doxysubsection{Detailed Description}
Total angle module for molecular mechanics energy averages. 

This module provides variables for accumulating and averaging molecular mechanics energy contributions in QM/\+MM calculations.

The module contains\+:
\begin{DoxyItemize}
\item Counters for different types of interactions
\item Running averages and squared averages
\item Error estimates for each interaction type
\item MPI parallelization support for statistics
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Used for statistical analysis of MM energy contributions 

Supports both serial and parallel calculations 
\end{DoxyNote}
