\doxysubsection{Detailed Description}
Physical and mathematical constants module for quantum Monte Carlo calculations. 

This module provides a comprehensive collection of physical and mathematical constants used throughout the Turbo\+RVB quantum Monte Carlo code. It includes fundamental mathematical constants, SI physical constants, atomic units, and various unit conversion factors.

The constants are organized into several categories\+:
\begin{DoxyItemize}
\item Mathematical constants (pi, sqrt2, etc.)
\item SI physical constants (Planck\textquotesingle{}s constant, Boltzmann constant, etc.)
\item Atomic units and conversion factors
\item Numerical precision parameters
\item Compatibility constants for legacy code
\end{DoxyItemize}

All constants are defined as double precision parameters for maximum accuracy in quantum mechanical calculations.
