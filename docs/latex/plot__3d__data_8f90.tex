3D data visualization output in XCry\+SDen format 

This subroutine generates 3D data visualization files in XCry\+SDen (.xsf) format for quantum Monte Carlo calculations. It outputs crystal structure information and 3D data grids that can be visualized using XCry\+SDen or similar software.

The subroutine handles unit conversion from atomic units to Angstroms and supports both periodic and non-\/periodic systems with proper file naming conventions.

The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Checks file unit availability and opens output file
\item Converts all units from atomic units to Angstroms\+:
\begin{DoxyItemize}
\item Cell dimensions, scaling factors, origin, and positions
\item Data grid values (divided by length\+\_\+unit\texorpdfstring{$^\wedge$}{\string^}3)
\end{DoxyItemize}
\item Writes XCry\+SDen format header\+:
\begin{DoxyItemize}
\item CRYSTAL section with primitive vectors
\item PRIMCOORD section with atomic positions and charges
\end{DoxyItemize}
\item Writes 3D data grid section\+:
\begin{DoxyItemize}
\item BEGIN\+\_\+\+BLOCK\+\_\+\+DATAGRID\+\_\+3D header
\item Grid dimensions and origin
\item Primitive vectors for grid orientation
\item Data values in optimized format (3 values per line)
\end{DoxyItemize}
\item Closes the output file
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
Output filename format\+: output\+\_\+$<$word$>$$<$indmol$>$.xsf 

The subroutine handles both scalar (ipc=1) and vector (ipc=3) data 

Data is written in chunks of 3 values per line for efficiency 

Used for visualizing electron density, wave functions, and other quantum mechanical properties 

Compatible with XCry\+SDen, VESTA, and other visualization software 
\end{DoxyNote}
