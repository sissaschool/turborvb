Global error checking and synchronization for parallel execution. 

This subroutine provides global error checking across all MPI processes and ensures proper synchronization for error handling in parallel quantum Monte Carlo calculations.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em iflagerr} & Local error flag for current process \\
\hline
\mbox{\texttt{in}}  & {\em rank} & MPI rank of the calling process \\
\hline
\mbox{\texttt{in}}  & {\em messag} & Error message to display if global error exists\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Performs global reduction of error flags across all MPI processes
\item If any process has an error (iflagerrall != 0)\+:
\begin{DoxyItemize}
\item Rank 0 displays the error message
\item For unreliable networks, synchronizes with barrier
\item Frees MPI communicators if k-\/point averaging is active
\item Finalizes MPI and terminates all processes
\end{DoxyItemize}
\item If no global errors, subroutine returns normally
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
This subroutine must be called by ALL MPI processes, not just rank 0 

Do not use this subroutine inside rank.\+eq.\+0 regions 

The subroutine handles both reliable and unreliable network configurations 

For k-\/point averaging calculations, it properly cleans up MPI communicators 
\end{DoxyNote}

Error handling and reporting utilities for Turbo\+RVB. 

This module provides comprehensive error handling and reporting functionality for the Turbo\+RVB quantum Monte Carlo code. It includes subroutines for warning messages, fatal error termination, and parallel error synchronization.

The module supports both serial and parallel execution modes, with proper MPI coordination for error handling across multiple processes.

Report errors and warnings with MPI-\/aware handling

This subroutine provides centralized error reporting for Turbo\+RVB calculations. It handles both warnings (ierror \texorpdfstring{$<$}{<} 0) and fatal errors (ierror \texorpdfstring{$>$}{>} 0) with appropriate MPI coordination for parallel execution.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em routin} & Name of the calling routine for error identification \\
\hline
\mbox{\texttt{in}}  & {\em messag} & Error or warning message to display \\
\hline
\mbox{\texttt{in}}  & {\em ierror} & Error code\+:
\begin{DoxyItemize}
\item ierror \texorpdfstring{$<$}{<} 0\+: Warning (program continues)
\item ierror = 0\+: No error (subroutine returns immediately)
\item ierror \texorpdfstring{$>$}{>} 0\+: Fatal error (program terminates) 
\end{DoxyItemize}\\
\hline
\mbox{\texttt{in}}  & {\em rank} & MPI rank of the calling process\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item For warnings (ierror \texorpdfstring{$<$}{<} 0)\+:
\begin{DoxyItemize}
\item Displays warning message with routine name and error code
\item Only rank 0 outputs the message
\item Program continues execution
\end{DoxyItemize}
\item For fatal errors (ierror \texorpdfstring{$>$}{>} 0)\+:
\begin{DoxyItemize}
\item Displays error message with routine name and error code
\item For ierror = 3, all ranks output their rank number
\item Otherwise, only rank 0 outputs the error
\item Terminates all MPI processes and stops the program
\end{DoxyItemize}
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The subroutine uses formatted output with separator lines for clear visual distinction of error messages 

For parallel execution, MPI\+\_\+\+ABORT is called to ensure all processes terminate when a fatal error occurs 

Error code 3 is special and causes all ranks to output their rank number 
\end{DoxyNote}
