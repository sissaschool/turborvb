\doxysubsection{Detailed Description}
External forces calculation module for Turbo\+RVB. 

This module provides comprehensive force calculations for QMC/\+MM (Quantum Monte Carlo/\+Molecular Mechanics) simulations, including external potential forces, van der Waals forces, and molecular mechanics restraints. \begin{DoxyAuthor}{Author}
E. Coccia (4/1/11)
