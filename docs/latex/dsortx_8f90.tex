\doxysubsection{Detailed Description}
Sorting and parallel grid utilities for scientific computing. 

This file provides a robust, double-\/precision sorting routine (DSORTX) and several grid/parallelization utilities for use in quantum Monte Carlo and electronic structure codes. The DSORTX subroutine implements a hybrid quicksort-\/ bubble sort algorithm for sorting arrays and returning the permutation indices. Additional routines support processor grid decomposition and distributed array indexing, as used in parallel linear algebra and FFTs.
