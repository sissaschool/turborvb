\doxysubsection{Detailed Description}
Splines module for interpolation of external potentials. 

This module provides data structures and variables for handling spline interpolation of external potentials on 3D grids.

The module contains\+:
\begin{DoxyItemize}
\item Spline orders and knot numbers for each dimension
\item Spline coefficients for 3D interpolation
\item Knot positions and grid spacing
\item Current position for interpolation
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Used for efficient evaluation of external potentials 

Supports cubic spline interpolation in 3D 
\end{DoxyNote}
