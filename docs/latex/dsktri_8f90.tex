Invert a skew-\/symmetric matrix using LU decomposition. 

This subroutine computes the inverse of a skew-\/symmetric matrix A using the LU decomposition A = L\texorpdfstring{$\ast$}{*}\+U\texorpdfstring{$\ast$}{*}P, where P is a permutation matrix. The inverse is computed as A\texorpdfstring{$^\wedge$}{\string^}(-\/1) = P\texorpdfstring{$^\wedge$}{\string^}T \texorpdfstring{$\ast$}{*} U\texorpdfstring{$^\wedge$}{\string^}(-\/1) \texorpdfstring{$\ast$}{*} L\texorpdfstring{$^\wedge$}{\string^}(-\/1).\hypertarget{dsktri_8f90_autotoc_md27}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{dsktri_8f90_autotoc_md27}
UPLO \+: character, in Specifies which part of the matrix A is stored\+: \textquotesingle{}U\textquotesingle{} or \textquotesingle{}u\textquotesingle{}\+: Upper triangular part is stored. \textquotesingle{}L\textquotesingle{} or \textquotesingle{}l\textquotesingle{}\+: Lower triangular part is stored. N \+: integer, in Order of the matrix A. A \+: real\texorpdfstring{$\ast$}{*}8 array, in The skew-\/symmetric matrix A, stored in packed format. On entry, contains the LU factors from DSKTRF. LDA \+: integer, in Leading dimension of array A. AINV \+: real\texorpdfstring{$\ast$}{*}8 array, out The inverse of matrix A. LDINV \+: integer, in Leading dimension of array AINV. IPIV \+: integer array, in Pivot indices from DSKTRF; dimension at least N. WORK \+: real\texorpdfstring{$\ast$}{*}8 array, work Workspace array; dimension at least N\texorpdfstring{$^\wedge$}{\string^}2 + 12\texorpdfstring{$\ast$}{*}N -\/ 2. INFO \+: integer, out = 0\+: successful exit. \texorpdfstring{$<$}{<} 0\+: if INFO = -\/i, the i-\/th argument had an illegal value. \texorpdfstring{$>$}{>} 0\+: if INFO = i, U(i,i) is exactly zero; the matrix is singular.\hypertarget{dsktri_8f90_autotoc_md28}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{dsktri_8f90_autotoc_md28}

\begin{DoxyItemize}
\item Assumes that DSKTRF has been called previously to factorize A.
\item Uses a three-\/step process\+: permutation, triangular solve, permutation.
\item Supports both upper and lower triangular storage formats.
\item The algorithm handles the special structure of skew-\/symmetric matrices.
\end{DoxyItemize}\hypertarget{dsktri_8f90_autotoc_md29}{}\doxysubsubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{dsktri_8f90_autotoc_md29}

\begin{DoxyEnumerate}
\item Initialize AINV as identity matrix
\item Apply first permutation (reverse order)
\item Extract skew-\/symmetric elements and prepare for triangular solve
\item Solve triangular system using DTRTRS
\item Solve tridiagonal system using DSKTRS or DGTSVX
\item Solve triangular system with transpose
\item Apply final permutation
\end{DoxyEnumerate}\hypertarget{dsktri_8f90_autotoc_md30}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{dsktri_8f90_autotoc_md30}
