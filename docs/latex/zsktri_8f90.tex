Invert a complex skew-\/symmetric matrix using LU decomposition. 

This subroutine computes the inverse of a complex skew-\/symmetric matrix A using the LU decomposition A = L\texorpdfstring{$\ast$}{*}\+U\texorpdfstring{$\ast$}{*}P, where P is a permutation matrix. The inverse is computed as A\texorpdfstring{$^\wedge$}{\string^}(-\/1) = P\texorpdfstring{$^\wedge$}{\string^}T \texorpdfstring{$\ast$}{*} U\texorpdfstring{$^\wedge$}{\string^}(-\/1) \texorpdfstring{$\ast$}{*} L\texorpdfstring{$^\wedge$}{\string^}(-\/1).\hypertarget{zsktri_8f90_autotoc_md106}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{zsktri_8f90_autotoc_md106}
UPLO \+: character, in Specifies which part of the matrix A is stored\+: \textquotesingle{}U\textquotesingle{} or \textquotesingle{}u\textquotesingle{}\+: Upper triangular part is stored. \textquotesingle{}L\textquotesingle{} or \textquotesingle{}l\textquotesingle{}\+: Lower triangular part is stored. N \+: integer, in Order of the matrix A. A \+: complex\texorpdfstring{$\ast$}{*}16 array, in The complex skew-\/symmetric matrix A, stored in packed format. On entry, contains the LU factors from ZSKTRF. LDA \+: integer, in Leading dimension of array A. AINV \+: complex\texorpdfstring{$\ast$}{*}16 array, out The inverse of matrix A. LDINV \+: integer, in Leading dimension of array AINV. IPIV \+: integer array, in Pivot indices from ZSKTRF; dimension at least N. WORK \+: complex\texorpdfstring{$\ast$}{*}16 array, work Workspace array; dimension at least N\texorpdfstring{$^\wedge$}{\string^}2 + 12\texorpdfstring{$\ast$}{*}N -\/ 2. INFO \+: integer, out = 0\+: successful exit. \texorpdfstring{$<$}{<} 0\+: if INFO = -\/i, the i-\/th argument had an illegal value. \texorpdfstring{$>$}{>} 0\+: if INFO = i, U(i,i) is exactly zero; the matrix is singular.\hypertarget{zsktri_8f90_autotoc_md107}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{zsktri_8f90_autotoc_md107}

\begin{DoxyItemize}
\item Assumes that ZSKTRF has been called previously to factorize A.
\item Uses a three-\/step process\+: permutation, triangular solve, permutation.
\item Supports both upper and lower triangular storage formats.
\item The algorithm handles the special structure of complex skew-\/symmetric matrices.
\item Complex arithmetic is used throughout the computation.
\end{DoxyItemize}\hypertarget{zsktri_8f90_autotoc_md108}{}\doxysubsubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{zsktri_8f90_autotoc_md108}

\begin{DoxyEnumerate}
\item Initialize AINV as identity matrix
\item Apply first permutation (reverse order)
\item Extract skew-\/symmetric elements and prepare for triangular solve
\item Solve triangular system using ZTRTRS
\item Solve tridiagonal system using ZSKTRS or ZGTSVX
\item Solve triangular system with transpose
\item Apply final permutation
