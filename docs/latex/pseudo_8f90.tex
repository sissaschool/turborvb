program pseudo}



Pseudopotential analysis and conversion program for Turbo\+RVB. 

This program reads pseudopotential data from pseudo.\+dat and analyzes the pseudopotential functions. It can suggest appropriate cutoff radii and convert pseudopotential data to different formats. The program outputs plotting data and can rewrite the pseudopotential file with optimized parameters.
