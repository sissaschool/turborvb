\doxysubsection{Detailed Description}
Module for dipole and quadrupole moment calculations. 

This module provides functionality for computing dipole and quadrupole moments of molecular systems. It includes subroutines for calculating electronic and nuclear contributions to these multipole moments and diagonalizing the quadrupole tensor.
