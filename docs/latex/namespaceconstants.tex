\doxysubsection{Detailed Description}
Physical and mathematical constants for quantum Monte Carlo calculations. 

This module defines all physical constants, mathematical constants, and unit conversion factors used throughout the Turbo\+RVB codebase for quantum Monte Carlo calculations in atomic and molecular systems.

\begin{DoxyNote}{Note}
About measurement units\+: The program works internally with atomic units\+:
\begin{DoxyItemize}
\item Length → Bohr radius (= 0.\+52917 Å)
\item Energy → Hartree (= 27.\+211383 eV)
\item Mass → Electron mass (9.\+10938291×10⁻³¹ kg)
\item Unit mass = 1/12 C₁₂ (1.\+660538921×10⁻²⁷ kg)
\item Time → 2.\+4188843×10⁻¹⁷ s
\end{DoxyItemize}
\end{DoxyNote}
Input/output units are\+:
\begin{DoxyItemize}
\item Length → Ångström
\item Energy → eV
\item Mass → amu (= 1/12 Carbon mass)
\item Time → fs (10⁻¹⁵ s)
\item Pressure → kbar
\end{DoxyItemize}
