Parallel matrix-\/matrix multiplication with MPI distribution. 

This subroutine performs matrix-\/matrix multiplication C = α\texorpdfstring{$\ast$}{*}\+A\texorpdfstring{$\ast$}{*}B + β\texorpdfstring{$\ast$}{*}C in parallel using MPI. The K dimension is distributed across processors, with each processor computing a partial result that is then reduced to form the final result.\hypertarget{dgemm__my_8f90_autotoc_md24}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{dgemm__my_8f90_autotoc_md24}
TRANSA \+: character\texorpdfstring{$\ast$}{*}1, in Transpose flag for matrix A (\textquotesingle{}N\textquotesingle{}=no transpose, \textquotesingle{}T\textquotesingle{}=transpose). TRANSB \+: character\texorpdfstring{$\ast$}{*}1, in Transpose flag for matrix B (\textquotesingle{}N\textquotesingle{}=no transpose, \textquotesingle{}T\textquotesingle{}=transpose). M \+: integer, in Number of rows in matrices A and C. N \+: integer, in Number of columns in matrices B and C. K \+: integer, in Number of columns in A and rows in B (distributed dimension). ALPHA \+: double precision, in Scalar multiplier for A\texorpdfstring{$\ast$}{*}B. A \+: double precision array, in Input matrix A (size depends on TRANSA). LDA \+: integer, in Leading dimension of matrix A. B \+: double precision array, in Input matrix B (size depends on TRANSB). LDB \+: integer, in Leading dimension of matrix B. BETA \+: double precision, in Scalar multiplier for C. C \+: double precision array, inout Input/output matrix C (M × N). LDC \+: integer, in Leading dimension of matrix C. nproc \+: integer, in Number of MPI processes. rank \+: integer, in MPI rank of current process. comm\+\_\+mpi \+: integer, in MPI communicator.\hypertarget{dgemm__my_8f90_autotoc_md25}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{dgemm__my_8f90_autotoc_md25}

\begin{DoxyItemize}
\item The K dimension is distributed across processors for parallel computation.
\item Each processor computes a partial matrix multiplication with its local K slice.
\item Results are reduced using MPI to form the final matrix C.
\item Only rank 0 applies the BETA scaling; other ranks start with zero.
\item Supports all four combinations of transpose operations (NN, NT, TN, TT).
\end{DoxyItemize}\hypertarget{dgemm__my_8f90_autotoc_md26}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{dgemm__my_8f90_autotoc_md26}
