Solve complex skew-\/symmetric tridiagonal system A\texorpdfstring{$\ast$}{*}X = B. 

This subroutine solves the linear system A\texorpdfstring{$\ast$}{*}X = B where A is a non-\/singular complex skew-\/symmetric tridiagonal matrix of even dimension n. The matrix A is stored in packed format with A(i+1,i) = a(i) and A(i,i+1) = -\/a(i) for i = 1, ..., n-\/1.\hypertarget{zsktrs_8f90_autotoc_md110}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{zsktrs_8f90_autotoc_md110}
UPLO \+: character, in Specifies which part of the matrix A is stored\+: \textquotesingle{}U\textquotesingle{} or \textquotesingle{}u\textquotesingle{}\+: Upper triangular part is stored (A(i,i+1) = a(i)). \textquotesingle{}L\textquotesingle{} or \textquotesingle{}l\textquotesingle{}\+: Lower triangular part is stored (A(i+1,i) = a(i)). N \+: integer, in Order of the matrix A (must be even). NHRS \+: integer, in Number of right-\/hand sides. A \+: complex\texorpdfstring{$\ast$}{*}16 array, in The complex skew-\/symmetric tridiagonal matrix stored in packed format. For UPLO = \textquotesingle{}U\textquotesingle{}\+: A(i,i+1) = a(i), i = 1, ..., n-\/1. For UPLO = \textquotesingle{}L\textquotesingle{}\+: A(i+1,i) = a(i), i = 1, ..., n-\/1. B \+: complex\texorpdfstring{$\ast$}{*}16 array, inout Right-\/hand side matrix (N × NHRS). On exit, contains the solution X. LDB \+: integer, in Leading dimension of array B. X \+: complex\texorpdfstring{$\ast$}{*}16 array, work Workspace array for storing intermediate results. INFO \+: integer, out = 0\+: successful exit. \texorpdfstring{$<$}{<} 0\+: if INFO = -\/i, the i-\/th argument had an illegal value. \texorpdfstring{$>$}{>} 0\+: if INFO = i, A(i,i+1) is exactly zero; the matrix is singular.\hypertarget{zsktrs_8f90_autotoc_md111}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{zsktrs_8f90_autotoc_md111}

\begin{DoxyItemize}
\item The matrix A must be of even dimension n.
\item The solution is computed using forward and backward substitution.
\item Even-\/indexed variables are solved forward, odd-\/indexed backward.
\item The algorithm exploits the special structure of complex skew-\/symmetric matrices.
\item For UPLO = \textquotesingle{}L\textquotesingle{}, the signs of the matrix elements are temporarily flipped.
\item Complex arithmetic is used throughout the computation.
\end{DoxyItemize}\hypertarget{zsktrs_8f90_autotoc_md112}{}\doxysubsubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{zsktrs_8f90_autotoc_md112}

\begin{DoxyEnumerate}
\item For UPLO = \textquotesingle{}L\textquotesingle{}, flip signs of matrix elements
\item Solve even-\/indexed variables forward\+: x(2), x(4), ..., x(n)
\item Solve odd-\/indexed variables backward\+: x(n-\/1), x(n-\/3), ..., x(1)
\item Copy solution back to B
\item Restore original matrix signs if needed
\end{DoxyEnumerate}\hypertarget{zsktrs_8f90_autotoc_md113}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{zsktrs_8f90_autotoc_md113}
