Translates constrained Jastrow parameter changes to unconstrained representation. 

This subroutine handles the transformation of constrained Jastrow parameter changes back to their original unconstrained representation. It is specifically designed for handling complex wave functions and 3-\/body Jastrow terms.

The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Maps constrained Jastrow parameters to their original positions using jbraj array
\item Handles both real (ipc=1) and complex (ipc=2) wave functions
\item Supports sign-\/flipped parameter mapping for constraint handling
\item Specifically designed for 3-\/body Jastrow correlation functions
\end{DoxyEnumerate}

The algorithm uses a mapping array jbraj to translate between constrained and unconstrained parameter spaces, where\+:
\begin{DoxyItemize}
\item Positive values\+: direct mapping from ddw to derjas
\item Negative values\+: sign-\/flipped mapping from ddw to derjas
\end{DoxyItemize}

\begin{DoxyParagraph}{Algorithm Details\+:}
The subroutine implements parameter mapping based on the wave function type\+:
\begin{DoxyEnumerate}
\item {\bfseries{Complex Wave Functions (ipc=2)\+:}} Handles real and imaginary parts separately
\item {\bfseries{Real Wave Functions (ipc=1)\+:}} Direct parameter mapping with sign handling
\end{DoxyEnumerate}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Parameter Mapping\+:}

\begin{DoxyItemize}
\item {\bfseries{Positive jbraj values\+:}} Direct copy from ddw to derjas
\item {\bfseries{Negative jbraj values\+:}} Sign-\/flipped copy from ddw to derjas
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{Complex Wave Function Handling\+:}
For complex wave functions (ipc=2), the subroutine handles\+:
\begin{DoxyItemize}
\item Real parts\+: derjas(2\texorpdfstring{$\ast$}{*}i-\/1) = ±ddw(2\texorpdfstring{$\ast$}{*}j-\/1)
\item Imaginary parts\+: derjas(2\texorpdfstring{$\ast$}{*}i) = ±ddw(2\texorpdfstring{$\ast$}{*}j) where the sign depends on whether jbraj(i) is positive or negative.
\end{DoxyItemize}
\end{DoxyParagraph}
\begin{DoxyParagraph}{3-\/Body Jastrow Terms\+:}
This subroutine is specifically designed for 3-\/body Jastrow correlation functions, which describe electron-\/electron-\/electron correlations in quantum Monte Carlo calculations. The n3body parameter specifies the number of such terms.
\end{DoxyParagraph}
