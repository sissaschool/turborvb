Generate symmetry operations for cubic and lower-\/symmetry Bravais lattices. 

This subroutine provides symmetry operations for all cubic and lower-\/symmetry Bravais lattices (Hexagonal and Trigonal excepted). It generates rotation matrices and their names for crystallographic symmetry operations.

The subroutine works by\+:
\begin{DoxyEnumerate}
\item Computing the overlap matrix between direct lattice vectors
\item Testing each of 24 possible symmetry operations
\item Checking if the operation preserves the lattice structure
\item Adding inversion symmetry (all Bravais lattices have inversion)
\end{DoxyEnumerate}

The symmetry operations include\+:
\begin{DoxyItemize}
\item Identity and inversion
\item 90°, 120°, and 180° rotations around various axes
\item Combinations of rotations and inversions
\end{DoxyItemize}
