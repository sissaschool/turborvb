\doxysubsection{Detailed Description}
B-\/spline interpolation library for one, two, and three dimensions. 

\begin{DoxyAuthor}{Author}
Wolfgang Schadow (original), Turbo\+RVB group (modifications) 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2000 (original), 2022 (modifications) 
\end{DoxyDate}
\begin{DoxyVersion}{Version}
2.\+2
\end{DoxyVersion}
This library contains routines for B-\/spline interpolation in one, two, and three dimensions. Part of the routines are based on the book by Carl de Boor\+: "{}\+A practical guide to Splines"{} (Springer, New-\/\+York 1978) and have the same calling sequence and names as the corresponding routines from the IMSL library.

The library provides\+:
\begin{DoxyItemize}
\item 1D B-\/spline interpolation and evaluation
\item 2D tensor-\/product B-\/spline interpolation and evaluation ~\newline

\item 3D tensor-\/product B-\/spline interpolation and evaluation
\item Derivative evaluation for all dimensions
\item Grid-\/based evaluation capabilities
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Results may vary slightly on different architectures due to floating-\/point precision differences.
\end{DoxyNote}
