program fitvsa}



Variable selection and analysis program for Turbo\+RVB. 

This program performs variable selection and analysis using polynomial fitting with various transformation options. It supports machine learning approaches with evidence-\/based model selection. The program can handle different input formats and provides statistical error analysis through Monte Carlo sampling.
