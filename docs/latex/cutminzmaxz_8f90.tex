Cut and rescale parameters to maintain Z values within bounds. 

This subroutine rescales alphab if the Z values are outside the interval minz \texorpdfstring{$<$}{<} Z \texorpdfstring{$<$}{<} maxz. It does not modify any other input parameters. If the previous Z values (alphavar) are already outside the interval, they are not changed. The subroutine handles both contracted and non-\/contracted cases for parameter optimization.
