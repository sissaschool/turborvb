logical function slaterorb (\begin{DoxyParamCaption}\item[{integer}]{ioptorb}{}\end{DoxyParamCaption})}



Orbital type classification for Slater vs Gaussian orbitals. 

This function determines whether a given orbital type code corresponds to a Slater-\/type orbital (STO) or a Gaussian-\/type orbital (GTO) in quantum Monte Carlo calculations. It provides a systematic way to classify orbital types based on their numerical identifiers.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em ioptorb} & Orbital type code to be classified \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Logical value\+: .true. for Slater orbitals, .false. for Gaussian orbitals
\end{DoxyReturn}
The function performs the following classification\+:
\begin{DoxyEnumerate}
\item Slater-\/type orbitals (return .true.)\+:
\begin{DoxyItemize}
\item Ranges\+: 1\+:8, 10\+:15, 20\+:29, 30\+:35, 38\+:43, 50, 55\+:57, 66, 70, 71, 80\+:89
\item Extended ranges\+: 121\+:123, 125\+:130, 133\+:144
\end{DoxyItemize}
\item Gaussian-\/type orbitals (return .false.)\+:
\begin{DoxyItemize}
\item Ranges\+: 16\+:19, 36, 37, 44\+:49, 51\+:54, 58\+:59, 60\+:65, 68\+:69, 72, 73
\item Extended ranges\+: 100\+:105, 108, 109, 131, 132, 145\+:155, 161
\item Large ranges\+: 1000\+:1099, 2000\+:2099, 1100\+:1199, 2100\+:2199, 1200\+:1299, 2200\+:2299
\item Special case\+: 200 (constant orbital considered Gaussian)
\end{DoxyItemize}
\item Unknown orbital types\+: Sets error flag and reports the unknown code
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The function uses case statements for efficient classification 

Slater orbitals include s, p, d, f, g orbitals and their variants 

Gaussian orbitals include contracted Gaussians and specialized forms 

The constant orbital (ioptorb=200) is classified as Gaussian 

Unknown orbital types trigger an error condition (iflagerr=1) 

Used in wave function setup and orbital basis set management 
\end{DoxyNote}
