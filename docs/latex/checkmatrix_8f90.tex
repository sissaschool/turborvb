Check and validate sparse matrix with linear indexing. 

This subroutine validates a sparse matrix stored in linear format and finds correspondences between two different sparse matrix representations. It uses a 1D indexing scheme where matrix elements are stored as linear indices.


\begin{DoxyParams}[1]{Parameters}

\hline
\mbox{\texttt{in}}  & {\em nnozeron} & Number of non-\/zero elements in the target matrix \\
\hline
\mbox{\texttt{in}}  & {\em nelorb} & Number of orbitals (matrix dimension) \\
\hline
\mbox{\texttt{in}}  & {\em nozero} & Array containing reference matrix linear indices (nnozero elements) \\
\hline
\mbox{\texttt{in}}  & {\em nozeron} & Array containing target matrix linear indices (nnozeron elements) \\
\hline
\mbox{\texttt{out}}  & {\em index\+\_\+out} & Output array mapping reference indices to target indices \\
\hline
\mbox{\texttt{in}}  & {\em rank} & MPI rank for parallel execution \\
\hline
\mbox{\texttt{in}}  & {\em nelorb\+\_\+c} & Number of orbitals in the contracted basis\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Validates that all matrix indices are within the valid range \mbox{[}1, nelorb\+\_\+c\texorpdfstring{$\ast$}{*}nelorb\mbox{]}
\item Sorts both sparse matrix representations for efficient searching
\item Finds correspondences between reference and target matrix elements
\item Creates a mapping array index\+\_\+out where\+:
\begin{DoxyItemize}
\item index\+\_\+out(j) = i if reference element j corresponds to target element i
\item index\+\_\+out(j) = -\/i if reference element j corresponds to target element -\/i (sign change)
\item index\+\_\+out(j) = 0 if no correspondence is found
\end{DoxyItemize}
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}

This subroutine is designed for parallel execution with MPI. 

The subroutine terminates the program if matrix elements are out of range. 
\end{DoxyNote}

Sparse matrix validation and checking utilities. 

This module provides subroutines for validating and checking sparse matrix structures used in quantum Monte Carlo calculations. It includes functions for checking matrix element ranges, finding correspondences between different sparse matrix representations, and detecting duplicate matrix elements.

The module handles both standard sparse matrix formats and specialized formats used in Turbo\+RVB for orbital and molecular orbital matrices.

Check for duplicate matrix elements in sparse matrix. 

This subroutine detects and reports duplicate matrix elements in a sparse matrix representation. It is used for validation to ensure that each matrix element appears only once in the sparse format.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em nnozero} & Number of non-\/zero elements in the matrix \\
\hline
\mbox{\texttt{in}}  & {\em nelorb} & Number of orbitals (matrix dimension) \\
\hline
\mbox{\texttt{in}}  & {\em nozero} & Array containing matrix linear indices (nnozero elements) \\
\hline
\mbox{\texttt{in}}  & {\em rank} & MPI rank for parallel execution\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Sorts the matrix indices in ascending order
\item Scans through the sorted array to find consecutive identical elements
\item Reports the location (row, column) and frequency of each duplicate
\item Terminates the program if duplicates are found (in parallel mode)
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The subroutine converts linear indices back to (row, column) format for reporting\+: row = (index -\/ 1) \% nelorb + 1, column = (index -\/ 1) / nelorb + 1 

This subroutine is designed for parallel execution with MPI. 

The subroutine terminates the program if duplicate elements are found. 

Only rank 0 performs the checking and reporting, but all ranks are synchronized for termination. 
\end{DoxyNote}
