Portable random number generator for quantum Monte Carlo. 

This function implements a portable random number generator based on the Park-\/\+Miller minimal standard multiplicative linear congruential generator combined with a Marsaglia shift sequence. It provides uniform random numbers in the interval (0,1) for use in quantum Monte Carlo calculations.


\begin{DoxyParams}[1]{Parameters}

\item idum ≤ 0\+: Initialize generator with \texorpdfstring{$\vert$}{|}idum\texorpdfstring{$\vert$}{|}
\item idum \texorpdfstring{$>$}{>} 0\+: Generate next random number 
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Real random number in the interval (0,1)
\end{DoxyReturn}
The function implements a combined generator with the following features\+:
\begin{DoxyEnumerate}
\item Park-\/\+Miller multiplicative linear congruential generator\+:
\begin{DoxyItemize}
\item Parameters\+: IA = 16807, IM = 2147483647, IQ = 127773, IR = 2836
\item Recurrence\+: iy = IA \texorpdfstring{$\ast$}{*} (iy -\/ k\texorpdfstring{$\ast$}{*}\+IQ) -\/ IR\texorpdfstring{$\ast$}{*}k (mod IM)
\end{DoxyItemize}
\item Marsaglia shift sequence for ix\+:
\begin{DoxyItemize}
\item Uses XOR and bit shifts for additional randomness
\end{DoxyItemize}
\item Combined output\+: ran = am \texorpdfstring{$\ast$}{*} (ix XOR iy OR 1)
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The generator has a period of approximately 2\texorpdfstring{$^\wedge$}{\string^}31 -\/ 1 

The function uses saved variables to maintain state between calls 

Initialization occurs when idum ≤ 0 or iy \texorpdfstring{$<$}{<} 0 

The function is portable across different platforms and compilers 

Used extensively in Monte Carlo sampling and random walk algorithms 
\end{DoxyNote}
