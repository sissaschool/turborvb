program zerojasfort10}



Jastrow factor zeroing program for Turbo\+RVB. 

This program reads a Turbo\+RVB wave function (fort.\+10) and selectively zeros Jastrow factors while preserving the wave function structure. It can zero both charge and spin-\/dependent Jastrow factors, with an option to preserve one-\/body terms. The program outputs a new fort.\+10\+\_\+new file with the modified Jastrow parameters.

The program supports two modes\+:
\begin{DoxyItemize}
\item Normal mode\+: zeros all Jastrow factors
\item leave1body mode\+: preserves one-\/body Jastrow terms
\end{DoxyItemize}
