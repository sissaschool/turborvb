\doxysubsection{Detailed Description}
Vector module for 3D vector field interpolation. 

This module provides data structures and variables for handling 3D vector field interpolation and evaluation.

The module contains\+:
\begin{DoxyItemize}
\item Grid dimensions for vector field
\item Vector field values on 3D grid
\item Coordinate vectors for interpolation
\item First call flag for initialization
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Used for vector field potentials and forces 

Supports 3D vector interpolation 
\end{DoxyNote}
