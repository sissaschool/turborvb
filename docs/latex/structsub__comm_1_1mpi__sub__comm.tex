\doxysubsection{Detailed Description}
Derived type for MPI sub-\/communicator information. 

Contains all necessary information for managing a sub-\/communicator\+:
\begin{DoxyItemize}
\item rank\+: Rank of current process in the sub-\/communicator
\item nproc\+: Number of processes in the sub-\/communicator
\item comm\+: MPI communicator handle for the sub-\/communicator
\item parent\+: Parent communicator handle
\item yesin\+: Logical flag indicating if current process is in the sub-\/communicator 
\end{DoxyItemize}
