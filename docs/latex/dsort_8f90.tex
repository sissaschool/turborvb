Sorts array X and optionally carries along array Y. 

This subroutine sorts array X and optionally makes the same interchanges in array Y. The array X may be sorted in increasing order or decreasing order. A slightly modified QUICKSORT algorithm (Singleton\textquotesingle{}s algorithm) is used. This is a Fortran 77 implementation from the SLATEC library. 
\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in,out}}  & {\em X} & Array of values to be sorted (usually abscissas) \\
\hline
\mbox{\texttt{in,out}}  & {\em Y} & Array to be optionally carried along with X \\
\hline
\mbox{\texttt{in}}  & {\em N} & Number of values in array X to be sorted \\
\hline
\mbox{\texttt{in}}  & {\em KFLAG} & Control parameter\+:
\begin{DoxyItemize}
\item KFLAG = 2\+: sort X in increasing order and carry Y along
\item KFLAG = 1\+: sort X in increasing order (ignoring Y)
\item KFLAG = -\/1\+: sort X in decreasing order (ignoring Y)
\item KFLAG = -\/2\+: sort X in decreasing order and carry Y along 
\end{DoxyItemize}\\

\end{DoxyParams}
