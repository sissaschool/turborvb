program find\+\_\+kpoints}



K-\/points finder program for Turbo\+RVB. 

This program determines the total number of k-\/points and their coordinates given a wave function file (fort.\+10) and input parameters. It requires a complex wave function and periodic boundary conditions. The program reads the k-\/points card from standard input and prints all k-\/points associated with the calculation.
