Preconditioned conjugate gradient method for matrix inversion with complex parameters. 

This subroutine implements a preconditioned conjugate gradient method for solving linear systems involving complex parameters. It uses a master-\/slave paradigm to ensure roundoff-\/free calculations. The matrix is distributed across raw groups with prep processors each, and handles both real and complex variational parameters with proper matrix structure for stochastic reconfiguration.
