File operations and I/O management module for Turbo\+RVB. 

This module provides comprehensive file I/O operations for Turbo\+RVB, including scratch directory management, file opening/closing, and parallel I/O support. It handles various output files for energy, forces, positions, and other simulation data. \begin{DoxyAuthor}{Author}

subroutine open\+\_\+files (\begin{DoxyParamCaption}\item[{integer}]{rank}{, }\item[{character(lchlen)}]{scratchpath}{}\end{DoxyParamCaption})}



Open all necessary files for Turbo\+RVB simulation. 

This subroutine opens various output files based on simulation parameters and I/O level settings. It handles both serial and parallel I/O modes, including POSIX and MPI-\/\+IO support. 
\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in}}  & {\em rank} & MPI rank of the current process \\
\hline
\mbox{\texttt{in}}  & {\em scratchpath} & Scratch directory path for temporary files \\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
Opens different files based on itestr, iopt, and other flags 

Supports multiple I/O levels (0=local, 1=POSIX, 2=MPI-\/\+IO) 

Creates rank-\/specific file names for parallel runs 

Handles quantum/classical decoupled runs 
\end{DoxyNote}
