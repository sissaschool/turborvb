\doxysubsection{Detailed Description}
Statistical estimator module for Turbo\+RVB. 

This module provides data structures and procedures for computing statistical estimators including averages, variances, and correlation functions. It supports both scalar and array data types with different levels of statistical analysis.

The module defines several derived types\+:
\begin{DoxyItemize}
\item avg\+\_\+scalar/avg\+\_\+array\+: For simple averaging
\item esti\+\_\+scalar/esti\+\_\+array\+: For statistical analysis with variance
\item corr\+\_\+basic/corr\+\_\+advanced\+: For correlation functions
\end{DoxyItemize}

Each type has associated procedures for allocation, reset, data pushing, calculation, and cleanup.
