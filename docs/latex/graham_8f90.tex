Real Gram-\/\+Schmidt orthogonalization with general metric

This subroutine performs Gram-\/\+Schmidt orthogonalization of real vectors using a general overlap matrix as the metric. The output vectors are orthogonal in the sense that they satisfy the orthogonality condition with respect to the given metric.

Complex Gram-\/\+Schmidt orthogonalization with general metric. 

This subroutine performs Gram-\/\+Schmidt orthogonalization of complex vectors using a general overlap matrix as the metric. The output vectors are orthogonal in the sense that they satisfy the orthogonality condition with respect to the given metric, using the complex conjugate scalar product.
