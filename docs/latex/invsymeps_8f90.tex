\doxysubsection{Detailed Description}
Symmetric (Hermitian) matrix inversion and trace utilities. 

This module provides routines for inverting symmetric or Hermitian matrices using eigenvalue decomposition, as well as utility functions for computing traces and trace-\/like quantities for real and complex matrices. \begin{DoxyAuthor}{Author}
Turbo\+RVB group 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2022 
\end{DoxyDate}
\hypertarget{invsymeps_8f90_Features}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{invsymeps_8f90_Features}

\begin{DoxyItemize}
\item Robust inversion of symmetric/\+Hermitian matrices with eigenvalue thresholding
\item Handles both real and complex matrices (ipc=1 or 2)
\item Computes traces and trace-\/like quantities for matrix products
\item Parallelization support (MPI) 
\end{DoxyItemize}

Invert a symmetric (Hermitian) matrix using eigenvalue decomposition. 

Computes the inverse of a symmetric (real or complex Hermitian) matrix by diagonalizing and thresholding small eigenvalues. Handles both real and complex cases, and supports parallel execution with MPI. 
\begin{DoxyParams}[1]{Parameters}
