program orthomol}



Molecular orbital orthogonalization program for Turbo\+RVB. 

This program performs orthogonalization of molecular orbitals in a Turbo\+RVB wave function. It reads a fort.\+10 file, applies orthogonalization procedures, and outputs a new fort.\+10\+\_\+new file with orthogonalized orbitals. The program supports both serial and parallel execution modes.
