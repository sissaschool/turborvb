\doxysubsection{Detailed Description}
Link angle module for molecular mechanics interactions. 

This module provides data structures and variables for handling molecular mechanics interactions in QM/\+MM calculations, including bonds, angles, dihedrals, and improper dihedrals.

The module contains\+:
\begin{DoxyItemize}
\item Two-\/body radial (bond) contributions
\item Three-\/body angular contributions
\item Four-\/body dihedral contributions
\item Improper dihedral contributions
\item Restraint parameters for MM region
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Used in QM/\+MM calculations with molecular mechanics force fields 

Supports various force field types (GROMOS, AMBER, etc.) 
\end{DoxyNote}
