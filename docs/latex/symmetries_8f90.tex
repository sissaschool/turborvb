\doxysubsection{Detailed Description}
Symmetry operations and Bravais lattice symmetries for Turbo\+RVB. 

Provides routines for handling symmetry operations in periodic systems, including Bravais lattice symmetries, point group operations, and symmetry-\/based optimizations. Based on Quantum ESPRESSO symmetry routines adapted for QMC calculations. \begin{DoxyAuthor}{Author}
Turbo\+RVB group (based on Quantum ESPRESSO) 
\end{DoxyAuthor}
