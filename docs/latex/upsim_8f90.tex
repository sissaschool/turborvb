Matrix update utilities for quantum Monte Carlo calculations. 

This module provides subroutines for updating matrix elements in quantum Monte Carlo calculations, supporting both real and complex matrices. It handles different matrix types including standard matrices and Pfaffian matrices for paired and unpaired electrons.

The module includes\+:
\begin{DoxyItemize}
\item Real matrix update with symmetry handling
\item Complex matrix update with Hermitian/transpose symmetry
\item Support for Pfaffian matrices with up/down electron blocks
\item Proper handling of paired and unpaired electron configurations
\end{DoxyItemize}

Update real matrix elements with symmetry handling

This subroutine updates matrix elements in a real matrix, handling different matrix types and symmetry conditions. It supports both standard matrices and Pfaffian matrices for quantum Monte Carlo calculations.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{in,out}}  & {\em amat} & Matrix to be updated (ndim, \texorpdfstring{$\ast$}{*}) \\
\hline
\mbox{\texttt{in}}  & {\em ndim} & Leading dimension of the matrix \\
\hline
\mbox{\texttt{in}}  & {\em ind} & Linear index of the matrix element to update \\
\hline
\mbox{\texttt{in}}  & {\em value} & New value for the matrix element \\
\hline
\mbox{\texttt{in}}  & {\em symmagp} & Flag for symmetric matrix updates \\
\hline
\mbox{\texttt{in}}  & {\em ipf} & Flag indicating matrix type\+:
\begin{DoxyItemize}
\item ipf = 1\+: Standard matrix
\item ipf ≠ 1\+: Pfaffian matrix
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Converts linear index to (i,j) matrix coordinates
\item For standard matrices (ipf = 1)\+:
\begin{DoxyItemize}
\item Sets amat(i,j) = value
\item If symmagp is true, sets amat(j,i) = value
\end{DoxyItemize}
\item For Pfaffian matrices (ipf ≠ 1)\+:
\begin{DoxyItemize}
\item Sets amat(i,j) = value and amat(j,i) = -\/value
\item Handles up/down electron blocks with proper symmetry
\item Manages paired and unpaired electron configurations
\item Applies symmetry conditions based on ion types
\end{DoxyItemize}
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The subroutine handles antisymmetry of Pfaffian matrices 

Up/down electron blocks are handled separately for paired electrons 

The subroutine respects ion type constraints (kiontot) 

Used in wave function optimization and matrix updates 
\end{DoxyNote}

Update complex matrix elements with symmetry handling. 

This subroutine updates matrix elements in a complex matrix, handling different matrix types and symmetry conditions. It supports both standard matrices and Pfaffian matrices with proper handling of Hermitian and transpose symmetries.

\item ipf ≠ 1\+: Pfaffian matrix
\end{DoxyItemize}\\
\hline
\end{DoxyParams}
The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Converts linear index to (i,j) matrix coordinates
\item For standard matrices (ipf = 1)\+:
\begin{DoxyItemize}
\item Sets amat(i,j) = value(1)
\item If symmagp is true, applies Hermitian or transpose symmetry
\end{DoxyItemize}
\item For Pfaffian matrices (ipf ≠ 1)\+:
\begin{DoxyItemize}
\item Sets amat(i,j) = value(1) and amat(j,i) = -\/value(1)
\item Handles up/down electron blocks with proper symmetry
\item Applies Hermitian or transpose symmetry based on yes\+\_\+hermite flag
\item Manages paired and unpaired electron configurations
\end{DoxyItemize}
\end{DoxyEnumerate}

Up/down electron blocks are handled separately for paired electrons 

Used in complex wave function optimization and matrix updates 
\end{DoxyNote}
