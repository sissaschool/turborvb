Solve skew-\/symmetric tridiagonal system A\texorpdfstring{$\ast$}{*}X = B. 

This subroutine solves the linear system A\texorpdfstring{$\ast$}{*}X = B where A is a non-\/singular skew-\/symmetric tridiagonal matrix of even dimension n. The matrix A is stored in packed format with A(i+1,i) = a(i) and A(i,i+1) = -\/a(i) for i = 1, ..., n-\/1.\hypertarget{dsktrs_8f90_autotoc_md31}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{dsktrs_8f90_autotoc_md31}
UPLO \+: character, in Specifies which part of the matrix A is stored\+: \textquotesingle{}U\textquotesingle{} or \textquotesingle{}u\textquotesingle{}\+: Upper triangular part is stored (A(i,i+1) = a(i)). \textquotesingle{}L\textquotesingle{} or \textquotesingle{}l\textquotesingle{}\+: Lower triangular part is stored (A(i+1,i) = a(i)). N \+: integer, in Order of the matrix A (must be even). NHRS \+: integer, in Number of right-\/hand sides. A \+: real\texorpdfstring{$\ast$}{*}8 array, in The skew-\/symmetric tridiagonal matrix stored in packed format. For UPLO = \textquotesingle{}U\textquotesingle{}\+: A(i,i+1) = a(i), i = 1, ..., n-\/1. For UPLO = \textquotesingle{}L\textquotesingle{}\+: A(i+1,i) = a(i), i = 1, ..., n-\/1. B \+: real\texorpdfstring{$\ast$}{*}8 array, in Right-\/hand side matrix (N × NHRS). LDB \+: integer, in Leading dimension of array B. X \+: real\texorpdfstring{$\ast$}{*}8 array, work Workspace array for storing intermediate results. INFO \+: integer, out = 0\+: successful exit. \texorpdfstring{$<$}{<} 0\+: if INFO = -\/i, the i-\/th argument had an illegal value. \texorpdfstring{$>$}{>} 0\+: if INFO = i, A(i,i+1) is exactly zero; the matrix is singular.\hypertarget{dsktrs_8f90_autotoc_md32}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{dsktrs_8f90_autotoc_md32}

\begin{DoxyItemize}
\item The matrix A must be of even dimension n.
\item The solution is computed using forward and backward substitution.
\item Even-\/indexed variables are solved forward, odd-\/indexed backward.
\item The algorithm exploits the special structure of skew-\/symmetric matrices.
\item For UPLO = \textquotesingle{}L\textquotesingle{}, the signs of the matrix elements are temporarily flipped.
\end{DoxyItemize}\hypertarget{dsktrs_8f90_autotoc_md33}{}\doxysubsubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{dsktrs_8f90_autotoc_md33}

\begin{DoxyEnumerate}
\item For UPLO = \textquotesingle{}L\textquotesingle{}, flip signs of matrix elements
\item Solve even-\/indexed variables forward\+: x(2), x(4), ..., x(n)
\item Solve odd-\/indexed variables backward\+: x(n-\/1), x(n-\/3), ..., x(1)
\item Copy solution back to B
\item Restore original matrix signs if needed
\end{DoxyEnumerate}\hypertarget{dsktrs_8f90_autotoc_md34}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{dsktrs_8f90_autotoc_md34}
