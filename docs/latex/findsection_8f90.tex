Find a specific section in a file. 

This subroutine searches for a specific section name in a file by reading through the file line by line. It rewinds the file to the beginning and searches for an exact match with the provided section name. If the section is found, the file pointer is positioned at the beginning of that section. If not found, an error is raised.
