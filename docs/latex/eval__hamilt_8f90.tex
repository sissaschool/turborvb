Evaluates Hamiltonian eigenvalues and eigenvectors in non-\/orthogonal basis. 

This subroutine computes the first bands eigenvectors of a Hamiltonian defined in a non-\/orthogonal basis. It handles ill-\/conditioned overlap matrices by applying a stable diagonalization algorithm that removes singular eigenvalues and reorthogonalizes eigenvectors. Supports both serial and parallel (SCALAPACK) execution with different algorithms for each case.
