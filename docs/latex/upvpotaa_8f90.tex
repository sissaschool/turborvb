Calculate ion-\/ion potential energy with Ewald summation. 

This function computes the ion-\/ion electrostatic potential energy using either direct Coulomb interaction (for isolated systems) or Ewald summation (for periodic boundary conditions). The calculation includes both the real-\/space and self-\/interaction contributions.\hypertarget{upvpotaa_8f90_autotoc_md70}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{upvpotaa_8f90_autotoc_md70}
ZETA \+: real\texorpdfstring{$\ast$}{*}8 array, in Array of ion charges (NION). IOND \+: real\texorpdfstring{$\ast$}{*}8 array, in Matrix of ion-\/ion distances (NION × NION). NION \+: integer, in Number of ions in the system. KAPPA \+: real\texorpdfstring{$\ast$}{*}8, in Ewald parameter for splitting the Coulomb interaction. LBOX \+: real\texorpdfstring{$\ast$}{*}8, in Box length for periodic boundary conditions. If LBOX ≤ 0\+: isolated system (direct Coulomb). If LBOX \texorpdfstring{$>$}{>} 0\+: periodic system (Ewald summation).\hypertarget{upvpotaa_8f90_autotoc_md71}{}\doxysubsubsection{\texorpdfstring{Returns}{Returns}}\label{upvpotaa_8f90_autotoc_md71}
real\texorpdfstring{$\ast$}{*}8 Total ion-\/ion potential energy including self-\/interaction correction.\hypertarget{upvpotaa_8f90_autotoc_md72}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{upvpotaa_8f90_autotoc_md72}

\begin{DoxyItemize}
\item For isolated systems (LBOX ≤ 0)\+: uses direct Coulomb interaction.
\item For periodic systems (LBOX \texorpdfstring{$>$}{>} 0)\+: uses Ewald summation with\+:
\begin{DoxyItemize}
\item Real-\/space contribution using complementary error function.
\item Self-\/interaction correction to avoid double-\/counting.
\end{DoxyItemize}
\item Includes nearest-\/neighbor interactions for periodic systems.
\item Uses SIMD vectorization for performance optimization.
\item The self-\/interaction term is\+: -\/2\texorpdfstring{$\ast$}{*}κ\texorpdfstring{$\ast$}{*}ε₀/√π \texorpdfstring{$\ast$}{*} Σ(zeta²).
\end{DoxyItemize}\hypertarget{upvpotaa_8f90_autotoc_md73}{}\doxysubsubsection{\texorpdfstring{Algorithm}{Algorithm}}\label{upvpotaa_8f90_autotoc_md73}
