program fort10toxyz}



Lambda parameter plotting program for Turbo\+RVB. 

This program reads a Turbo\+RVB wave function (fort.\+10) and generates files containing lambda parameters sorted by distance. It outputs lambda.\+dat for orbital parameters, lambdaj.\+dat for Jastrow parameters, and lambdajsz.\+dat for spin-\/dependent Jastrow parameters if applicable.
