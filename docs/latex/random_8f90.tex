Random configuration selection for quantum Monte Carlo moves. 

This subroutine implements a random configuration selection algorithm for quantum Monte Carlo calculations, particularly useful for non-\/diagonal moves in variational Monte Carlo and diffusion Monte Carlo. It uses a cumulative probability table to select configurations based on their transition probabilities.

The subroutine performs the following operations\+:
\begin{DoxyEnumerate}
\item Initializes cumulative probability with diagonal element
\item Iterates through configurations until cumulative probability ≥ ztry\+:
\begin{DoxyItemize}
\item Calculates configuration and particle indices
\item Applies power and gamma modifications to transition weights
\item Accumulates modified weights in cumulative probability
\end{DoxyItemize}
\item Handles edge cases and roundoff errors\+:
\begin{DoxyItemize}
\item Adjusts index if final configuration has zero weight
\item Ensures valid configuration selection
\end{DoxyItemize}
\item Determines sign based on transition weight sign
\item Returns selected configuration and particle indices
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
The algorithm assumes diag \texorpdfstring{$<$}{<} ztry ≤ wtot (non-\/diagonal move) 

Configuration index is calculated as\+: index = (i-\/1)/L + 1 

Particle index is calculated as\+: ipart = i -\/ (index-\/1)\texorpdfstring{$\ast$}{*}L 

Negative indvic indicates unrecoverable error (zero weight) 

The subroutine handles both positive and negative transition weights 

Power and gamma parameters modify transition weights for optimization 
\end{DoxyNote}
