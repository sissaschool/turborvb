Read atomic wave functions from files. 

This subroutine reads atomic wave function files for each atom and extracts orbital information for both determinant and Jastrow orbitals. It processes fort.\+10 files and builds the orbital arrays.

The subroutine handles\+:
\begin{DoxyItemize}
\item Reading atomic fort.\+10 files
\item Extracting orbital parameters and types
\item Building determinant and Jastrow orbital arrays
\item Setting up atomic matrices
\item Handling different atom types

Read orbital definitions from input file. 

This subroutine reads orbital definitions for both determinant and Jastrow orbitals from the input file. It processes each atom\textquotesingle{}s orbital shells, counts the total number of orbitals and parameters, and allocates the necessary arrays.

The subroutine handles\+:
\begin{DoxyItemize}
\item Determinant orbitals (detorb)
\item Jastrow orbitals (jasorb)
\item Shell counting and parameter estimation
\item Atomic Jastrow matrices
\item Hybrid orbital generation
\end{DoxyItemize}
