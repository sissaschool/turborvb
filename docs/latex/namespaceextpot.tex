\doxysubsection{Detailed Description}
External potential module for quantum Monte Carlo calculations. 

This module provides functionality for handling external potentials in quantum Monte Carlo calculations, including cube file potentials, QM/\+MM interfaces, and various molecular mechanics interactions.

The module contains variables for\+:
\begin{DoxyItemize}
\item Cube file potential data (grid, atoms, charges)
\item Statistical averages and error estimates
\item MPI parallelization support
\item Link atom definitions for QM/\+MM interfaces
\item Molecular mechanics restraints and forces
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Used in VMC and DMC calculations with external potentials 

Supports QM/\+MM hybrid calculations and molecular mechanics 
\end{DoxyNote}
