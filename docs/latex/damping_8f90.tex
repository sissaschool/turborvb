Calculate damping function for quantum chemistry interactions. 

This function computes a damping factor used in quantum chemistry calculations to modify the strength of interactions based on distance and quantum number. The damping function is based on the work by G. Scoles et al. in J. Chem. Phys. 76, 3057 (1982).


\begin{DoxyParams}[1]{Parameters}

\hline
\mbox{\texttt{in}}  & {\em n} & Quantum number parameter (0 for no damping) \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
damping Damping factor (0 ≤ damping ≤ 1)
\end{DoxyReturn}
The damping function implements the following formula\+:

\end{DoxyCode}


{\bfseries{For n = 0\+:}} 
\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{damping_8f90_a42f7375ae5e4bc350c612d5ca4859e25}{damping}}\ =\ 1.0}

\end{DoxyCode}


{\bfseries{Physical Interpretation\+:}}
\begin{DoxyItemize}
\item The damping function reduces the strength of interactions at short distances
\item The reduction is more pronounced for larger quantum numbers (n)
\item The function approaches 1.\+0 as distance increases
\item For n = 0, no damping is applied (damping = 1.\+0)
\end{DoxyItemize}

{\bfseries{Parameters\+:}}
\begin{DoxyItemize}
\item r\+: Distance parameter (typically in atomic units)
\item n\+: Quantum number that controls the damping strength
\item 2.\+1\+: Linear damping coefficient
\item 0.\+109\+: Quadratic damping coefficient
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The function is commonly used in van der Waals and dispersion interactions. 

The damping factor is always in the range \mbox{[}0, 1\mbox{]}. 

For n = 0, the function returns 1.\+0 regardless of the distance r. 

The exponential form ensures smooth behavior across all distances. 
\end{DoxyNote}
Return unity damping for n = 0 (no damping)
