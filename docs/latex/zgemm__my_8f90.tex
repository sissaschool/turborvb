Parallel complex matrix-\/matrix multiplication with MPI distribution. 

This subroutine performs complex matrix-\/matrix multiplication C = α\texorpdfstring{$\ast$}{*}\+A\texorpdfstring{$\ast$}{*}B + β\texorpdfstring{$\ast$}{*}C in parallel using MPI. The K dimension is distributed across processors, with each processor computing a partial result that is then reduced to form the final result. Supports both transpose and conjugate transpose operations.\hypertarget{zgemm__my_8f90_autotoc_md103}{}\doxysubsubsection{\texorpdfstring{Parameters}{Parameters}}\label{zgemm__my_8f90_autotoc_md103}
TRANSA \+: character\texorpdfstring{$\ast$}{*}1, in Transpose flag for matrix A (\textquotesingle{}N\textquotesingle{}=no transpose, \textquotesingle{}T\textquotesingle{}=transpose, \textquotesingle{}C\textquotesingle{}=conjugate transpose). TRANSB \+: character\texorpdfstring{$\ast$}{*}1, in Transpose flag for matrix B (\textquotesingle{}N\textquotesingle{}=no transpose, \textquotesingle{}T\textquotesingle{}=transpose, \textquotesingle{}C\textquotesingle{}=conjugate transpose). M \+: integer, in Number of rows in matrices A and C. N \+: integer, in Number of columns in matrices B and C. K \+: integer, in Number of columns in A and rows in B (distributed dimension). ALPHA \+: complex\texorpdfstring{$\ast$}{*}16, in Complex scalar multiplier for A\texorpdfstring{$\ast$}{*}B. A \+: complex\texorpdfstring{$\ast$}{*}16 array, in Input complex matrix A (size depends on TRANSA). LDA \+: integer, in Leading dimension of matrix A. B \+: complex\texorpdfstring{$\ast$}{*}16 array, in Input complex matrix B (size depends on TRANSB). LDB \+: integer, in Leading dimension of matrix B. BETA \+: complex\texorpdfstring{$\ast$}{*}16, in Complex scalar multiplier for C. C \+: complex\texorpdfstring{$\ast$}{*}16 array, inout Input/output complex matrix C (M × N). LDC \+: integer, in Leading dimension of matrix C. nproc \+: integer, in Number of MPI processes. rank \+: integer, in MPI rank of current process. comm\+\_\+mpi \+: integer, in MPI communicator.\hypertarget{zgemm__my_8f90_autotoc_md104}{}\doxysubsubsection{\texorpdfstring{Notes}{Notes}}\label{zgemm__my_8f90_autotoc_md104}

\begin{DoxyItemize}
\item The K dimension is distributed across processors for parallel computation.
\item Each processor computes a partial matrix multiplication with its local K slice.
\item Results are reduced using MPI to form the final matrix C.
\item Only rank 0 applies the BETA scaling; other ranks start with zero.
\item Supports all combinations of transpose operations including conjugate transpose.
\item Complex matrices are handled as pairs of real numbers in MPI reduction.
\end{DoxyItemize}\hypertarget{zgemm__my_8f90_autotoc_md105}{}\doxysubsubsection{\texorpdfstring{Example}{Example}}\label{zgemm__my_8f90_autotoc_md105}
