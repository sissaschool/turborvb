\doxysubsection{Detailed Description}
Fort.\+11 file I/O operations for Turbo\+RVB. 

This module handles reading and writing of fort.\+11 files, which contain simulation state information for restart and continuation of quantum Monte Carlo calculations. \begin{DoxyAuthor}{Author}
Turbo\+RVB group 
\end{DoxyAuthor}
\begin{DoxyDate}{Date}
2022 
\end{DoxyDate}
\hypertarget{invsymeps_8f90_Features}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{invsymeps_8f90_Features}

\begin{DoxyItemize}
\item Write simulation state to fort.\+11 for restart capability
\item Read simulation state from fort.\+11 for continuation
\item Handle various simulation parameters and arrays
\item Support for different simulation modes (VMC, LRDMC, etc.)
\item Compatibility checking between read and current parameters 
\end{DoxyItemize}\hypertarget{fort11__io_8f90_Files}{}\doxysubsection{\texorpdfstring{Files}{Files}}\label{fort11__io_8f90_Files}
fort.\+11 contains\+:
\begin{DoxyItemize}
\item Simulation parameters (nw, np, nmatb, etc.)
\item Walker configurations (wconfn)
\item Correlation weights (wcorw)
\item Kinetic energy derivatives (dek, dekg)
\item Ion velocities (velion)
\item CG optimization data (reduce)
\item Contraction matrices (detmat\+\_\+proj, projmat\+\_\+c) 
\end{DoxyItemize}

Read simulation header information from fort.\+11. 

Reads the beginning section of fort.\+11 file containing simulation parameters, dimensions, and control variables. Performs compatibility checks and handles parameter updates. \begin{DoxyNote}{Note}
Rewinds unit 11 before reading 

Reads rmax and rmaxj if scalermax is enabled

subroutine write\+\_\+fort11\+\_\+end}



Write simulation data arrays to fort.\+11. 

Writes the main simulation data arrays to fort.\+11 file, including walker configurations, correlation weights, kinetic energy derivatives, and optimization data. \begin{DoxyNote}{Note}
Writes different data sets based on itestr value 

Handles contraction matrices if contraction \texorpdfstring{$>$}{>} 0

Writes CG optimization data (reduce array) for parameter optimization 

Conditionally writes detmat\+\_\+proj and projmat\+\_\+c if allocated 

Writes covariance matrix (cov\+\_\+old) if allocated
